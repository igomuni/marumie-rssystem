# MOF 予算書アーカイブ由来の CSV（項・目・事項）

財務省の予算書アーカイブ（`data/download/mof.go.jp/archive/`）の原本から作った、素朴な CSV（原本の形のまま、人間が確認できる形）の一覧と作り方。

## 正の置き場

**`tests/fixtures/mof-archive-csv/{2023,2024,2025,2025_teishutsu,2026}/`** が唯一の正。各版に次の 6 ファイルがある（`manifest.json` に全ファイルの SHA-256）。

- 版の意味（アーカイブの CSV 内の日付で確認）: `2023`＝令和5年度、`2024`＝令和6年度、`2026`＝令和8年度は、いずれも**国会への提出時**の予算書（CSV の日付は 1〜2 月）。令和7年度だけ、`2025_teishutsu`＝提出時（2025-01-20）と `2025`＝**成立後**（2025-04-04）の 2 版がある。

| ファイル | 単位 | 由来 | 行数 (2023 / 2024 / 2025 / 2025_teishutsu / 2026) |
|---|---|---|---|
| `kou-general.csv` | 一般会計の項 | 公式 CSV（歳出）を項で集計 | 800 / 784 / 806 / 806 / 824 |
| `kou-special.csv` | 特別会計の項 | 同上 | 243 / 250 / 254 / 254 / 260 |
| `moku-general.csv` | 一般会計の目 | 公式 CSV（歳出） | 6,823 / 6,718 / 6,780 / 6,780 / 6,790 |
| `moku-special.csv` | 特別会計の目 | 同上 | 1,223 / 1,225 / 1,250 / 1,250 / 1,239 |
| `jikou-general.csv` | 一般会計の事項 | 予算書 XML（事項別内訳） | 1,289 / 1,256 / 1,287 / 1,287 / 1,303 |
| `jikou-special.csv` | 特別会計の事項 | 予算書 XML（歳出事項別内訳） | 361 / 360 / 365 / 365 / 361 |

項・目は公式 CSV（`DL{帳票ID}.zip` の `b.csv`）から、事項は XML から作る。項と事項は、項の（コード・名称）の集合が一致し、項ごとの合計も一致することを作成時に確認した（FY2023〜FY2026 の両会計）。

## 補正予算・決算の目（別ファイル）

当初予算とは原本の表が違う（列も単位も違う）ため、**別ファイル**にしている。行は原本のまま（`source_row` を足すだけ）。足し算・補正はしない。識別列（所管・組織／特別会計・勘定・項コード・各分類コード・項名・目名）は、当初予算の目の CSV と同じ名前で、`項コード＋各分類コード` で結合できる。

| ファイル | 原本 | 金額の列（原本の見出しのまま） | 版 |
|---|---|---|---|
| `moku-general-hosei.csv`、`moku-special-hosei.csv` | 補正予算の科目別内訳（`…21001`、`…22001`） | 成立予算額、補正追加額、補正修正減少額、補正差引額、改予算額（**千円**。成立予算額は累計の基準額で、当初予算の額に足してはいけない） | 2023、2024、2025、2026（2026 は一般会計のみ。特別会計は CSV がなく PDF のみ） |
| `moku-general-kessan.csv`、`moku-special-kessan.csv` | 決算の科目別内訳（`…77001`、`…78001`） | 歳出予算額、前年度繰越額、予備費使用額、（特別会計のみ）予算総則の規定による経費増額、流用等増△減額、予算決定後移替増△減額、歳出予算現額、支出済歳出額、翌年度繰越額、不用額（**円**） | 2023、2024（決算は年度が締まってから公開される） |

- 原本の列の恒等式は全件で成立（補正: 改予算額＝成立予算額＋差引額、差引額＝追加額＋修正減少額。決算: 歳出予算現額＝歳出予算額＋繰越等、不用額＝現額−支出済−翌年度繰越）。
- 決算の識別列は `目別分類コード` の代わりに `目番号` を持つ。2025 の特別会計の補正予算は、款コード・項コード・目コード（特別会計予算の款項目）の体系で、当初予算の目とは識別列が違う。
- 事項（jikou）は当初予算の XML だけ。補正・決算の XML はアーカイブにない。
- 作り方: `npx tsx scripts/pipeline-v2/build-mof-archive-hosei-kessan-csv.ts <hosei|kessan> <year> <out-dir>`（入力の zip の SHA-256 を固定。凍結値と違えば停止）。

## 列の読み方

- 金額はすべて**千円のまま**（円換算しない）。`△` は負（`-` で出力）。空欄は 0 ではない（前年度の列がない勘定は空欄）。
- 年度の文字は列名に入る（`令和6年度` / `令和7年度`）。一般会計の事項・項・目は `要求額`、特別会計は `予定額`。公式 CSV 由来の列名は元の表記のまま（例: 提出時の項は `…要求額の合計` で `(千円)` なし）。
- `jikou-*`: `source_file` `source_row` `source_page` で XML の行に戻れる。説明欄は含めない。
- `jikou-special`: `組織` は復興庁（東日本大震災復興）の 1 ファイルだけ埋まる。そのファイルでは `所管` はファイル内の所管の行（復興庁・総務省・財務省）で、公式 CSV の `共管所管名`・`共管組織名` と同じ組になる。他は目次の所管。
- `jikou-general`: `主要経費別分類コード` は 2 桁のコードで、意味は付けていない。

## 作り方

入力はすべて `data/download/mof.go.jp/archive/`（取得は `scripts/pipeline-v2/download-mof-archive.ts`）。出力は再生成して正の CSV とバイト単位で一致する。

```bash
# <version> は 2023 | 2024 | 2025 | 2025_teishutsu | 2026（事項の builder は特別会計・一般会計とも同じ）
# 項・目（公式 CSV から）
npx tsx scripts/pipeline-v2/build-mof-archive-kou-moku-csv.ts <version> <out-dir>
# 事項（一般会計／特別会計）
npx tsx scripts/pipeline-v2/build-mof-jikou-csv.ts <version> <out-dir>
npx tsx scripts/pipeline-v2/build-mof-jikou-special-csv.ts <version> <out-dir>
```

事項の parser は `scripts/pipeline-v2/lib/` にある。
- 一般会計: `mof-budget-xml-items.ts`（FY2024 専用。評価 artifact の source hash で固定されているため変更しない）と、その複製に帳票ごとの値（帳票 ID・DOCTYPE・年度の文字）を渡せるようにした `mof-budget-xml-items-general.ts`。
- 特別会計: `mof-budget-xml-special-items.ts`。
- 入力境界は凍結した source set（XML の SHA-256 の一覧）。FY2024 の一般会計は `tests/fixtures/mof-budget-xml-parser-v0/2024/`、それ以外は `tests/fixtures/mof-xml-parser-general/`・`mof-xml-parser-special/`。想定外の構造は例外にし、silent skip しない。

### 特別会計 parser の行の文法

`歳出事項別内訳` のデータ行を、列の集合の完全一致で受理する（`1.4` / `3.2` は `1.1` / `3.1` の列位置の変種）。

| 行の種類 | 列の集合 |
|---|---|
| 項の開始行 | `{1.1\|1.4, 2.1, 3.1\|3.2, 4.1, 5.1, 7.1, 9.1, 11.1}`（項コード・項名・分類コード・事項名・予定額・前年度・比較増△減額・説明） |
| 事項の続き行 | `{3.1\|3.2, 4.1, 5.1, 7.1, 9.1, 11.1}` |
| 説明の続き行 | `{11.1}`（数えるだけ） |
| 所管・組織の行 | `{1.1}`、`{1.3}`、`{1.3, 5.1, 7.1, 9.1}`（復興庁のファイルだけ。header が `所管・組織・項`） |
| 前年度なしの項の開始行 | `{1.1, 2.1, 3.1, 4.1, 5.1, 7.1}`（新勘定のファイルだけ。`7.1` は説明） |

- 説明欄（`11.1`）は読まない。入れ子の表（食糧管理勘定）は無視し、後ろの行まで読む。
- 前年度の列がない行は、前年度・比較増△減額を空欄にする（0 にしない）。
- 上記以外の列の集合・header は例外で止める。所管・特別会計・勘定は、目次の祖先 chain（`…所管 > {特別会計} > 甲号歳入歳出予定計算書 > ({勘定}) > 歳出 事項別内訳`）から取る。
