# 概算要求の年度推移 CSV（項の粒度, FY2023〜FY2027）

概算要求の項を、年度をまたいで並べるための 1 本の CSV。MOF の予算書との突合は参考情報で、キーにも出力の有無にも使わない。

```bash
npx tsx scripts/pipeline-v2/build-budget-request-trend-csv.ts   # → tests/fixtures/budget-request-trend/{kou.csv,summary.json}
```

- 入力: `tests/fixtures/mof-budget-request-match/{2023,2024,2025,2026}/request-kou.csv`（概算要求の TOC・総表の木だけから決めた項の所属と金額。`build-mof-budget-request-match.ts` が出す）と同 `m1-kou.csv`（突合の状態）、`tests/fixtures/budget-request-csv/{年度}/cover/sources/*.csv`（表紙の所管コード）。
- FY2027 は MOF の令和9年度版が無いため、`mof-budget-request-match/2027/` には `request-kou.csv` だけを置く（`build-mof-budget-request-match.ts 2027 2026 <dir>` を実行し、`request-kou.csv` だけを残す。他の出力は MOF 令和8年度を辞書にした参考にならない値なので置かない）。`MOF突合(参考)` は空。

## 列

| 列 | 内容 |
|---|---|
| `年度` | 概算要求の年度（西暦） |
| `会計区分` | 一般 / 特別 |
| `所管コード` | 表紙の見出しのコード（例: `19` 内閣府、`9905` エネルギー対策特別会計） |
| `所管` | 一般会計の所管名（目次の見出しから）。特別会計は空 |
| `特別会計` `勘定` | 特別会計の名称と勘定（一般会計は空） |
| `組織` `組織の出所` | 組織名と、その出所（`目次` / `総表` / `表紙括弧` / `なし`） |
| `項名` `項コード` | 項の名称（空白を除く）とコード（組織内の連番で、キーにしない） |
| `前年度予算額_千円` `要求額_千円` `増減_千円` | 総表の値。増減は要求額 − 前年度予算額（総表の値ではなく差を計算） |
| `要求書` `頁` `PDF頁` `階層` | 出所（source の slug、TOC 上の頁＝紙面の印字、PDF の通し頁、`toc` / `position`）。`PDF頁` は明細表の各行の `頁` と `source_page` の対応から引く（`4復興特` のような接頭辞・接尾辞つきも一致させる）。明細表が無い要求書（内閣府の一部、文科省の一部、国家安全保障局など）と、対応が取れない頁は空で、UI のリンクは PDF の先頭を開く（取れた割合は各年度の約 80%）。UI のリンクは `#page=<PDF頁>` |
| `複数書` | 同じキーが同じ年度に複数の要求書にある行は 1（一覧の「複数書」バッジ）。CSV では要求書ごとに別の行で、どの行にも 1 が付く |
| `金額不一致` | `複数書` のうち、要求額か前年度の額が行によって異なるものは 1 |
| `MOF突合(参考)` | `m1-kou.csv` の status（FY2027 は空） |

キー（年度ごとに）: `会計区分 + 所管コード + 特別会計 + 勘定 + 組織 + 項名`。コードは組織内の連番でキーにならない。ただし同じ要求書の中で同名の別の項（例: 厚生労働調査研究等推進費の 087 / 405、国交省の情報化推進費の 642 / 800）が同じキーになるときは、そのキーを全年度で `項コード` つきの別の行にする（UI の `kou`）。名称の変更・統廃合の紐づけは、このCSVの範囲外（別のロジック）。

## 方針

- **組織**: 目次があれば目次の見出し。目次を持たない要求書は、総表で「組織計」（TOTAL）の後ろ（表の始め）にある CODE3 の行のうち、次の行も CODE3 のものを組織の見出しとする（項には明細が続く）。それでも決まらない行は、表紙の括弧内の組織で補う。
- **会計・所管・特別会計名が明細表の CONTEXT 行から決まらない行**（FY2023 の金融庁・個人情報保護委員会、FY2027 の総務省冊子の復興特会 3 行など）は、表紙の見出しで補う（コード 2 桁は一般会計の所管、4 桁は特別会計）。
- **複数の府省の要求書に載る特別会計の項は按分しない。** 同じ特別会計の項が複数の府省の要求書に載り、額が同じ（総額が各書に載る）。CSV では要求書ごとに行を残し、`複数書` を付ける。所管をまたいで合計すると二重になる。UI では同じキーを 1 行にまとめる。
- **例外: 東日本大震災復興特別会計は各書が自分の取り分だけを載せ、復興庁の書が合計を載せる**（例: FY2026 東日本大震災復興事業費の要求額は 国交省 22,381,339 ＋ 復興庁 4,054,000 ＝ 復興庁全体書 26,435,339）。これが `金額不一致` の主な原因。UI では同じキーで額が違うときは最も大きい額の書（合計書）の額を表示し、各書の額は詳細の PDF の横に出す。
- 検算（要求額 − 前年度 = 増減）は総表の値では行わない。増減は差を計算した値。
- 単位は千円。事項要求（金額を持たない要求）は、項に金額がある限りこの CSV の対象外ではない。金額が無い行は空。

## UI（`/budget-request-trend`、URL 直打ち）

- データ: 同じスクリプトが `public/data/v2/ui/budget-request-trend/kou.json.gz`（キー単位に束ね、元の PDF の URL を持つ。型は `types/budget-request-trend.ts`）を出し、ページがブラウザから静的ファイルとして直接取得する（Vercel の関数には `public/data` を同梱しないため、API を経由しない。他の v2 データと同じ方式）。
- 画面: 左がフィルタ、中が選択年度の一覧（所管・組織・項名・前年度予算額・要求額・増減・増減率）、右が選んだ項の全年度分の表・棒グラフ・元の PDF へのリンク。
- 金額は `client/lib/formatBudget.ts` の `formatBudgetShort` と同じ桁数（/sankey-svg に合わせる）で、円・万円・億円・兆円に自動で切り替える。
- 増減・増減率は、その年度の要求額 − 前年度予算額（その年度の要求書が載せる値どうし）。新規・消滅は前年度のキーとの比較。名称変更の紐づけはしない。
- 絞り込み・並べ替えは `app/lib/budget-request-trend.ts`（純粋関数）。
- 要求書の公開元（PDF のドメイン → 府省庁名、`publisherOf`）は、キーに使わず表示だけに使う。詳細の PDF リンクに府省名を付け、一覧の「複数書」バッジのツールチップに載っている府省を出す。特別会計の共管（どの府省の書にも載る）や、復興特会の各省の取り分の内訳を追うため。
