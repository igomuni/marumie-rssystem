# 概算要求の「金額を示さない要求」（事項要求など）の候補

概算要求書のうち、金額をすべては示していない要求の候補を、項の単位で拾う。FY2023〜2027 が対象。

```bash
npx tsx scripts/pipeline-v2/build-budget-request-jikou-youkyu.ts   # → tests/fixtures/budget-request-jikou-youkyu/{kou.csv,marks.csv,summary.json}
```

## 入力

| 入力 | 使い方 |
|---|---|
| `tests/fixtures/budget-request-trend/kou.csv` | 項の一覧、前年度予算額、要求額 |
| `tests/fixtures/budget-request-csv/{year}/detail-table/sources/*.csv` | 明細表の行の位置（`source_line_start`）と目の名前 |
| `data/work/budget-request-plain-text/{year}/*.txt` | 備考の文字（明細表 CSV は備考を持たない） |
| `tests/fixtures/mof-budget-request-match/{year}/m1-kou.csv` | MOF の当初額と突合の状態（参考。FY2027 は無い） |

## 形

1 つの項が複数の形を持つことがある。`形` 列では `;` で区切る。

| 形 | 条件 |
|---|---|
| `印` | 項の範囲の中に「（事項要求）」がある。空白を除いて照合し、括弧は全角でも半角でもよい。 |
| `文` | 項の範囲の中に、印以外の「事項要求」の言及がある（例: 「…財源の確保については、事項要求とする」）。 |
| `要求0` | 前年度予算額が正で、要求額が 0。 |
| `要求0・場所ごと` | `要求0` のうち、同じ場所の項がすべて要求額 0 のもの。場所は、特別会計なら特別会計＋勘定、一般会計なら所管＋組織。条件は、項が 2 つ以上あり、前年度の合計が正であること（例: FY2026 の先端半導体・人工知能関連技術勘定）。 |
| `一括計上` | 次をすべて満たす項（例: 国際観光旅客税財源観光振興推進費）。 |

`一括計上` の条件:

- 目が括弧書きのものだけである。
- 前年度予算額が 0 で、要求額が正。
- 予算書に同じ項がない（MOF 突合の状態が `NO_CANDIDATE`）。MOF の無い年度は、この条件を問わない。
- 予備費・予備経費ではない。

**項の範囲**

- 範囲は、明細表 CSV の項の行（`CODE3`）から、次の項の行までとする。
- **項の行と見なすのは、年度推移 CSV にある項だけ。** キーは、書（分冊の連番を除いた slug）＋項コード＋項名。内閣府などは、事項にも 3 桁のコードが付くため。
- **組織の見出し:** 直後の行が項の行である `CODE3`。
- **特別会計・勘定の行（`CODE2` / `CODE1`）で範囲を区切るのは、直前の見出し（`CONTEXT`）が特別会計の書だけ。** 一般会計の書では、2 桁・1 桁の行は事項の番号になる（例: 文部科学省の「02 産業教育総合推進事業」）。

**「事項要求」の出現を行に結びつける規則**

- 同じ頁で直前（12 行以内）にある明細表の行に結びつける。
- その行が項の範囲にあれば、その項の出現とする。
- 組織の行に付いたものと、行に結びつかないものは、`marks.csv` にだけ出す。後者は、明細表以外の説明の頁や、事項名の中の括弧書きなど。

## 出力

**`kou.csv`**（形を 1 つ以上持つ項。同じ項が複数の書に載るときは 1 行）

| 列 | 内容 |
|---|---|
| 年度・会計区分・所管・特別会計・勘定・組織・項名・項コード | 項の識別 |
| 前年度予算額_千円・要求額_千円 | 年度推移 CSV の値 |
| `MOF当初額_千円(参考)` | m1-kou.csv の MATCHED / NEAR_NAME の MOF の額 |
| `MOFとの比較(参考)` | `当初>要求` / `当初=要求` / `当初<要求` / `MOFに対応なし`。FY2027 は空。 |
| 形 | 上の表の形 |
| 印の行の階層 | 「事項要求」が付いた行の階層（項・事項・目など） |
| 根拠の行 | 最初の出現の行の本文 |
| 要求書・頁・PDF頁 | 要求書は、載っている書を空白で区切る |

**`marks.csv`:** 「事項要求」の出現ごとに 1 行。列は、年度、要求書、PDF 頁（plain text の頁）、行、種類（印・文）、階層、行の名前、項名（結びついた項）、本文。

**`summary.json`:** 年度ごとの出現数、項に結びついた数、組織の行の数、結びつかない数、形ごとの項の数。

## 注意

- **候補であって、事項要求と確定したものではない。**
  - `要求0` には、施設費の終了のように予算でも 0 のものが含まれる。`MOFとの比較(参考)` が `当初=要求` の項がそれにあたる。
  - `印` の項でも、事項要求はその項の一部にすぎない。項の額の大部分は、金額で要求されている。
- **MOF の当初額は、突合（名前と所属）の結果をそのまま使う。** 所属の組織が分からない書では、同名の項の MOF の額が入ることがある（例: 外務省の在外公館の項に、外務本省の額が入る）。
