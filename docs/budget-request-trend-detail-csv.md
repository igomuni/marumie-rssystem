# 概算要求の事項・目の年度推移 CSV（FY2023〜FY2027）

項の年度推移 CSV（[budget-request-trend-csv.md](budget-request-trend-csv.md)）の各項の下に、事項と目を並べる。要求側だけで作り、MOF の予算書はキーにも出力の有無にも使わない。検算（項 = Σ事項 = Σ目）は状態として記録するだけで、値は書き換えない。

```bash
npx tsx scripts/pipeline-v2/build-budget-request-trend-detail-csv.ts   # → tests/fixtures/budget-request-trend/{jikou.csv, moku/{年度}.csv, detail-summary.json}
```

- 入力:
  - `tests/fixtures/budget-request-trend/kou.csv`（項。キーの列をここから取る。先に `build-budget-request-trend-csv.ts` を実行する）
  - `tests/fixtures/mof-budget-request-match/{年度}/request-kou.csv`（項の一覧。`kou.csv` の各年度の行と同じ順で、一致しなければ止まる）
  - `tests/fixtures/budget-request-csv/{年度}/total-table/sources/*.csv`（総表。事項の額）
  - `tests/fixtures/budget-request-csv/{年度}/detail-table/sources/*.csv` と `unresolved.csv`（明細表。事項・目）
  - `data/work/budget-request-plain-text/{年度}/*.txt`（不一致の分類だけに使う。文字層の無い頁、明細表の CSV の無い PDF）
- 実装: `scripts/pipeline-v2/lib/budget-request-detail-tree.ts`（pure、テストあり）、`scripts/pipeline-v2/build-budget-request-trend-detail-csv.ts`（runner）

## 要求書の階層

```text
CODE3         010 事務取扱費                    ← 項（項の一覧と、コード + 名前で照合できるもの）
DETAIL    1   01‑95 事務取扱いに必要な経費      ← 事項（要求番号つき）
CODE3         001 既定定員に伴う経費            ← 事項の下の見出し（範囲を変えない）
CODE_5_4_2_4  95016‑2111‑02‑0000 職員基本給     ← 目
CODE_NN_NNNN  02‑0100 職員俸給                  ← 目の細分
```

## 項の範囲

1. **書（分冊を含む）ごとに項の一覧を作る。** 書は、slug から日付と末尾の連番を除いたもの（`kou.csv` の `PDF頁` の照合と同じ）。目次・総表の PDF と明細表の PDF が分かれた書（内閣府の組織別の分冊、文科省など）も、同じ書として項を探す。一覧の順は、書の中の source の順、source の中は目次の順。
2. **ファイルごとに行を順に読む。** `CODE3` の行で、コード + 名前が一覧の中で前に照合した項より後ろにあれば、その項の範囲を始める。
   - 組織と項が同じ名前の機関（衆議院・会計検査院など）は、組織の行の直後に同じコード・名前の項の行が続く。後の行を項とする。
3. **一覧に無い項:** `CODE3` で次の行が事項（`DETAIL`）のもので、次のすべてを満たすものは、一覧に無い項（目次に無い項）として範囲を切る。その下の事項・目は出力しない（`detail-summary.json` に件数と項を記録）。
   - 範囲の外か、今の項よりコードが大きい（項コードは組織の中で増える。コードの小さい見出しは事項の下の見出し）。
   - 次の事項が、目次で今の項の事項になっていない（例: 人事院の「026 諸外国との人事交流及び意見交換に要する経費」は事項の下の見出しで、次の事項は目次で人事院の項の事項）。
4. **それ以外の `CODE3`** は事項の下の見出しで、範囲を変えない。`CONTEXT` の行で範囲を閉じる。
5. 事項は範囲の中の `DETAIL` の行。目は、事項の行から次の事項・項までの `CODE_5_4_2_4` の行（事項の行より前の目は、事項名を空にして出す）。

## 事項（`jikou.csv`）

1 行 = 年度 × 項（要求書ごと）× 事項。

- **額は総表の値**（`前年度予算額_計`・`概算要求額_計`）。明細表の事項の行は額が空欄のことが多い（額は下の目にある）。
- **総表と明細表の事項を事項名で結ぶ。** 同じ項に同名の事項が複数あるときだけ要求番号で絞る。内閣府の分冊は、明細表の要求番号が PDF ごとに 1 から振り直されるため、要求番号では結べない。
- 明細表にだけある事項も出す（`検算` = `事項の額なし`）。

| 列 | 内容 |
|---|---|
| `年度` 〜 `項コード` | `kou.csv` と同じ（項のキーの列） |
| `要求番号` `事項コード` `事項名` | 総表（無ければ明細表）の値。事項コードは `NN-NN`（後半は主要経費の分類） |
| `前年度予算額_千円` `要求額_千円` | 総表の値 |
| `目の要求額の合計_千円` `目の行数` | 事項の下の目の行の要求額の合計と行数 |
| `細分の合計を使った目` `目の額の空き` | 下の「目の額」を参照 |
| `検算` | `一致` / `不一致` / `額の空きあり` / `目なし` / `画像の頁`（項の頁が画像で目が取れない）/ `事項の額なし` |
| `要求書` `PDF頁` | 事項の行がある明細表の PDF と頁（`source_page`） |

## 目（`moku/{年度}.csv`）

1 行 = 年度 × 項 × 事項 × 目。同じ事項の中で、事項の下の見出しをまたいで、同じ目（主要経費・目的別 5 桁 + 目別 2 桁 + 目名）を足す。目の細分は出さない。

- **目の額:** 目の行の額。目の行が空欄で、すぐ下の細分（`CODE_NN_NNNN`）に額があるときは、細分の合計を使い、`細分の合計を使った行` に数える（目の行に額があるときは、細分は内訳なので足さない）。どちらも無い行は `額の空き` に数える。
- `目コード(原文)` は、明細表のコードを `-` でつないだもの（中央の桁が欠けた形もそのまま。複数の形は「、」区切り）。

**年度をまたぐキー:** 事項は「項のキー + 事項名」、目は「項のキー + 事項名 + 目名 + 目別 2 桁」。事項コードの前半（事項の番号）と目の末尾 4 桁はキーにしない。前年度にも同じキーがある割合は、事項が 91〜95%、目が 91〜95%（FY2024〜FY2027）。

**項 = Σ目 の不一致の分類**（`kou_ne_moku_by_reason`。上から順に当てはめる）

| 分類 | 内容 | FY2023 | FY2024 | FY2025 | FY2026 | FY2027 |
|---|---|---:|---:|---:|---:|---:|
| `位置で決めた項（目次なし）` | 項の一覧が目次ではなく総表・明細表の並びから作られた書 | 2 | 2 | 2 | 3 | 3 |
| `組織と同名の項（項の額が組織計）` | 衆議院・会計検査院のように、組織の行の直後に同じ見出しの項の行がある項（項の額の取り違えは直したので、今は 0） | 0 | 0 | 0 | 0 | 0 |
| `明細表の未解決の行あり` | 項の明細表の PDF に、列の決まらない行（`unresolved.csv`）がある | 11 | 10 | 3 | 3 | 0 |
| `画像の頁あり` | 項の明細表の頁の範囲に、文字層の無い頁がある | 0 | 0 | 0 | 1 | 4 |
| `明細表の無い分冊あり` | 同じ書に、plain text はあるが明細表の CSV の無い PDF がある | 1 | 0 | 0 | 0 | 1 |
| `未分類` | 上のどれでもない | 1 | 1 | 1 | 1 | 0 |

未分類は各年度 0〜1 件（FY2023 カジノ管理委員会、FY2024 個人情報保護委員会、FY2025 公安調査庁共通費、FY2026 財務本省共通費）。

**項に結びつかない目**（`orphan_moku`）: 一覧に無い項の下の目（年 0〜25 行）と、ファイルの最初の項より前の目（FY2027 の 14 行）だけ。書に項が 1 つも無い目、`CONTEXT` の後の目は、全年度で 0。

**一覧に無い項**（`unlisted_kou`）: 項の見出しの形で、項の一覧（`request-kou.csv`）に無いもの。目次から漏れた項は総表から補う（`docs/mof-budget-request-match.md`）ので、残りは FY2025〜FY2027 の内閣府の分冊の「内閣本府施設費」（総表に無く、明細表だけにある）各 1 件。
