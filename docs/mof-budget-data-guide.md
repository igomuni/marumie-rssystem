# 財務省 予算書データ（MOF）ガイド

財務省「予算書・決算書データベース」（[bb.mof.go.jp](https://www.bb.mof.go.jp/)）から取得した予算データの構造リファレンス。
`data/download/mof_YYYY/` の CSV と、CSV に含まれない Web 上の帳票の両方を扱う。

RS システム側のデータ範囲は `rs-data-scope.md`、パイプライン全体の流れは `data-pipeline-guide.md` を参照。

---

## 1. 取得元とファイル命名

年度別のアーカイブページ（例: `https://www.bb.mof.go.jp/archive/reiwa8.html`）から ZIP / XLSX を取得する。

```text
DL{西暦4桁}{区分2桁}{連番3桁}.zip
```

| 区分 | 意味 |
|---|---|
| `11` | 当初予算・一般会計 |
| `12` | 当初予算・特別会計 |
| `13` | 当初予算・政府関係機関 |
| `21` | 補正予算・一般会計 |
| `22` | 補正予算・特別会計 |
| `31`〜`33` | 暫定予算 |
| `76`〜`78` | 決算 |

西暦は**会計年度**（令和8年度 = `2026`）。ZIP を展開すると `…a.csv` と `…b.csv` の2本が出る。

| ファイル | 一般会計（`11`） | 特別会計（`12`） |
|---|---|---|
| `a` | 歳入予算部款項目別表 | 歳入予定額科目別表 |
| `b` | 歳出予定経費要求書 科目別内訳 | 歳入歳出予定額科目別表（歳出） |

ローカルの配置は `data/download/mof_{西暦}/`（`mof_2021` 〜 `mof_2024`、`mof_2026`）。

## 2. CSV の列構造

### 2-1. 一般会計 歳入 `DL{YYYY}11001a.csv`

```text
主管,部コード,款コード,項コード,目コード,部名,款名,項名,目名,
{元号}{N}年度予算額(千円),前年度予算額(千円),比較増△減額(千円)
```

歳入は「主管 > 部 > 款 > 項 > 目」の5階層。令和8年度で430行。

### 2-2. 一般会計 歳出 `DL{YYYY}11001b.csv` ← 主に使うのはこれ

```text
所管,組織,項コード,主要経費別分類コード,目的別分類コード,
財政法公債金対象非対象別分類コード,経済性質別分類コード,使途別分類コード,目別分類コード,
項名,目名,{元号}{N}年度要求額(千円),前年度予算額(千円),比較増△減額(千円)
```

| 列 | 型 | 説明 |
|---|---|---|
| `所管` | 名称 | 皇室費・国会・裁判所・各省。19種 |
| `組織` | 名称 | 所管の下の組織（内閣本府、資源エネルギー庁 等）。令和8年度で96種 |
| `項コード` | 3桁 | 組織内での連番。**組織をまたぐと重複する**ので単独ではキーにならない |
| `主要経費別分類コード` | 2桁 | 社会保障関係費・公共事業関係費 等（§4-2） |
| `目的別分類コード` | 3桁 | 国家機関費・社会保障関係費 等（§4-3） |
| `財政法公債金対象非対象別分類コード` | 1桁 | 建設公債の対象か否か（§4-4） |
| `経済性質別分類コード` | 2桁 | SNA 準拠の経済的性質（§4-5） |
| `使途別分類コード` | 1桁 | 人件費・旅費・物件費 等（§4-6） |
| `目別分類コード` | 2桁 | 職員基本給・庁費の類 等（§4-7） |
| `項名` | 名称 | 例「内閣本府共通費」 |
| `目名` | 名称 | 例「職員基本給」「庁費」 |
| 金額3列 | 整数 | **千円単位**。マイナスは半角 `-` |

1行 = 所管×組織×項×目。令和8年度で6,790行・122.3兆円。

### 2-3. 特別会計 歳入 `DL{YYYY}12001a.csv`

```text
所管,特別会計,勘定,款コード,項コード,目コード,款名,項名,目名,
{元号}{N}年度予定額(千円),前年度予算額(千円),比較増△減額(千円)
```

款名が `他会計より受入` の行が**会計間の資金移動の受け手側**。一般会計からの繰入はここで捕捉する。

### 2-4. 特別会計 歳出 `DL{YYYY}12001b.csv`

```text
所管,特別会計,勘定,項コード,主要経費別分類コード,目的別分類コード,
経済性質別分類コード,使途別分類コード,目別分類コード,共管所管名,共管組織名,
項名,目名,{元号}{N}年度予定額(千円),前年度予算額(千円),比較増△減額(千円)
```

一般会計版との差:

- `組織` の代わりに `特別会計` + `勘定`（勘定を持たない会計は空文字）
- `財政法公債金対象非対象別分類コード` が**無い**
- `共管所管名` / `共管組織名` が**ある**（特会は複数省庁の共管が普通のため）

令和8年度で1,239行・14会計・34勘定・441.7兆円。

### 2-5. 年次で列名が揺れる（重要）

金額列の名前は年度で変わる。令和6年度は `(千円)` が付かない。

```text
令和6年度: 令和6年度要求額      , 前年度予算額(千円) , 比較増△減額(千円)
令和8年度: 令和8年度要求額(千円) , 前年度予算額(千円) , 比較増△減額(千円)
```

パーサは列名の完全一致で拾わず、**列位置**または `令和\d+年度(要求額|予定額|予算額)` の正規表現で解決すること。

## 3. CSV に含まれないもの

ZIP に入るのは**科目別（目レベル）の表だけ**。Web の帳票にはさらに以下がある。

| 帳票 | `title_for_list` | 粒度 |
|---|---|---|
| 一般会計の事項別内訳 | `〔組織別事項別内訳〕` | 組織 > 項 > **事項** |
| 特別会計の事項別内訳 | `歳出 事項別内訳` | 特会 > 勘定 > 項 > **事項** |
| 政府関係機関の事項別内訳 | `支出 事項別内訳` | 機関 > 業務 > 項 > **事項** |
| 歳入 各目の見積の事由及び計算の基礎（特会） | — | 款 > 項 > 目 + 算定根拠 |

**事項**（例「拉致被害者等の支援に必要な経費」）は MOF 側で唯一「事業らしい」粒度で、`説明` 欄に所掌事務と根拠法の記述を持つ。

### 3-1. 取得済みデータセット

事項は `npm run generate-mof-jikou` で JSON 化してある（`public/data/mof-jikou-{YEAR}.json`、
型は `types/mof-jikou.ts`、API は `/api/mof-jikou`、確認用 UI は `/mof-jikou`）。

令和8年度で取り込んでいるのは8帳票・2,685事項。**各帳票の合計は同年度の CSV と1円単位で一致する**。

> **単位**: 予算書の印字は千円単位だが、JSON はリポジトリ全体の金額規約に合わせて
> 円単位（生成時に1000倍）で持つ。下表は CSV と直接比較できるよう千円のまま示している。

| 帳票ID | 内容 | ページ | 事項 | 合計（千円） |
|---|---|---|---|---|
| `202611001` | 一般会計・当初予算 | 96 | 1,303 | 122,309,247,035 |
| `202612001` | 特別会計・当初予算 | 34 | 361 | 441,726,012,445 |
| `202613001` | 政府関係機関・当初予算 | 9 | 48 | 4,717,101,130 |
| `202631001` | 一般会計・暫定予算 | 95 | 777 | 8,564,101,351 |
| `202632001` | 特別会計・暫定予算 | 32 | 166 | 29,814,160,948 |
| `202633001` | 政府関係機関・暫定予算 | 9 | 27 | 42,687,789 |
| `202621001` | 一般会計・補正予算第1号 | 2 | 3 | 3,113,504,625（差引額） |
| `202622001` | 特別会計・補正予算特第1号 | 0 | 0 | — |

補正の特別会計（`202622001`）は国債整理基金の残高表しか無く、事項別内訳が存在しない。

**事項に公式なIDは無い**。JSON では2種類のキーを持たせている。

- `id` — 掲載位置ベース（`{会計区分}-{帳票ID}-{ページ}-{行}`）。改版でページがずれると変わる
- `key` — 内容ベースの合成キー（会計区分・予算種別・所管・組織・特会・勘定・機関・項コード・事項名）。
  令和8年度の2,685件で重複なし。年度をまたいで同じ事項を追跡するならこちら

### 3-2. Web 帳票の取得方法

各帳票は `https://www.bb.mof.go.jp/server/{YYYY}/html/{DOC}Main.html` のフレームセットで、実体は次の3つ。

| フレーム | ソース | 文字コード |
|---|---|---|
| 目次 | `{DOC}menu.html` | EUC-JP |
| 本文 | `../xml/{DOC}000NNNa.xml` | Shift_JIS |

目次は `LineOut(階層, 子有無, 表題, リンク, 頁)` を並べた JavaScript なので、正規表現で階層付きの帳票一覧を復元できる。
ただし一般会計では事項別内訳ページの目次表題が組織名そのものになっており表題では絞れないうえ、
表題は年度・予算種別によっても揺れる。**帳票の判別は本文 XML の `<title_for_list>` で行うこと**
（目次だけで絞ると乙号継続費要求書などが混入する）。

本文 XML はセルが `<clm id="p{頁}-{行}.{行内連番}-{列}.{列内連番}">` の形を持ち、**`id` をパースするだけで XSL 無しに表を再構成できる**。テキストは `<p><l><![CDATA[…]]></l></p>` で、原文の折り返しごとに `<l>` が分かれるため連結が必要。

> **列ごとに扱いを変えること**: 同じ (頁,行,列) に複数のセルが現れる（折り返し・「うち」書き）。
> テキスト列は連結しないと名前が途中で切れるが、**金額列を連結すると別の金額と繋がって桁が壊れる**
> （実測で合計が750倍になった）。金額は先頭の1件だけを採ること。

### 3-3. 列位置が帳票ごとに違う

列位置は固定値にせず `<header>` の見出しから解決すること。帳票ごとに次の差がある。

| 帳票 | 先頭列 | 主要経費列 | 金額列の見出し | 比較欄 |
|---|---|---|---|---|
| 一般会計 | `組織` あり | あり | `令和N年度` | 前年度予算額・比較増△減額 |
| 特別会計 | `組織` なし（1列左にずれる） | あり | `令和N年度` | 同上 |
| 政府関係機関 | `組織` なし | **なし** | `令和N年度` | 同上 |
| 暫定予算（3会計とも） | 当初と同じ | 当初と同じ | `令和N年度暫定予算` | **なし** |
| 補正予算（一般会計） | `組織・項・事項` が1列 | 兼用 | 下記5本 | 成立予算額 |

要点:

- 金額列の見出しは `令和N年度` の**前方一致**で拾う（暫定は `令和N年度暫定予算`）
- 事項名は「事項」見出しの列にかかる主要経費コードの**1つ右**。ただし政府関係機関には
  主要経費の列が無く、事項名が見出しの列にそのまま入る。**見出し列に2桁コードが並んでいるか**で判別する
- 暫定予算には比較欄が無いので、前年度額・増減額は「0」ではなく「該当なし」として扱う
- 補正予算は表が別物で、組織・項・事項が1列に畳まれ、金額欄が
  `成立予算額` / `補正要求追加額` / `修正減少額` / `差引額` / `改予算額` の5本になる。
  行の種類はコードの桁数で判別する（項コードは3桁ゼロ埋め、主要経費コードは2桁）

> **「説明」欄に別の表が埋め込まれている**: 一部の事項では説明欄に数量の内訳表
> （`種別` / `令和N年度予定(千トン)` / `前年度予算(千トン)` 等）が入っており、
> その行も本体と同じ列番号を使う。素直に「項コードが印字されていたら項を更新」と書くと、
> 数量表の行を項として拾ってしまう（実例: 食料安定供給特別会計 食糧管理勘定 p.348 で
> 項コードが `大麦等`、項名が `172` になった）。
> **項コードが数字であることと、項コード・項名が揃っていることを条件に更新すること。**

## 5. RS システムとの結合

RS 側の `2-2_RS_{YEAR}_予算・執行_予算種別・歳出予算項目.csv` が予算科目を持つ。

```text
シート種別,事業年度,予算事業ID,事業名,…,予算年度,会計区分,会計,勘定,予算種別,
所管,組織・勘定,項,目,歳出予算項目の補足情報,予算額（歳出予算項目ごと）,翌年度要求額（…）,備考
```

### 5-1. 結合キー

| | MOF 側 | RS 側 |
|---|---|---|
| 一般会計 | `所管` / `組織` / `項名` / `目名` | `所管` / `組織・勘定` / `項` / `目` |
| 特別会計 | `特別会計` / `勘定` / `項名` / `目名` | `会計` / `勘定` / `項` / `目` |

正規化の注意:

- RS の `会計` は「エネルギー対策特別会計」、MOF は「エネルギー対策」→ **RS 側から `特別会計` を除去**する
- `勘定` は両者とも「労災勘定」形式。**除去してはいけない**
- 会計の新設・再編があるため（例: 子ども・子育て支援特別会計は令和6年度時点では年金特会内の勘定）、年度をまたぐなら会計名のマッピングが要る

### 5-2. 単位

**MOF は千円、RS の `予算額（歳出予算項目ごと）` は円。**

### 5-3. 年度の対応

RS_{YEAR} のシートは前年度実績を扱うため、`予算年度` 列で選ぶ。RS_2025 なら `予算年度=2024` を使い、MOF 側は `mof_2024`（令和6年度）に揃える。MOF の最新年度（令和8年度）は RS に対応年度が無く、紐づけには使えない。

### 5-4. 結合率（令和6年度・当初予算での実測）

| | MOF キー数 | MOF 総額 | RS キー数 | RS 総額 | 一致キー | MOF 側カバー | RS 側カバー |
|---|---|---|---|---|---|---|---|
| 一般会計 | 6,716 | 112.6兆 | 3,227 | 42.2兆 | 3,223 | 37.4% | 98.2% |
| 特別会計 | 1,225 | 436.0兆 | 573 | 78.9兆 | 559 | 18.0% | 98.9% |

**RS の予算額はほぼ全額が MOF の科目キーの上に載る**（名前ベースの結合で実用に耐える）。逆に MOF 側で RS に対応が無い分は、国債費・地方交付税・特別会計への繰入といった移転的経費と、RS 対象外機関（国会・裁判所・会計検査院・皇室費等）が大半を占める。
