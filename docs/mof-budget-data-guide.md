# 財務省 予算書データ（MOF）ガイド

財務省「予算書・決算書データベース」（[bb.mof.go.jp](https://www.bb.mof.go.jp/)）から取得した予算データの構造リファレンス。
`data/download/mof_YYYY/` の CSV と、CSV に含まれない Web 上の帳票の両方を扱う。

RS システム側のデータ範囲は `rs-data-scope.md`、パイプライン全体の流れは `data-pipeline-guide.md` を参照。

---

## 1. 取得元とファイル命名

年度別のアーカイブページ（例: `https://www.bb.mof.go.jp/archive/reiwa8.html`）から ZIP / XLSX を取得する。

```text
DL{西暦4桁}{区分2桁}{連番3桁}.zip
```

**連番は補正予算の号数**（`21001`=第1号、`21002`=第2号）。号数は会計ごとに独立採番なので、
同じ号数でも会計によって成立した国会が違うことがある（平成23年度の政府関係機関 第2号は
一般会計の第3号と同じ第179回）。年度＋号数だけで会計をまたいで突き合わせないこと。
CSV/Excel が提供されるのは**平成23年度から**で、それ以前は PDF/XML のみ。

| 区分 | 意味 |
|---|---|
| `11` | 当初予算・一般会計 |
| `12` | 当初予算・特別会計 |
| `13` | 当初予算・政府関係機関 |
| `21` | 補正予算・一般会計 |
| `22` | 補正予算・特別会計 |
| `23` | 補正予算・政府関係機関（CSV があるのは平成23年度と令和2年度だけ） |
| `31`〜`33` | 暫定予算（一般会計 / 特別会計 / 政府関係機関） |
| `76` | 決算・政府関係機関 |
| `77` | 決算・一般会計 |
| `78` | 決算・特別会計 |

**同じ年度に予算と決算の2系列がある。**決算はその年度が終わってから公表されるため、
最新年度には予算しか無い（令和7年度は予算のみ、令和6年度は両方）。
決算は単位も列構成も予算と別物なので §2-6 を参照。

### 1-1. 提出版と修正成立版（令和7年度）

国会で修正されて成立した年度は、**同じファイル名のまま置き場が分かれる**。

```text
修正成立版: https://www.bb.mof.go.jp/server/{年度}/csv/DL{帳票ID}.zip
提出版    : https://www.bb.mof.go.jp/server/{年度}_teishutsu/csv/DL{帳票ID}.zip
```

令和7年度では一般会計（`11001`）と特別会計（`12001`）の2帳票が該当し、
一般会計歳出で **3,436.6億円**（予備費 -2,605億、地方交付税交付金 -2,055億、
高等学校等修学支援事業費補助金 +1,054億 ほか）の差がある。
`/server/{年度}/` を見れば修正成立版になる。

西暦は**会計年度**（令和8年度 = `2026`）。ZIP を展開すると `…a.csv` と `…b.csv` の2本が出る。

| ファイル | 一般会計（`11`） | 特別会計（`12`） |
|---|---|---|
| `a` | 歳入予算部款項目別表 | 歳入予定額科目別表 |
| `b` | 歳出予定経費要求書 科目別内訳 | 歳入歳出予定額科目別表（歳出） |

ローカルの配置は `data/download/mof_{西暦}/`（`mof_2021` 〜 `mof_2024`、`mof_2026`）。
**ZIP のまま置き、展開ファイルは残さない**（同じ内容が二重になるため）。
パイプラインからは `scripts/zip-reader.ts` で ZIP 内のエントリを直接読む。

## 2. CSV の列構造

### 2-1. 一般会計 歳入 `DL{YYYY}11001a.csv`

```text
主管,部コード,款コード,項コード,目コード,部名,款名,項名,目名,
{元号}{N}年度予算額(千円),前年度予算額(千円),比較増△減額(千円)
```

歳入は「主管 > 部 > 款 > 項 > 目」の5階層。令和8年度で430行。

### 2-2. 一般会計 歳出 `DL{YYYY}11001b.csv` ← 主に使うのはこれ

```text
所管,組織,項コード,主要経費別分類コード,目的別分類コード,
財政法公債金対象非対象別分類コード,経済性質別分類コード,使途別分類コード,目別分類コード,
項名,目名,{元号}{N}年度要求額(千円),前年度予算額(千円),比較増△減額(千円)
```

| 列 | 型 | 説明 |
|---|---|---|
| `所管` | 名称 | 皇室費・国会・裁判所・各省。19種 |
| `組織` | 名称 | 所管の下の組織（内閣本府、資源エネルギー庁 等）。令和8年度で96種 |
| `項コード` | 3桁 | 組織内での連番。**組織をまたぐと重複する**ので単独ではキーにならない |
| `主要経費別分類コード` | 2桁 | 社会保障関係費・公共事業関係費 等（§4-2） |
| `目的別分類コード` | 3桁 | 国家機関費・社会保障関係費 等（§4-3） |
| `財政法公債金対象非対象別分類コード` | 1桁 | 建設公債の対象か否か（§4-4） |
| `経済性質別分類コード` | 2桁 | SNA 準拠の経済的性質（§4-5） |
| `使途別分類コード` | 1桁 | 人件費・旅費・物件費 等（§4-6） |
| `目別分類コード` | 2桁 | 職員基本給・庁費の類 等（§4-7） |
| `項名` | 名称 | 例「内閣本府共通費」 |
| `目名` | 名称 | 例「職員基本給」「庁費」 |
| 金額3列 | 整数 | **千円単位**。マイナスは半角 `-` |

1行 = 所管×組織×項×目。令和8年度で6,790行・122.3兆円。

### 2-3. 特別会計 歳入 `DL{YYYY}12001a.csv`

```text
所管,特別会計,勘定,款コード,項コード,目コード,款名,項名,目名,
{元号}{N}年度予定額(千円),前年度予算額(千円),比較増△減額(千円)
```

款名が `他会計より受入` の行が会計間の資金移動の受け手側。ただし**款名だけでは足りない**
（年金特会は款 `保険収入` の下に置かれる）。捕捉は款名と目名の和集合で行う。§6-2 を参照。

### 2-4. 特別会計 歳出 `DL{YYYY}12001b.csv`

```text
所管,特別会計,勘定,項コード,主要経費別分類コード,目的別分類コード,
経済性質別分類コード,使途別分類コード,目別分類コード,共管所管名,共管組織名,
項名,目名,{元号}{N}年度予定額(千円),前年度予算額(千円),比較増△減額(千円)
```

一般会計版との差:

- `組織` の代わりに `特別会計` + `勘定`（勘定を持たない会計は空文字）
- `財政法公債金対象非対象別分類コード` が**無い**
- `共管所管名` / `共管組織名` が**ある**（特会は複数省庁の共管が普通のため）

令和8年度で1,239行・14会計・34勘定・441.7兆円。

### 2-5. `a` / `b` の役割が入れ替わっている帳票がある

通常は `a` が歳入形式・`b` が歳出形式だが、全25 ZIP を調べたところ
**令和7年度 補正・特別会計（`DL202522001`）だけ逆**だった。

```text
DL202522001a.csv → 歳出形式（主要経費別分類コードを持つ）
DL202522001b.csv → 歳入形式（款コードを持つ）
```

ファイル名で歳入・歳出を決め打ちしないこと。**ヘッダの列で判定する**
（`主要経費別分類コード` があれば歳出、`款コード` だけなら歳入）。

### 2-6. 決算 CSV は単位も列も別物

**決算は円単位**（予算は千円）。金額列が3本から9本に増え、`目別分類コード` は `目番号` に改称される。

一般会計・歳出決算（`DL{YYYY}77001b.csv`）:

```text
所管,組織,項コード,主要経費別分類コード,目的別分類コード,財政法公債金対象非対象別分類コード,
経済性質別分類コード,使途別分類コード,目番号,項名,目名,
歳出予算額(円),前年度繰越額(円),予備費使用額(円),流用等増△減額(円),予算決定後移替増△減額(円),
歳出予算現額(円),支出済歳出額(円),翌年度繰越額(円),不用額(円)
```

歳入決算（`a`）は `歳入予算額 / 徴収決定済額 / 収納済歳入額 / 不納欠損額 / 収納未済歳入額 / 差` の6本。

この列構成は行政事業レビューの `2-1_予算・執行_サマリ`
（歳出予算現額・執行額・翌年度への繰越し・不用）と**同じ枠組み**で、概念がそのまま対応する。

### 2-7. 年次で列名が揺れる（重要）

金額列の名前は年度で変わる。令和6年度は `(千円)` が付かない。

```text
令和6年度: 令和6年度要求額      , 前年度予算額(千円) , 比較増△減額(千円)
令和8年度: 令和8年度要求額(千円) , 前年度予算額(千円) , 比較増△減額(千円)
```

パーサは列名の完全一致で拾わず、**列位置**または `令和\d+年度(要求額|予定額|予算額)` の正規表現で解決すること。

## 3. CSV に含まれないもの

ZIP に入るのは**科目別（目レベル）の表だけ**。Web の帳票にはさらに以下がある。

| 帳票 | `title_for_list` | 粒度 |
|---|---|---|
| 一般会計の事項別内訳 | `〔組織別事項別内訳〕` | 組織 > 項 > **事項** |
| 特別会計の事項別内訳 | `歳出 事項別内訳` | 特会 > 勘定 > 項 > **事項** |
| 政府関係機関の事項別内訳 | `支出 事項別内訳` | 機関 > 業務 > 項 > **事項** |
| 歳入 各目の見積の事由及び計算の基礎（特会） | — | 款 > 項 > 目 + 算定根拠 |
| **一般会計の歳出決算報告書** | 組織名（判別は下記） | 組織 > 項 > **事項** + 執行額 |

**決算にも事項レベルがある（一般会計のみ）。** 列は
`項 / 事項 / 歳出予算額 / 前年度繰越額 / 予備費使用額 / 流用等増△減額 /
予算決定後移替増△減額 / 歳出予算現額 / 支出済歳出額 / 翌年度繰越額 / 差引額`（すべて円）で、
事項単位に「予算 → 執行 → 不用」まで取れる。事項名は予算書の事項別内訳と同じ表記。
ただし予算書が持つ `説明`（所掌事務・根拠法）は無く、組織単位の `備考` があるだけ。

この帳票は `title_for_list` が組織名になるため判別に使えない。
`running_title` が「内閣府所管　歳出決算報告書　内閣本府」の形になるので、
**`歳出決算報告書` を含むかで判定する**。

> **事項表の見出しは `<header>` に入っていない。** `<header>` にあるのは組織単位の
> 総括表の見出しだけで、事項表の見出し（`項` `事項` `支出済歳出額(円)` …）は本文の行として
> 現れ、しかもページごとに再出現する。見出し行を見つけるたびに列位置を取り直すこと。
> これをやらないと総括表や小計まで拾って総額が2倍以上になる（実測で293兆円）。
>
> **差引額はマイナスになりうる。** 支出済歳出額が歳出予算現額を超える事項が実在する
> （例: 令和6年度 防衛本省「統合幕僚監部の運営に必要な経費」現額89.1億に対し支出済146.1億）。
> 異常値として弾かないこと。

特別会計の決算（`78001`）は勘定ごとの歳入歳出決算・財務諸表・債務計算書で、
事項レベルの歳出決算報告書は**無い**。政府関係機関（`76001`）も収入支出決算のみ。

**事項**（例「拉致被害者等の支援に必要な経費」）は MOF 側で唯一「事業らしい」粒度で、`説明` 欄に所掌事務と根拠法の記述を持つ。

### 3-1. 取得済みデータセット

事項は `npm run generate-mof-jikou` で JSON 化してある
（`public/data/mof-jikou-{YEAR}.json`、型は `types/mof-jikou.ts`、API は `/api/mof-jikou?year=`、
確認用 UI は `/mof-jikou`）。収録は **2017〜2026年度**（平成29〜令和8年度）の10年度分。
JSON 合計 34.3MB / `.gz` 合計 2.91MB。

年度により取り込める帳票が変わる。補正は**成立した号数をすべて取り込む**（第1号〜第4号）。

| 年度 | 当初 | 暫定 | 補正 | 決算 |
|---|---|---|---|---|
| 平成29年度（2017） | ○ | — | 第1号 | ○ |
| 平成30年度（2018） | ○ | — | 第1号・第2号 | ○ |
| 令和元年度（2019） | ○ | — | 第1号 | ○ |
| 令和2年度（2020） | ○ | — | 第1号・第2号・第3号 | ○ |
| 令和3年度（2021） | ○ | — | 第1号 | ○ |
| 令和4年度（2022） | ○ | — | 第1号・第2号 | ○ |
| 令和5年度（2023） | ○ | — | 第1号 | ○ |
| 令和6年度（2024） | ○ | — | 第1号 | ○ |
| 令和7年度（2025） | ○ | — | 第1号 | まだ公表なし |
| 令和8年度（2026） | ○ | ○ | 第1号 | まだ公表なし |

生成物の妥当性は `npm run validate-mof-jikou` で確認する。帳票別の合計を配布 CSV と
突き合わせ、1円でもずれたら失敗する（`scripts/validate-mof-jikou-data.ts`）。
検証には `data/download/mof_{YEAR}/DL{帳票ID}.zip` が要る。無い年度は黙ってスキップされるので、
「OK が並んだ」ではなく末尾の検証項目数を見ること（事項別内訳は10年度で100項目）。

#### 制約1: 補正の号数は第4号まで

帳票IDの連番が補正の号数（`21001`=第1号、`21002`=第2号）で、`DOCUMENTS` は第1号〜第4号を
並べる（`revisedDocuments()`）。上限4号は実績上の最大（平成23年度）に合わせたもので、
それを超える年度が現れたら `MOFRevisionNumber`（`types/mof-jikou.ts`）を広げる。
存在しない号数は 404 になり欠番として飛ぶ。

予算種別は `補正予算（第N号）` として号ごとに分かれる。**号数をまたいで合算しないこと**
（`amount` は改予算額なので、第1号と第2号を足すと二重計上になる）。
その年度の最終的な姿を見るなら最大号数の `amount`、または決算（`77001`）を使う。

**政府関係機関の補正（区分 `23`）は未対応。**10年度分では令和元年度・令和2年度・令和6年度に
帳票があるが取り込んでいない。

#### 制約2: 元号は年度をまたいで混在する

金額列の見出しは `平成29年度要求額(千円)` のように元号年で書かれる。
生成・検証とも `/^(令和|平成)(元|\d+)年度/` で拾う。決め打ちにすると平成年度が静かに0件になる。

**令和元年度（2019）は1年度の中に両元号が現れる。**当初予算は改元前に成立したため
「平成31年度予算」、補正は「令和元年度」表記。`metadata.eraLabel` は `令和元年度`
（`令和1年度` ではない）。

#### 制約3: 配信側は過剰なアクセスを 404 で弾く

429 ではなく **404** が返るため、素直に書くと「帳票なし」と誤認して空の JSON を
正常終了で出力してしまう（実際に2018〜2022が全滅した）。生成スクリプトは 404 のときに
常設ページ `https://www.bb.mof.go.jp/hdocs/bxsselect.html` を引き、
それも失敗すればブロックと判断して中断する。取得間隔は1秒（300ms では数分で弾かれた）。
ブロックは数分で解ける。

### 3-1-1. 識別子 — 事項に公式なIDは無い

**MOF は事項にも項にも「ID」を振っていない。**分類コードをIDと取り違えないこと。

| 列 | 性質 |
|---|---|
| `主要経費別分類コード` ほか4種 | **静的な分類**。令和8年度当初では35種で1,712事項を束ね、最多の `95 その他の事項経費` だけで696事項。識別子ではない |
| `項コード` | 組織内の**連番**。単独では一意にならず（組織をまたぐと重複）、年度をまたぐと動く（下記） |
| 事項名 | **項をまたいで重複する**。`河川整備事業に必要な経費` は令和8年度当初で項353・項083・項086 の3つに存在 |

JSON では2種類のキーを持たせている。

- `id` — 掲載位置ベース（`{会計区分}-{帳票ID}-{ページ}-{行}`）。改版でページがずれると変わる
- `key` — 内容ベースの合成キー（会計区分・予算種別・所管・組織・特会・勘定・機関・項コード・事項名）。
  年度をまたいで同じ事項を追跡するならこちら

年度横断の判定は `app/lib/api/mof-jikou-loader.ts` の `identityKey()`。`key` から予算種別だけを
落とした8要素の**完全一致**で、正規化も曖昧一致もしない（当初と決算を同じ事項として辿るため種別を外す）。
**識別子 × 年度 × 予算種別 の重複は10年度・全種別で0件。**

### 3-1-2. 項コードは同一年度内なら一貫、年度をまたぐと動く

同一年度内では当初・暫定・補正・決算で項コードが振り直されることはない（平成30・令和2・令和8年度で
不一致0件）。一方、**項コードは組織内の連番**なので、項が増減すると以降が総ずれする。

当初予算・10年度・全会計での実測:

| 検査 | 件数 |
|---|---:|
| 組織×項名 の組合せ総数 | 1,496 |
| 項名は同じなのに項コードが変わった | **96件（6.4%）** |
| 同じ項コードが別の項名に再利用された | 164件 |

```text
水産基盤整備費  2017-2020:143 → 2021-2025:141 → 2026:122
```

**年度横断のキーとして項コードを信頼しないこと。**年度推移が途切れる原因は2系統ある。

- **項コードの移動** — 項コードを外すと10年そろう系列が1,065→1,116本、平均追跡年数が6.39→6.78年に伸びる
- **事項名の改称** — 同じ組織×項コードで名前が入れ替わった境界が156件（1対1のもの。分割・統合が52件）

ただし項コードを外すと、上記のとおり同名で複数項に分かれる事項が合算されてしまう。
現状は項コード込みのままで、この制約を承知で使う。

**特別会計の所管名も年度内で変わりうる。**復興特会の所管は共管省庁を全部並べた文字列で、
令和8年度は防災庁の新設により当初と暫定で違う文字列になった。

#### 設計判断: 年度間の名寄せはしない（切断を許容する）

**元データに年度間の対応関係が無い。**MOF の帳票は各年度が独立しており、
「この事項は前年度のどれの続きか」を示す欄が存在しない。したがって対応付けを作るには
事項名や項コードからの**推定**に頼るしかない。

推定では表現しきれない。同じ組織×項コードで系列が入れ替わった境界208件の内訳:

| 型 | 件数 |
|---|---:|
| 1対1（単純な改称） | 156 |
| 1対多（分割） | 13 |
| 多対1（統合） | 20 |
| 多対多（再編） | 19 |

**52件（25%）が1対1でない。**「前年度の事項」を1つ持つ単一参照では足りず、
N対Nの関連が要る。実例:

```text
子ども・子育て支援の財源の年金特別会計…へ繰入れ ＋ 特例給付等の財源の年金特別会計…へ繰入れ
  → 児童手当等の財源の子ども・子育て支援特別会計…へ繰入れ
  ＋ 妊婦のための支援給付事業等の財源の…へ繰入れ
```

2事項が2事項に組み替わっており、どちらがどちらの続きかは一意に決まらない。
制度改正の実態が N 対 N なので、構造が N 対 N でなければ表現できない。

**推定で関連を作ると、元データに無い関係を生成することになる。**予算データで根拠のない
接続を作るのはパイプラインの正確性を損なうため、**現状は切断をそのまま見せる方針とする。**
UI も「計上のない年度は行がありません」と明示する。

この問題は元データ側（MOF が前年度事項への N 対 N 参照を持つ）でしか根本解決しない。
名寄せの実装を検討する場合は、まずこの判断を覆す根拠が要る。

### 3-1-3. 事項は最小単位ではない

同じ項の下に、切り口の違う内訳が**2系統並列**でぶら下がる（入れ子ではない）。

```text
所管 ─ 組織 ─ 項 ┬─ 事項   （事項別内訳。Web帳票のXMLのみ）
                 └─ 目     （科目別内訳。ZIP同梱CSV）
```

令和8年度・一般会計では 項824 / 事項1,303 / 項×目6,790 で、**目が事項の5倍細かい**。
ただし**事項と目の対応表は公表されていない**。目は支出の性質（職員基本給・庁費）、
事項は目的（アイヌ政策の推進に必要な経費）による括りで、切り口が違うため1対1に対応しない。

事項を採用しているのは、MOF側で唯一「事業らしい」名前と `説明` を持つ粒度だから
（令和8年度当初の1,712事項すべてに説明がある）。

### 3-2. Web 帳票の取得方法

各帳票は `https://www.bb.mof.go.jp/server/{YYYY}/html/{DOC}Main.html` のフレームセットで、実体は次の3つ。

| フレーム | ソース | 文字コード |
|---|---|---|
| 目次 | `{DOC}menu.html` | EUC-JP |
| 本文 | `../xml/{DOC}000NNNa.xml` | Shift_JIS |

目次は `LineOut(階層, 子有無, 表題, リンク, 頁)` を並べた JavaScript なので、正規表現で階層付きの帳票一覧を復元できる。
ただし一般会計では事項別内訳ページの目次表題が組織名そのものになっており表題では絞れないうえ、
表題は年度・予算種別によっても揺れる。**帳票の判別は本文 XML の `<title_for_list>` で行うこと**
（目次だけで絞ると乙号継続費要求書などが混入する）。

本文 XML はセルが `<clm id="p{頁}-{行}.{行内連番}-{列}.{列内連番}">` の形を持ち、**`id` をパースするだけで XSL 無しに表を再構成できる**。テキストは `<p><l><![CDATA[…]]></l></p>` で、原文の折り返しごとに `<l>` が分かれるため連結が必要。

> **列ごとに扱いを変えること**: 同じ (頁,行,列) に複数のセルが現れる（折り返し・「うち」書き）。
> テキスト列は連結しないと名前が途中で切れるが、**金額列を連結すると別の金額と繋がって桁が壊れる**
> （実測で合計が750倍になった）。金額は先頭の1件だけを採ること。

### 3-3. 列位置が帳票ごとに違う

列位置は固定値にせず `<header>` の見出しから解決すること。帳票ごとに次の差がある。

| 帳票 | 先頭列 | 主要経費列 | 金額列の見出し | 比較欄 |
|---|---|---|---|---|
| 一般会計 | `組織` あり | あり | `令和N年度` | 前年度予算額・比較増△減額 |
| 特別会計 | `組織` なし（1列左にずれる） | あり | `令和N年度` | 同上 |
| 政府関係機関 | `組織` なし | **なし** | `令和N年度` | 同上 |
| 暫定予算（3会計とも） | 当初と同じ | 当初と同じ | `令和N年度暫定予算` | **なし** |
| 補正予算（一般会計） | `組織・項・事項` が1列 | 兼用 | 下記5本 | 成立予算額 |

要点:

- 金額列の見出しは `令和N年度` の**前方一致**で拾う（暫定は `令和N年度暫定予算`）
- 事項名は「事項」見出しの列にかかる主要経費コードの**1つ右**。ただし政府関係機関には
  主要経費の列が無く、事項名が見出しの列にそのまま入る。**見出し列に2桁コードが並んでいるか**で判別する
- 暫定予算には比較欄が無いので、前年度額・増減額は「0」ではなく「該当なし」として扱う
- 補正予算は表が別物で、組織・項・事項が1列に畳まれ、金額欄が
  `成立予算額` / `補正要求追加額` / `修正減少額` / `差引額` / `改予算額` の5本になる。
  行の種類はコードの桁数で判別する（項コードは3桁ゼロ埋め、主要経費コードは2桁）

> **「説明」欄に別の表が埋め込まれている**: 一部の事項では説明欄に数量の内訳表
> （`種別` / `令和N年度予定(千トン)` / `前年度予算(千トン)` 等）が入っており、
> その行も本体と同じ列番号を使う。素直に「項コードが印字されていたら項を更新」と書くと、
> 数量表の行を項として拾ってしまう（実例: 食料安定供給特別会計 食糧管理勘定 p.348 で
> 項コードが `大麦等`、項名が `172` になった）。
> **項コードが数字であることと、項コード・項名が揃っていることを条件に更新すること。**

## 5. RS システムとの結合

RS 側の `2-2_RS_{YEAR}_予算・執行_予算種別・歳出予算項目.csv` が予算科目を持つ。

```text
シート種別,事業年度,予算事業ID,事業名,…,予算年度,会計区分,会計,勘定,予算種別,
所管,組織・勘定,項,目,歳出予算項目の補足情報,予算額（歳出予算項目ごと）,翌年度要求額（…）,備考
```

### 5-1. 結合キー

| | MOF 側 | RS 側 |
|---|---|---|
| 一般会計 | `所管` / `組織` / `項名` / `目名` | `所管` / `組織・勘定` / `項` / `目` |
| 特別会計 | `特別会計` / `勘定` / `項名` / `目名` | `会計` / `勘定` / `項` / `目` |

正規化の注意:

- RS の `会計` は「エネルギー対策特別会計」、MOF は「エネルギー対策」→ **RS 側から `特別会計` を除去**する
- `勘定` は両者とも「労災勘定」形式。**除去してはいけない**
- 会計の新設・再編があるため（例: 子ども・子育て支援特別会計は令和6年度時点では年金特会内の勘定）、年度をまたぐなら会計名のマッピングが要る

### 5-2. 単位

**MOF は千円、RS の `予算額（歳出予算項目ごと）` は円。**

### 5-3. 年度の対応

RS_{YEAR} のシートは前年度実績を扱うため、`予算年度` 列で選ぶ。RS_2025 なら `予算年度=2024` を使い、MOF 側は `mof_2024`（令和6年度）に揃える。MOF の最新年度（令和8年度）は RS に対応年度が無く、紐づけには使えない。

### 5-4. 結合率（令和6年度・当初予算での実測）

| | MOF キー数 | MOF 総額 | RS キー数 | RS 総額 | 一致キー | MOF 側カバー | RS 側カバー |
|---|---|---|---|---|---|---|---|
| 一般会計 | 6,716 | 112.6兆 | 3,227 | 42.2兆 | 3,223 | 37.4% | 98.2% |
| 特別会計 | 1,225 | 436.0兆 | 573 | 78.9兆 | 559 | 18.0% | 98.9% |

**RS の予算額はほぼ全額が MOF の科目キーの上に載る**（名前ベースの結合で実用に耐える）。逆に MOF 側で RS に対応が無い分は、国債費・地方交付税・特別会計への繰入といった移転的経費と、RS 対象外機関（国会・裁判所・会計検査院・皇室費等）が大半を占める。

## 6. 会計間の繰入（内部振替）

国の予算は**同じ金を会計から会計へ回す**割合が非常に大きい。一般会計・特別会計・政府関係機関の
歳出を単純合計すると、この振替が二重・三重に数えられる。

### 6-1. 送り手側は分類コードで取れる

歳出側は `使途別分類コード = 6`（他会計へ繰入）で機械的に拾える。名前一致は不要。
令和8年度・当初予算の実測:

| 会計 | 歳出 | うち他会計へ繰入 | 比率 |
|---|---:|---:|---:|
| 一般会計 | 122.31兆 | **69.66兆** | **57.0%** |
| 特別会計 | 441.73兆 | 102.14兆 | 23.1% |

**一般会計は歳出の過半が他会計への繰入**で、使う会計というより回す会計になっている。
一般会計の使途別内訳は 繰入57.0% / 補助費・委託費28.4% / 物件費5.4% / 人件費4.0% / 施設費3.3%。

宛先の上位（一般会計から）:

```text
30.79兆  普通国債等償還財源等国債整理基金特別会計へ繰入
20.88兆  交付税及び譲与税配付金特別会計へ繰入
13.13兆  基礎年金年金特別会計へ繰入
 1.53兆  子どものための教育・保育給付等子ども・子育て支援特別会計へ繰入
```

特別会計から（`国債整理基金へ` と `基礎年金勘定へ` が大半）:

```text
56.65兆  国債整理基金特別会計へ繰入
25.83兆  基礎年金勘定へ繰入
13.00兆  財政融資資金へ繰入
```

`目別分類コード = 22`（他会計への繰入）でもほぼ同じ額になる（一般会計で69.61兆）。
どちらを使ってもよいが、使途別のほうが会計をまたいで一貫している。

### 6-2. 受け手側は款名だけでは取りこぼす（重要）

特別会計の歳入側で受入を拾うとき、**款名 `他会計より受入` だけでは足りない。**
年金特別会計は「一般会計より受入」が款 `保険収入` の下に置かれている。

令和8年度の実測:

```text
款名 = 他会計より受入            113.09兆
目名に「一般会計より受入」を含む    66.83兆
款のみ（目名は別表記）             59.64兆
目のみ（款は別表記）★取りこぼし     13.38兆   ← 年金特会
和集合                          126.47兆
```

この取りこぼしは特定年度の事故ではなく**恒常的**。

| 年度 | 款名のみ | 和集合 | 取りこぼし |
|---|---:|---:|---:|
| 平成23（2011） | 104.81兆 | 115.25兆 | 10.45兆 |
| 平成26（2014） | 111.38兆 | 122.11兆 | 10.73兆 |
| 平成30（2018） | 106.27兆 | 117.90兆 | 11.63兆 |
| 令和4（2022） | 112.23兆 | 124.39兆 | 12.16兆 |
| 令和8（2026） | 113.09兆 | 126.47兆 | 13.38兆 |

**捕捉は「款名 = 他会計より受入」または「目名に 一般会計より受入 を含む」の和集合で行うこと。**
実装は `scripts/generate-mof-budget-overview-data.ts` の `isTransferIn()`、
同じ判定を `scripts/validate-mof-budget-overview-data.ts` が持ち、CSV と突き合わせている。

### 6-3. 送受は突き合う

宛先別に送り手と受け手を並べると整合する（令和8年度・単位は兆円）。

| 特別会計 | 一般会計から | 受入計（他会計すべて） |
|---|---:|---:|
| 国債整理基金 | 31.27 | **87.99** |
| 交付税及び譲与税配付金 | 20.92 | 21.17 |
| 年金 | 13.50 | **13.50** |
| 子ども・子育て支援 | 2.72 | 2.61 |
| エネルギー対策 | 0.76 | 0.81 |
| 合計 | 69.66 | 126.47 |

- **年金は完全一致**（1円単位）
- 国債整理基金の差 56.7兆は特別会計からの繰入（56.65兆）とほぼ一致する
- 残差は年度内の他会計間の細かい振替と、貨幣回収準備資金・防衛力強化資金といった
  特別会計以外への繰入（いずれも僅少）

### 6-4. 純計の取り方

```text
一般会計 歳出       122.31
特別会計 歳出       441.73
政府関係機関 支出      4.72
単純合計           568.75
− 他会計より受入    126.47
− 他勘定より受入      1.15
= 一次純計         441.13
```

**これでもまだ大きい。**特別会計歳出441.73兆の**50.9%（224.83兆）が国債整理基金**で、
その大半は借換債の償還（同じ債務を借り換えるための出入り）。実質的な支出規模を見るなら
ここも落とす必要がある。

特別会計の歳出規模（令和8年度）:

| 特別会計 | 歳出 | 構成比 |
|---|---:|---:|
| 国債整理基金 | 224.83兆 | 50.9% |
| 年金 | 102.93兆 | 23.3% |
| 交付税及び譲与税配付金 | 51.07兆 | 11.6% |
| 財政投融資 | 27.44兆 | 6.2% |
| エネルギー対策 | 16.92兆 | 3.8% |
| その他9会計 | 18.54兆 | 4.2% |

### 6-5. 逆方向（特別会計 → 一般会計）は歳出予算に載らない

**逆流は存在するが、§6-1 の方法では捕捉できない。**方向によって計上の仕方が違う。

| 方向 | 送り手側 | 受け手側 |
|---|---|---|
| 一般会計 → 特会 | 歳出に計上（`使途別分類コード=6`） | 特会歳入 款 `他会計より受入` ＋ 目 `一般会計より受入` |
| **特会 → 一般会計** | **歳出にほぼ計上されない** | 一般会計歳入 款 `諸収入` の目 `◯◯特別会計受入金` |

特会歳出側に目名 `一般会計へ繰入` は実在するが、令和8年度で**18勘定あわせて7億円**しかない
（各勘定は数千万〜2億円）。これは事務費相当の精算で、本体ではない。

本体は一般会計の歳入側にある。令和8年度:

| 一般会計 歳入 | 金額 |
|---|---:|
| 諸収入 / 特別会計受入金 / 外国為替資金特別会計受入金 | 2.378兆 |
| 諸収入 / 防衛力強化資金受入 | 1.381兆 ※捕捉対象外 |
| 諸収入 / 防衛力強化特別会計受入金 / 外国為替資金特別会計受入金 | 0.752兆 |
| 諸収入 / 東日本大震災復興エネルギー対策特別会計受入金 | 0.069兆 |
| 回収金等収入 / 社会資本整備事業特別会計整理収入 | 0.047兆 |

**※の行は捕捉対象外。**判定（`isFromSpecialAccount`）は目名が `特別会計受入金` /
`特別会計整理収入` / `特別会計等負担金` で終わるものに限っており、`防衛力強化資金受入` は
特別会計からの受入ではないため入らない。上表の5行を単純に足すと4.627兆になるが、
捕捉されるのはそれを除いた **3.25兆**（下表の令和8年度）。

`◯◯特別会計受入金` 系の合計は年度により1.8〜4.3兆円で推移する。

| 年度 | 合計 | 最大 |
|---|---:|---|
| 平成23（2011） | 4.32兆 | 外国為替資金 2.93兆 |
| 平成26（2014） | 1.86兆 | 外国為替資金 1.59兆 |
| 平成30（2018） | 1.92兆 | 外国為替資金 1.75兆 |
| 令和4（2022） | 1.79兆 | 外国為替資金 1.42兆 |
| 令和8（2026） | 3.25兆 | 外国為替資金 3.13兆 |

**なぜ歳出に載らないか。**繰入の原資は歳出予算ではなく**剰余金**だから。
外国為替資金特別会計の令和8年度は 歳入4.82兆 / 歳出1.97兆 で差し引き2.85兆の剰余があり、
歳出予算には `一般会計へ繰入` の行が（融通証券事務取扱費の僅少分を除いて）無い。
外貨資産の運用益が原資なので、円安局面ほど額が膨らむ。

`社会資本整備事業特別会計整理収入` は**廃止された特別会計の残務処理**（平成25年度に廃止）。
清算に伴う整理収入が今も計上されている。

規模は単純合計568.75兆に対して0.6%程度で純計を大きく動かさないが、
**「繰入は一般会計から特会への一方通行」という理解は誤り**なので注意する。

> **会計をまたいだ単純合算は禁止。**`/api/mof-jikou` の `notes` にも
> 「一般会計・特別会計・政府関係機関の金額を単純合算すると会計間の繰入が二重計上されます」と入れている。
