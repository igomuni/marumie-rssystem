# 統合サンキー実験

## 画面の基準

`/integrated-sankey` は `/sankey-svg/page.tsx` の描画・操作を複製した独立ルート。検索、緑と橙の事業ノード、赤い支出先、TopN、ズーム、パン、詳細パネルを引き継ぐ。既存ページ・共有部品は変更しない。実験中の複製なので、基準ページの変更は自動反映されない。

## 最小モデル

MOF当初予算の全項または選択項のRS結合予算 → RS府省庁 → RS事業（結合予算／事業全体の支出）→ recipient。

現段階ではMOFの組織・勘定・全項をそれぞれ独立列で同時表示しない。項は画面下の選択欄で切り替え、左端のMOFノードから結合済み事業の流れを表示する。MOF未結合分や国の総予算を表す図ではない。

## join

`generate-mof-rs-kou-moku-linkage.ts` が生成する `mof-rs-kou-moku-linkage-{budgetYear}.json` を使用。一般会計は予算種別・所管・組織・項名・目名、特別会計は予算種別・所管・会計・勘定・項名・目名をNFKCと空白除去後に照合する。

項の識別は会計区分・予算種別・所管・組織/特会・勘定・項コードの組。項コード単独や名称だけで結合しない。項配下の目をprojectIdごとに合算する。`metadata.rsYear` とRS年度の一致を確認し、2025年度RSは2024会計年度MOFを参照する。

RSグラフは `generate-sankey-svg-data.ts` の生成物をそのまま参照し、project-budget / project-spending のprojectIdで接続。recipientのID・名称・エッジ額を維持し、対象事業分を合計し直す。

## 金額と制約

緑は選択範囲の当初予算リンクのrsAmount。橙とrecipientはRS事業全体の実支出であり、MOF項への按分推定をしない。事業の詳細パネルの予算内訳は元のRS事業全体を参照する。決算からの引継ぎリンク・補正・繰越・未結合事業は初期実験に含めない。データ欠落年度はエラーで知らせる。

## 検証

Playwrightで1920×1080の基準・統合ページを撮影して目視比較。検索から事業選択、詳細パネル、ズーム、MOF項切替と描画、pageerrorなしを検証。型チェックを実施。
