# 統合サンキーのグラフモデル

`/integrated-sankey` は、MOFの「項」とRS予算事業の対応関係を見る実験ページ。
仕様の正は `docs/tasks/20260913_1555_統合サンキー再構築の確定仕様.md`。本書は実装後の恒久ガイド。

## 画面の基準

`/sankey-svg` の「サンキー図そのもの以外」のコントロール一式（検索・フィルタ・ズーム・
パン・サイドパネルの枠・年度切替・ページ切替）をそのまま引き継ぐ独立ルート。
既存ページ・共有部品は変更しない。

MOF項・RS事業という2ノード型は、`/sankey-svg` の4列（総計/省庁/事業/支出先）レイアウト
エンジン（`app/lib/sankey-svg-filter.ts` の `filterTopN`/`computeLayout`）が前提とする
ノード型と根本的に異なるため、**データ・レイアウトのロジックは `page.tsx` 内に新規で持つ**。
一方、検索ボックス・フィルタパネル・ズームコントロールの**UI構造とスタイル値は
`/sankey-svg` の実装からそのまま移植**する（近似で書き直さない）。

## 2列モデル

```text
MOF項 ── 帯 ──→ RS予算事業
       ├ 帯 ──→ RS未接続
       └ 帯 ──→ 超過・要確認
```

左列はMOFの項、右列はRS予算事業と集約ノード。**目エッジは持たない。** MOFの「目」を
介した紐づけデータ（`IntegratedItemEdge[]`、`app/lib/integrated-sankey.ts` が生成）を
`page.tsx` 側で項×事業のペアに集約し、1本の帯として描画する。目の個別内訳は
詳細パネルのタブでのみ見せる（下記「詳細パネル」参照）。

同じRS事業が複数の項に接続する場合、複数の項から同じ事業ノードへ収束させる。

### 項の識別

会計区分・予算種別・所管・組織／特別会計・勘定・項コードの組で識別する
（`app/lib/integrated-sankey.ts` の `itemSectionKey`）。項名または項コード単独をIDにしない。

## 検索とフィルタは別物

`/sankey-svg` と同じ設計を守る。前回の実装（この2つを1つの検索ボックスへ統合していた）
の誤りをやり直した経緯は `docs/tasks/20260913_1529_...` `20260913_1555_...` を参照。

- **検索（ジャンプ機能）**：`SearchJumpBox`。グラフを絞り込まない。入力に一致するノードを
  ドロップダウンに列挙し、クリックすると該当ノードへ選択・ウィンドウ移動する。
  MOF項用・RS事業用に独立した2本を持つ（統合1本にしない）。部分一致・正規表現の
  2モードを切り替えられる（`.*` トグル）。不正な正規表現は例外を投げず「該当なし」
  として扱う（`buildMatcher` がページ内に集約）
- **フィルタ（絞り込み）**：検索ボックスの下に開閉する `filtersOpen` パネル。実際に
  グラフから項・事業を除外する。会計区分・所管はチェックボックス付きコンボボックス
  （`CheckboxCombobox`。選択が空＝絞り込みなし）、項名・事業名は部分一致テキスト、
  項予算・事業予算はそれぞれ独立した金額レンジ（`parseAmountToYen` で解釈）

検索・フィルタのドロップダウンは、全画面の透明レイヤーではなく**外側クリック検知**
（`document.addEventListener('mousedown', ...)` ＋ ルート要素への `ref`）で閉じる。
`/sankey-svg` と同じ方式。全画面レイヤーだとトリガーボタン自身もレイヤーの下敷きになり、
再クリックで閉じようとした操作が奪われるため使わない。

## 金額定義

| 対象 | 使用する金額 |
| --- | --- |
| MOF項の総額 | 配下にあるMOF目の `amount` 合計 |
| MOF項の前年度額・増減率 | 配下の目の `previousAmount`/`difference` を合算（null は0扱い） |
| RS事業へ向かう帯 | 結合レコードの `rsAmount` を項×事業で合算 |
| RS未接続へ向かう帯 | MOF目金額 − その目からRS事業へ向かう `rsAmount` 合計（項単位で合算） |
| RS事業の予算額 | `initialBudget`（当初予算） |
| RS事業の支出額 | `budgetSummary.executedAmount` |
| RS事業の会計区分 | 接続する目の `mofAccountType` から集計。単一なら一般/特別、複数にまたがれば `mixed` |

### 禁止事項

- MOF目の全額を、接続したRS事業へそのまま流さない
- `MOF目金額 − RS接続額` が負になる場合、0へ丸めて隠さない（`超過・要確認` として集計する）
- MOF当初予算とRSの歳出予算現額・執行額を同じエッジで混在させない

## 年度切替

対応年度はRS2025（MOF2024）・RS2024（MOF2023）の2つ（`app/api/integrated-sankey/route.ts`
の `SUPPORTED_RS_YEARS`）。**紐づけ品質は年度で大きく異なる**（実測: RS2025×MOF2024は
事業紐づけ率92.7%、RS2024×MOF2023は21.3%）。API は `linkageQuality`
（`app/lib/api/mof-rs-kou-moku-linkage-loader.ts` の `linkageQuality()`）を常に返し、
画面右上に隠さず表示する。紐づけ率50%未満の年度は明示的な注記を出す。

紐づけ生成ロジック（`scripts/generate-mof-rs-kou-moku-linkage.ts`）自体の精度改善は
別task doc（未着手）。今回は既存の生成済みデータをそのまま両年度分出している。

## 事項データ（未統合）

MOF予算書には「目」（性質別）とは別に「事項」（目的別、`/mof-jikou` が扱う）という
分類がある。項の詳細パネルに「事項一覧」タブを持たせる案があったが、統合には
新規のデータ結合パイプラインが要るため今回のスコープから外した（別task doc、未着手）。
現在の項の詳細パネルは「目一覧」「RS事業一覧」の2タブ。

## 詳細パネル

`SidePanelChrome`（`/sankey-svg`・`/subcontracts` と共有）を右側に開く。

### 項選択時

ヘッダー：項名、会計区分、所管、組織／特別会計、勘定、本年度額、前年度額、増減率。
タブ：目一覧（接続先事業・状態・金額）、RS事業一覧（この項から接続する事業の合計額）。

### 事業選択時

ヘッダー：事業名、会計区分、所管、部課局（近似・下記注意）、PID、予算額、支出額。
タブ：予算執行一覧（`budgetSummary` の当初・補正・繰越・予備費・執行率等の表形式表示、
接続するMOF項一覧）、目一覧（既存の `budgetItems`、MOF接続済み/未接続バッジ付き）。

**部課局は近似値。** 事業内で複数組織にまたがる場合があり、目内訳の先頭行
（`budgetItems[0].organizationAccount`）を代表値として使っているため厳密ではない。

## 対象外（今回のスコープ外）

- 紐づけ生成ロジックの精度改善（別task doc）
- 支出先（recipient）列・再委託・政策評価スコア・AIチャット・ミニマップ・
  「関連ノードのみ表示」・事業の予算/支出の二重ノード構造
  （`docs/tasks/20260913_1529_...` の洗い出しで不要と判定）
