# 目一覧の分類列・フィルタをコード番号順に整列

## コード番号の並び順（一次情報）

`docs/mof-budget-data-guide.md` 4-0節に予算書「(参考) コード番号について」の複合コード表記がある:

```text
一般会計:  95016-2111-02
           ││   │││└ 目別分類 02 = 職員基本給
           ││   ││└─ 使途別分類 1 = 人件費
           ││   │└── 経済性質別分類 11 = 雇用者報酬
           ││   └─── 財政法公債金対象非対象別分類 2 = 上記以外のもの
           │└─────── 目的別分類 016 = 一般行政費
           └──────── 主要経費別分類 95 = その他の事項経費
```

順は **主要経費別 → 目的別 → 財政法公債金対象非対象別 → 経済性質別 → 使途別 → 目別**。

## 変更内容

- `client/components/mof-kou-moku/columns.ts`: COLUMNSの並びを主要経費→目的別→財政法公債金対象非対象別→経済性質別→使途別→目コード→目名の順に変更（従来は主要経費→目コード→目名→使途別で、使途別が目別の後ろにずれていた）
- `client/components/mof-kou-moku/KouMokuTable.tsx`: 上記に合わせて目的別・財政法公債金対象非対象別・経済性質別の`<td>`を追加し、既存セルの並びも合わせた
- `client/components/mof-kou-moku/FilterSidebar.tsx`: フィルタの並びも主要経費→目的別→財政法公債金対象非対象別→経済性質別→使途別の順に変更（従来は主要経費→使途別→目的別→財政法→経済性質別で使途別が先頭寄りだった）

## フィルタ全体の並び順の根拠（既存分）

予算種別・会計区分・所管・組織／特会／機関・勘定／業務、という並びはコード番号由来ではなく、**絞り込みが連鎖する階層構造**（会計区分・予算種別で母集団を分け、所管→組織→勘定の順に組織階層を絞り込む）に基づく。主要経費以降の分類群（コード番号由来の5分類）はその下に続けて配置しており、今回その5分類の内部順序だけをコード番号順に揃えた。

## 確認

- `npx tsc --noEmit` / `npm run lint`: エラーなし
- ブラウザで列・フィルタともに主要経費→目的別→財政法公債金対象→経済性質別→使途別→目コード→目名の順に並ぶことを確認
