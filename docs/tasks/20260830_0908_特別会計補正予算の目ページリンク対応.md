# 特別会計 補正予算の目ページリンク対応

[前回調査](20260830_0855_目ページリンクのスクレイピング可否調査.md)で実現可能と分かった、特別会計の補正予算における目レベルの出典ページリンクを実装した。決算（全会計区分）は対象のXML帳票が存在しないため引き続き対象外。

## 変更内容

`scripts/generate-mof-kou-moku-data.ts`の`buildSpecialPageMap`を汎用化し、帳票判別用の`listTitleMatch`と目名列番号`subItemNameCol`を引数化した:

- 当初・暫定: `歳入歳出予定額科目別表` / 目名列=5（従来通り）
- 補正: `歳入歳出予算補正予定額科目別表` / 目名列=6（新規。列数が5本の金額列を持ち、目名の列位置が1つずれる）

呼び出し側（`generateYear`）の`specialSpecs`フィルタを`layout === 'standard'`から`layout !== 'settlement'`に変更し、補正も対象に含めた。

## 確認

- `npx tsc --noEmit` / `npm run lint`: エラーなし
- 全10年度（2017-2026）で`generate-mof-kou-moku`・`generate-mof-budget`を再実行、`compress-data`で再圧縮
- 令和6年度（2024）の実行ログ: 特別会計 2,832件中1,279件で行単位URLを特定（従来は当初予算1,225件が上限だったところ、補正予算356件の一部も加わり増加）
- 国債整理支出（国債整理基金特別会計）の補正予算・目5件すべてで`page`/`sourceUrl`が正しく設定されることをAPI（`/api/mof-kou/detail`）で確認

## 対象外のまま

決算は歳出側に目レベルのXML帳票が存在しないため未対応（前回調査の結論通り）。
