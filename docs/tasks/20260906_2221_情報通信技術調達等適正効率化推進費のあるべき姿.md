# 『情報通信技術調達等適正・効率化推進費』のあるべき姿 — 一括計上予算の透明性を『国際観光旅客税財源観光振興費』と比較して

[全項での当初決算の目数金額変化パターン](20260906_2138_全項での当初決算の目数金額変化パターン.md)の続き。同じ一括計上予算（送り手の項が決算で多数の所管に受け皿として現れる）でも、『国際観光旅客税財源観光振興費』は目でデータの整合が取れるのに、デジタル庁の『情報通信技術調達等適正・効率化推進費』はMOF・RSどちらの側でも内訳が追えない。両者を2024年度の実データで並べ、何が欠けているか、本来どう記録されているべきかを整理する。

## 比較の結論（先に要点）

| 観点 | 国際観光旅客税財源観光振興費（観光庁） | 情報通信技術調達等適正・効率化推進費（デジタル庁） |
|---|---|---|
| 送り手の当初の目 | 用途ごとに別名（出入国管理業務庁費・税関業務特別庁費・文化資源活用委託費…13目） | ほぼ1目に集約（情報処理業務庁費 4,539億円が全体の94%） |
| 決算の受け皿側の目 | 送り手と**同じ目名・同じ金額**が受け皿所管に現れる（法務省に出入国管理業務庁費72.0億円、財務省に税関業務特別庁費24.9億円…） | 74組織すべてが**同じ目名「情報処理業務庁費」**（6,175億円）。どの組織の行がどのシステムか目からは分からない |
| RS事業 | 31事業、全て観光庁所管、**全て予算あり支出あり**。事業の予算額が送り手の目の金額と一致（円滑な出入国の環境整備=72.0億円 等） | 240事業、全てデジタル庁所管。**予算を持つのは親事業1件だけ**、残り239件は予算0円で支出だけを持つ |
| RSの移替の表し方 | 負の行なし。受け皿側の予算行も持たない | 親事業に**「予備費等1」として−5,097億円**の負の行（所管・項・目は空欄） |
| MOF↔RS紐づけ | 目名で1対1に結べる | 240事業中18件しか結べず、金額が付くのは親事業1件のみ。他17件は0円の行で形式上結べるだけ |

つまり『国際観光旅客税』は **RS事業 ↔ 送り手の目 ↔ 受け皿の目** が同じ目名と金額で三者一致しており、どの省庁に渡った金がどの事業のものか機械的に復元できる。『情報通信技術』はその鎖が二か所で切れている（目名が用途を持たない／RSの予算が親事業に丸められている）。

### 情報通信技術調達等適正・効率化推進費（2024年度）

**MOF側**: 送り手（デジタル庁）の当初は7目・4,803億円、うち情報処理業務庁費が4,539億円。決算では受け皿85行が74組織（項コード829〜842）に現れ、そのうち74組織・6,175億円が同じ目名「情報処理業務庁費」。

**RS側**: 事業名に「(情報通信技術調達等適正・効率化推進費)」を含む事業は240件、全てデジタル庁所管（防衛装備品等調達システムのような他省庁のシステムも含めて）。受け皿側の省庁が同じシステムのRS事業を別途持つことは無い（PMH・VisitJapanWeb・ガバメントクラウド等で確認）。

親事業 ID 4「情報システムの整備(情報通信技術調達等適正・効率化推進費)」の2-2:

```text

当初予算       （同）マイナンバーカード関係システム事業費補助金                          22,136,794,000
...            （当初7行、計480,327,293,000）
前年度から繰越し  （所管・項・目すべて空欄）                                            93,383,296,000
予備費等1        （所管・項・目すべて空欄）                                          -509,690,849,950   ← 移替の流出
第1次補正予算   （同）情報処理業務庁費                                              204,661,390,000
```

2-1では 当初4,803億＋補正2,054億＋繰越934億 → 歳出予算現額2,694億円、執行1,760億円。**移替で他省庁に渡した約5,097億円が、所管・項・目を持たない負の「予備費等1」1行で表現されている。**

子事業（239件）は全て 当初0円・補正0円・現額0円 で、5-1の支出だけを持つ（例: ID 11 第一期政府共通プラットフォーム 執行57億円、ID 15 電子政府の総合窓口システム 支出49.6億円）。240事業の5-1支出合計は1兆394億円。

**紐づけ**: `mof-rs-kou-moku-linkage-2024.json`で結べるのは18事業。金額が付くのは親事業ID 4のみで、他17件は2-2に「情報処理業務庁費 0円」の行があるため形式上結べるだけ。残り222事業は2-2の所管・項・目が空欄で紐づけ不能。

## 何が欠けているか

1. **目名が用途を持たない**。送り手も受け皿も「情報処理業務庁費」1本のため、決算で74組織に分かれた行を、どのシステムの経費かに戻せない。『国際観光旅客税』は目名自体が用途（出入国管理・税関・文化資源…）を表すので受け皿でも意味が保たれる
2. **RSの予算が親事業に丸められ、子事業は「予算なし支出あり」になる**。239件の子事業は支出先まで詳細に記録している一方、予算は0円。RSの2-2は「歳出予算項目ごと」の予算を記録する帳票だが、移替先で執行される分は子事業側に予算として書かれていない
3. **移替が負の「予備費等」で表現され、行き先を持たない**。−5,097億円がどの省庁のどの項に渡ったかはRS上に無い。MOF決算側には受け皿（74組織）があるが、目名が共通なので突き合わせる鍵が無い
4. **結果として、この項に属する事業の大半がMOF↔RS紐づけから漏れる**。当初予算で行の92.7%・金額の97.9%が結べるという全体の実測値の裏で、この項では240事業中1件しか実質的に結べていない

## あるべき本来の姿

一括計上予算という制度自体は標準的な仕組み（[予算移替は一括計上予算という標準的な仕組み](20260901_2308_予算移替は一括計上予算という標準的な仕組み.md)）で、問題は制度ではなく記録の粒度にある。『国際観光旅客税』が既にそうなっているように、次のいずれかが満たされていれば機械的に追跡できる。

**MOF側（予算書・決算）**

- 送り手の目を用途（システム・事業）単位に分ける。『国際観光旅客税』は13目で用途を表しており、決算の受け皿でも同じ目名が保たれている。デジタル庁の項も「情報処理業務庁費」1本ではなく、少なくとも受け皿の所管ごと、望ましくはシステムごとの目名を持てば、受け皿74行が何の経費か決算から読める
- それが難しければ、受け皿側の決算行に**移替元の事業（RSの予算事業ID）を補足情報として持たせる**。RSの2-2には「歳出予算項目の補足情報」列が既にあり、逆方向の参照は制度上可能

**RS側（行政事業レビュー）**

- 子事業（239件）の2-2に、**移替後に執行される予算額を、移替先の所管・組織・項・目つきで記録する**。現状は親事業の負の「予備費等1」に流出額だけが書かれ、子事業は0円。移替先の所管（例: 防衛装備品等調達システムなら防衛省）と項コード829番台の受け皿項を書けば、MOF決算の受け皿行と(所管,組織,項,目)で直接結べる
- 親事業ID 4と子事業239件の関係を**1-5「関連事業」で明示する**。現状は事業名の括弧書き「(情報通信技術調達等適正・効率化推進費)」が唯一の手がかりで、機械的には文字列一致に頼るしかない
- 少なくとも、移替の負の行に**移替先の所管を書く**。−5,097億円が1行で消えるのではなく、所管別に分かれていればMOF決算の受け皿合計（6,275億円。補正・繰越分の差は別途要確認）と突き合わせられる

## 本リポジトリでの扱い方（提案）

- **「予算あり支出なし」「予算なし支出あり」はこの項ではデータ不備ではなく構造そのもの**。親事業ID 4は5-1の支出先が0件（執行額1,760億円はあるが支出先の内訳が無い）で「予算あり支出なし」、子事業239件は「予算なし支出あり」になる。品質判定やフィルタでこれらを異常扱いする場合、事業名の括弧書きで親子を束ねて1つの事業群として評価する方が実態に合う
- **紐づけの取りこぼしを可視化する**。`/mof-kou`や`/mof-sankey`で項『情報通信技術調達等適正・効率化推進費』を見たとき、RS事業数は実質1件（ID 4）だが、事業名で束ねれば240件ある。「この項の受け皿74組織・6,175億円に対応するRS事業は240件だが、目名では結べない」という注記を出せると誤解を防げる
- **受け皿とRS子事業の突合は、目名ではなく金額と所管で推定するしかない**。防衛装備品等調達システム（ID 20570）と防衛省の受け皿行のように、所管が一意に決まる組み合わせなら推定可能。ただし1組織に複数システムが渡る場合は分けられないので、推定結果は信頼度を分けて表示する必要がある（[項目の年度推移チャート化に向けた調査テーマ](20260905_0807_項目の年度推移チャート化に向けた調査テーマ.md)の「推定で繋いだ箇所を隠さない」方針と同じ）

## 補足・未解明

- RS子事業240件の5-1支出合計1兆394億円は、MOF決算の項全体の歳出予算現額8,970億円（デジタル庁2,694億＋受け皿6,275億）を上回る。繰越分の執行や複数年度契約の計上方法の違いが考えられるが未確認
- 親事業の負の「予備費等1」−5,097億円と受け皿の決算現額6,275億円の差（約1,178億円）も未照合。補正予算後の追加移替が受け皿側に含まれている可能性がある
- 本ドキュメントの数値は2024年度（RS_2025シート・MOF令和6年度）のみ。制度の記録粒度が年度で変わっていないかは未確認
