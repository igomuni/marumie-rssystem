# 概算要求と MOF 当初予算の差を見るページの設計

状態: 設計案（未実装）。年度推移のページとは別のページを作る。MOF の項ごとに、概算要求額と当初予算額（政府案）の差を一覧にする。差の理由の型をバッジで示す。対象は FY2023〜2026。末尾の「決めてほしいこと」はユーザーの判断待ち。

## 目的

- 項ごとに、要求額から予算額へどれだけ変わったかを見る。
- その差をどう読むかの手がかり（事項要求、要求0、仮置きの項など）を、同じ画面で示す。

MOF との突合を、年度推移のページ（`/budget-request-trend`）に混ぜない方針（2026-10-21 の合意）に沿って、別のページにする。

## 入力（すべて既存）

| 入力 | 使い方 |
|---|---|
| `tests/fixtures/mof-budget-request-match/{ver}/m1-kou.csv` | 概算要求の項と MOF の項の対応。状態、要求額、MOF の額 |
| `tests/fixtures/mof-budget-request-match/{ver}/unmatched-mof-kou.csv` | MOF のみの項 |
| `tests/fixtures/mof-archive-csv/{ver}/kou-{general,special}.csv` | MOF の項の所属（所管・組織 / 特別会計・勘定・共管）と前年度予算額 |
| `tests/fixtures/budget-request-trend/kou.csv` | 要求書の PDF の頁（リンク用） |
| `tests/fixtures/budget-request-jikou-youkyu/kou.csv` と `public/data/v2/ui/budget-request-trend/jikou.json.gz` | 事項要求（項・組織）、要求0、一括計上 |

## 行の単位

**1 行 = 年度 × MOF の項。** 予算書の項を基準にする。そこに概算要求の行を対応させる。

| 行の種類 | 内容 | 件数（FY2026） |
|---|---|---:|
| 対応あり | MATCHED / NEAR_NAME の MOF の項 | 1,026 |
| MOF のみ | `unmatched-mof-kou.csv` | 58 |
| 概算要求のみ | NO_CANDIDATE の概算要求の行。MOF の項がないので、要求側の所属で 1 行にする | 14 |
| 額0の項 | ZERO_AMOUNT の概算要求の行。既定では隠す | 48 |

**同じ MOF の項に複数の要求行が対応する場合**（FY2026 は 70 項）は、1 行にまとめる。

- 67 項は、同じ項が複数の府省の書に同額で載るもの。
- 3 項は、復興特会の持ち分。
- 要求額は、年度推移と同じく最も大きい額（合計書）を使う。各書の額は詳細に出す。
- 所属の違う要求行が同じ MOF の項に当たる例は、FY2026 では 0 件だった。

## 一覧の列

所管・会計・組織／勘定・項名・要求額・当初予算額・差（当初 − 要求）・差率・型のバッジ。

- **差の符号:** 正は、要求より予算が大きいことを示す（年度推移の「査定差」と同じ向き）。
- **合計:** 一覧の上に出す。繰入は会計をまたいで二重になるので、年度推移と同じ注意書きを出す。

## 差の理由の型（バッジ）

既存のデータから機械的に付ける。理由を確定するものではなく、読み方の手がかりとして示す。

| 型 | 条件 | 出所 |
|---|---|---|
| 事項要求 | 項の中に、備考の事項要求の記載がある | jikou（項） |
| 組織に事項要求 | 組織の行に、事項要求の記載がある | jikou（組織） |
| 要求0 | 前年度に額があり、要求額が 0 | jikou の kou.csv |
| 一括計上の配分先 | 要求では推進費に一括し、予算で配分される | 国際観光旅客税の 2 項。名前の規則で付ける |
| 仮置き | 項名が `予備費` / `国債費` / `地方交付税交付金` / `地方特例交付金` を含むか、`繰入` で終わる | 名前の規則 |
| 複数書 / 持ち分 | 同じ MOF の項に、複数の要求行が対応する | m1 |

**仮置きを型にする理由**

- 仮置きに当たる項は、FY2023〜2026 の各年度で 100〜119 項（全体の約 1 割）ある。
- ところが、差の絶対値の合計に占める割合は 79% / 58% / 36% / 59% になる。
- 仮置きの項を除いて見るフィルタがないと、裁量の項の差がこれに埋もれる。

## 画面

年度推移と同じ 3 ペイン（左がフィルタ、中が一覧、右が詳細）。部品は `client/components/budget-request-trend/` を流用する。

**左（フィルタ）**

- 年度
- 所管・会計（年度推移と同じコンボ）
- 組織／勘定・項名
- 行の種類（対応あり / MOF のみ / 概算要求のみ / 額0の項）
- 型（上の表）。「仮置きを除く」も置く。
- 差の大きさ（例: |差| ≥ 10 億、差率 ±10%）

**中（一覧）:** 既定は、|差| の大きい順。

**右（詳細）:**

- 要求側の行: 要求書・PDF の頁へのリンク、前年度予算額、要求額。複数書なら書ごと。
- MOF 側の行: 所属、当初額、前年度予算額。
- 型の説明。
- 年度推移のページの同じ項へのリンク（キーで引く）。

## 範囲外（今回はやらない）

- **組織の移動の検出**（例: FY2025 の地方創生基盤整備事業推進費が、地方創生推進事務局から内閣本府へ移った）。MOF のみの項と、同所管・同名で対応ありの MOF の項の組から候補を出せる。ただし件数と確度を見てから決める。
- 事項・目の階層（m2 / m3）の差。
- FY2027（MOF 未公表）。

## 決めてほしいこと

1. **ページの名前と URL。** 案: `/budget-request-mof`（「概算要求と当初予算」）。
2. **MOF の版。** 案: すべて提出時（政府案）にそろえる。`2023`・`2024`・`2026` は提出時、FY2025 は `2025_teishutsu` が提出時で、`2025` は成立後（`docs/mof-archive-csv.md`）。本文の FY2025 の件数・割合は `2025`（成立後）で数えた。FY2025 は国会で修正されたので、提出時と成立後の両方がある。版の切り替えを付けるか、提出時だけにするか。
3. **額0の項の行を出すか。** 案: 既定では隠し、行の種類のフィルタで出せるようにする。
4. **仮置きの名前の規則。** `繰入` を全部含めるか。案: 含める。繰入は受け側の会計の動きに従うため。
