# 共管の特別会計の要求書の重複と、所管の表示

状態: 調査と実装の済み（PR #542）。

結論:

- 複数の府省に載る要求は 2 種類ある。
  - 同額: 同じ要求書を各府省がそれぞれ掲載している。
  - 合計: 東日本大震災復興だけで、各省の持ち分と復興庁の合計の書がある。
- 同額の要求書から、主となる府省は決められない。
- 画面では「N所管」と出し、所管のフィルタに「複数所管」を加えた（「共管」は伝わりにくいので改めた。年度推移のページも同じ）。

## 同額の要求書は同じものか（FY2026）

| 特別会計（勘定） | 掲載している府省 |
|---|---|
| 子ども・子育て支援 | こども家庭庁、厚生労働省 |
| エネルギー対策（エネルギー需給） | 環境省、経済産業省 |
| エネルギー対策（電源開発促進） | 内閣府、環境省、経済産業省、文部科学省 |

**ファイルは別物。** SHA-256 も頁数も違う（例: 子ども・子育て支援は 50 頁ずつ、エネルギー需給は 11 頁と 15 頁）。

**中身は同じ。** どれも、その特別会計（勘定）全体の歳出概算要求書。

- 空白を除いた本文の行の並びは 87〜93% 一致した。
- 明細の金額は一致した。違った 1 行（エネルギー需給の「エネルギー使用…」）も、額は同じで、備考の参照コード（環 A11 / 環 A11 環 A14）だけが違う。

**違いは体裁。**

- 表紙・目次の有無。内閣府の電源開発促進（e2.pdf）と、環境省のエネルギー需給は、明細表からの抜粋。
- 目次の組み方と頁ラベル。
- 定員表の有無。環境省の電源開発促進にだけある。
- 印刷日時。環境省 8/19・経済産業省 8/28（エネルギー需給）、文部科学省 8/22・環境省 8/28（電源開発促進）。こども家庭庁と内閣府の版には印刷日時がない。

共通の要求書の内容を、共管の各府省がそれぞれ出力して掲載したものと見られる。府省ごとの行を足すと二重になる。

## 主となる府省は分かるか

- **予算書（MOF）:**
  - 特別会計の `所管` は「内閣府、総務省及び財務省」のような列挙で、順序に主従の意味はない。
  - 項ごとの `共管所管名` が埋まるのは東日本大震災復興だけ（ほとんど復興庁。地方交付税は総務省、国債整理基金への繰入などは財務省）。
- **要求書（FY2026）:**

| 特別会計 | 要求書を載せている府省 |
|---|---|
| 交付税及び譲与税配付金 | 総務省だけ |
| 財政投融資（3 勘定とも） | 財務省だけ |
| エネルギー対策の原子力損害賠償支援、先端半導体・人工知能関連技術 | 経済産業省だけ |
| エネルギー需給、電源開発促進、子ども・子育て支援 | 複数の府省が同額で掲載 |

主が決められるのは、1 府省だけが載せる勘定と、東日本大震災復興に限られる。法律上の勘定ごとの所管は、手元のデータにない。

## 画面（/budget-request-mof と /budget-request-trend）の扱い

年度推移の一覧も、項 × 所管（府省ごとに 1 行）から、項ごとに 1 行に改めた。金額はその年度の値（合計の書）なので、一覧の合計は二重に数えない。

- **所管の列:**
  - 単独の府省は、その名前。
  - 複数所管は「N所管」（例: 2所管）。
  - 東日本大震災復興は「復興庁（取りまとめ）」。
  - 府省名は、ツールチップと詳細に出す。
- **所管のフィルタ:**
  - 府省を選ぶと、その府省が載せている複数所管の項も出る。
  - 選択肢「複数所管」を選ぶと、複数所管の項だけが出る。
  - 件数は合計だけを出す（内訳はノイズになるため出さない）。
- **MOF のみの特別会計の行:** 予算書の `共管所管名` があればそれを使い、なければ `所管` の列挙を府省に分ける。
  - 以前は、元データにない「共管」という語を所管として出していた。今回の変更で、この表示はなくなった。
