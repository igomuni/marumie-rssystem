## 次（ユーザーの判断）
1. **一般会計の FY2025（成立後・提出時）を先に一般化する。** 年度の文字・DOCTYPE・source set・想定件数を、帳票ごとの値（spec）にする。規則の追加はない。回帰条件は、FY2024 の一般会計の出力（`jikou-general.csv` `2b92b50e…`）がバイト単位で変わらないこと。
