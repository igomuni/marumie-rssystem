# MOF 側に RS の事業名に相当する項目はあるか

結論: **事業名で直結する列は無い。最も近いのは〔事項別内訳〕の「事項」だが、粒度が約4倍粗く、名前での一致は6%程度。**
実用上は「項」で構造的に挟み、「主要経費」で分類軸を合わせ、事項は説明文付きの中間ラベルとして使うのが現実的。

検証データ: MOF 令和6年度（`mof_2024` + `server/2024` の事項別内訳95ページ）× RS_2025 の予算年度2024・一般会計・当初予算。

---

## 1. 候補の棚卸し

| 候補 | 所在 | 判定 |
|---|---|---|
| **事項名** | 予算書 Web の〔組織別事項別内訳〕 | ◎ 最も近い。ただし粗く、名前一致は限定的 |
| 項名 | CSV `b` の `項名` | ○ 事業名ではないが**構造キーとして機能する** |
| 目名 | CSV `b` の `目名` | × 「庁費」「職員基本給」等、支出の性質分類 |
| 主要経費 | CSV `b` のコード / RS 1-2 の `主要経費` | ○ 事業名ではないが**語彙が共通で分類軸に使える** |
| RS `歳出予算項目の補足情報` | RS 2-2 | × 充足率7.2%・書式不統一 |

---

## 2. 事項名 vs 事業名（実測）

令和6年度一般会計の事項 1,262件（ユニーク名 1,084）に対し、RS 事業 3,844件。

| 突合 | 件数 | 対 RS 事業 |
|---|---|---|
| 事業名 == 事項名（完全一致） | 80 | 2.1% |
| 事項名の語幹（「に必要な経費」を除去）が事業名に含まれる | +134 | 3.5% |
| 合計 | 214 | **5.6%** |

一致する例:

```text
事業「遺棄化学兵器廃棄処理事業経費」      ⊂ 事項「遺棄化学兵器廃棄処理事業に必要な経費」
事業「沖縄北部連携促進特別振興事業費」    ⊂ 事項「沖縄北部連携促進特別振興事業に必要な経費」
事業「皇宮警察本部」                      ⊂ 事項「皇宮警察本部に必要な経費」
事業「消費者政策企画・立案」              ⊂ 事項「消費者政策に必要な経費」
```

RS 事業名の 4.5%（238件）は「〜に必要な経費」で終わっており、これは MOF の事項名の書式そのもの。**府省庁がレビューシートを作るとき、事項名をそのまま事業名にしたケースが一定数ある**とみられる。逆に言えば残りは独自の事業名を付けており、文字列だけでは寄らない。

## 3. 粒度の関係

項名で見ると、RS 側の 555項のうち **554項が MOF 側にも存在する**（ほぼ完全被覆）。その共通項の中で:

```text
MOF 事項  998件  ←→  RS 事業 3,995件
```

**1事項あたり平均4事業**。事項は項と事業の中間にある実在の層であって、事業と1:1ではない。

## 4. 主要経費という共通軸

RS の `1-2_基本情報_事業概要等` に `主要経費` 列があり、値は「その他の事項経費」「科学技術振興費」「エネルギー対策費」など30種。**MOF の主要経費別分類コードの名称と同じ語彙**（`mof-budget-data-guide.md` §4-2）。事業名の代わりにはならないが、事項↔事業のマッチング候補を絞る制約として使える。

---

## 5. 使うなら

1. **骨格は項で作る**。RS 事業の 99.8% が MOF の項の下に収まるので、`項 → RS事業` は確実に描ける。
2. **事項は中間ラベルとして挟む**。事項は `説明` 欄（所掌事務・根拠法）を持つため、項と事業の間に意味のある層を1枚追加できる。ただし事項↔事業の対応は自動では決まらない。
3. **対応付けを詰めるなら**、同一項＋同一主要経費に絞ったうえで、事項の `説明` と RS の `事業の目的`／`事業の概要` を突き合わせる。`/project-bubble` で使った埋め込みが流用できる。
4. 完全一致・部分一致する 214件は先に確定させてよい。

## 6. スクレイパ実装時の注意

事項別内訳 XML のセルは折り返しごとに `<clm>` が分かれる（`id` の `{行内連番}` が異なる）。
**テキスト列は連結すべきだが、金額列は連結してはいけない**（別の行の金額が繋がって桁が壊れる）。列ごとに扱いを変えること。

## 7. 「事項名があるもの」の割合と金額（令和6年度・一般会計・当初予算）

### 7-1. MOF 側 — 事項名は歳出の全額に付いている

| | 件数 | 金額 |
|---|---|---|
| 事項別内訳（事項名あり） | 1,262 | 112,587,959,045千円 = **112.6兆円** |
| 科目別内訳＝CSV `b` の合計 | 6,716キー | 112,571,688,422千円 = 112.6兆円 |

差は 0.014%（折り返し行の取りこぼし）。**一般会計歳出は 100% が何らかの事項に属する**ので、「事項名が無い予算」は存在しない。事項が付かないのではなく、事項が RS 事業と 1:1 で対応しないことが問題。

### 7-2. RS 事業側 — 事項名を特定できるのは件数5.5%・金額32.2%

母数: RS 2024・一般会計・当初予算 = **3,861事業 / 42.22兆円**。

| 突合 | 件数 | 件数比 | 金額 | 金額比 |
|---|---|---|---|---|
| 事業名 == 事項名 | 79 | 2.0% | 2.60兆円 | 6.2% |
| 事項名の語幹が事業名に含まれる | 132 | 3.4% | 10.98兆円 | 26.0% |
| **合計** | **211** | **5.5%** | **13.58兆円** | **32.2%** |

**件数では5.5%だが金額では32.2%**。大口の事業ほど「1事項＝1事業」になりやすく、名前もそのまま引き継がれるため。上位を見ると精度も高い。

```text
10.157兆 [語幹] 事業「医療保険給付費国庫負担金等」 / 事項「医療保険給付に必要な経費」
 1.563兆 [完全] 事業「義務教育費国庫負担金に必要な経費」（事項名と同一）
 0.412兆 [完全] 事業「年金生活者支援給付金の支給に必要な経費」（同）
 0.147兆 [語幹] 事業「独立行政法人国際協力機構運営費交付金」 / 事項「…運営費交付金に必要な経費」
```

独立行政法人の運営費交付金は事項＝事業になりやすく、ほぼ全件が拾える。
一方、語幹一致には誤検出も混じる（例: 事項「地域振興に必要な経費」が事業「過疎地域振興対策等に要する経費」に部分一致）。金額は小さいが、採用するなら人手または意味的照合での確認が要る。

### 7-3. MOF 事項側 — 紐づいたのは 187事項・14.1兆円

| | 件数 | 件数比 | 金額 | 金額比 |
|---|---|---|---|---|
| 全事項 | 1,262 | 100% | 112.6兆円 | 100% |
| RS 事業名と結びついた事項 | 187 | 14.8% | 14.1兆円 | 12.5% |

MOF 側の金額比が低いのは、国債費・地方交付税・特会繰入といった大口が RS に事業として存在しないため（§前編の分析と同じ構図）。
