# 項一覧（/mof-kou）のフィルタを左サイドパネル化

これまで上部の横並び折りたたみパネルだったフィルタを左サイドパネルに移し、列の値のタイプに合わせて操作方法を変えた。

## 対応方針

- **選択付きコンボ**（予算種別・会計区分・所管・組織/特会/機関・勘定/業務）: `<select>`を縦に並べる。会計区分はこれまでセグメントボタンだったがコンボに統一
- **文字列**（項名）: 正規表現トグル（`.*`ボタン）付きのテキスト検索。既定は部分一致
- **文字列（一覧に無い列）**: 事項名・目名。一覧APIには件数しか無いため、`MOFKouSectionSummary`に`detailNames: string[]`（事項名+目名を項ごとに重複除去）を新規追加し、これも同じ正規表現トグル付き検索で対象にした
- **数値範囲スライダー**（事項数・目数・RS事業数・本年度額・前年度額・増減額・増減率）: デュアルハンドルスライダー（`RangeSlider.tsx`、新規）。金額2列（本年度額・前年度額）は裾が極端に長い分布のため対数目盛（`scale="log"`）、他は線形。可動域は年度全体（他の絞り込みの影響を受けない）から算出。前年度額・増減額・増減率はnullを持つ行があり、範囲を絞ると除外される（未絞り込み時は含める）
- **項（コード）**: 対応しない（ユーザー指示どおり）

RS事業数の範囲スライダーが旧来の「RSあり/なし」セグメントボタンを包含する（0〜0が「なし」、1件以上が「あり」）ため、旧フィルタは削除した。

## 実装

- `types/mof-kou.ts`: `MOFKouSectionSummary`に`detailNames`追加
- `app/lib/api/mof-kou-loader.ts`: `toSummary()`で`row.jikou`/`row.koumoku`から名前を集めて設定
- `client/components/mof-kou/RangeSlider.tsx`（新規）: `<input type="range">`を2本重ねるデュアルハンドル実装。ログスケール対応、直接入力モード切替あり
- `client/components/mof-kou/RegexTextFilter.tsx`（新規）: `.*`トグル付きテキスト検索。不正な正規表現は何もマッチさせない（例外を投げない）
- `client/components/mof-kou/FilterSidebar.tsx`（新規）: 上記を束ねた左サイドパネル本体
- `app/mof-kou/page.tsx`: フィルタ状態を`FilterSidebarState`1個のオブジェクトに統合（個別useStateの羅列から変更）。旧・上部横並びフィルタと「項名を検索」インライン入力・RS有無セグメントボタンを削除

## 検証

- `npx tsc --noEmit` / `npm run lint`: クリーン（既存警告のみ）
- Playwrightで実地確認: 項名の正規表現検索（`^国債(費|整理)`で24件に絞り込み）、事項・目名検索（「職員基本給」で312項に絞り込み＝一覧に出ない内部データへのヒットを確認）、RS事業数レンジスライダーのキーボード操作（下限を3に変更→他条件と組み合わせて0件になることを確認）が正しく動作
