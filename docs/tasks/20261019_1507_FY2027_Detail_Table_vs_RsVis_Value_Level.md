# FY2027 明細表と rs-vis の、頁単位の金額の突き合わせ

rs-vis の金額 34,071 個は、すべて自前の明細表にもある。以前の「金額が違う 519 組」は比較のキーの違いによる見かけで、実体のズレは裁判所 PDF の 64 頁を自前が取りこぼしていることだけ。

## 方法

- 対象: 共通の 115 PDF（FY2027）。自前は `tests/fixtures/budget-request-csv/2027/detail-table/sources/*.csv` の「概算要求額」列、rs-vis は `budget-requests-2027.json.gz` の `accounting_table` の `amounts.request.valueYen / 1000`（origin/main の rs-vis）。
- 比較: (PDF, 物理頁) ごとに金額（千円）の集合（重複を数える）を突き合わせた。事項の名前・コードは使わない。PDF の URL は、URL をデコードして `/` を `__` にしたキーで対応づけた。
- PDF 本文での確認: 食い違った金額を `pdftotext -layout` の頁本文に、桁区切り付きの文字列としてあるか探した。

## 結果

| 項目 | 件数・内容 |
|---|---|
| rs-vis の数値（共通の頁） | 34,071 個。すべて自前にもある |
| 自前だけにある金額 | 22 個。内閣官房 `r9_12` の 2〜5 頁、内閣府 `29` の 2 頁、国交省 `002021868` の 472 頁。rs-vis は `extraction_failed`（全体で 21 レコード）。22 個とも PDF 本文にある |
| rs-vis だけにある金額 | 裁判所 `R09saishutsu_gaisanyokyusho_468kb.pdf` の 64 頁・415 個。415 個とも PDF 本文にある |
| 衆議院 `kaikei-saishutsugaisan9.pdf` | URL のエンコード（`$File` と `%24File`）の違いで別文書に見えただけ。10 頁・111 個は一致 |

## 裁判所 PDF の取りこぼし

- 88 頁の PDF で、自前の明細表 CSV は 7 頁だけ（24 行）。8 頁以降の事項は `05‑0050 定年前再任用…` のように、コードのハイフンが U+2011（non-breaking hyphen）。自前の行の判定が、これを事項の行として拾えていないとみられる（原因の特定は未了）。
- ほか 6 頁（env `000425952` の 39 頁、国交省 `002021868` の 277 頁、総務省 `001091979` の 199・200・210・247 頁）は、rs-vis 側に数値がなく、金額の差には影響しない。

## 修正後の再比較

裁判所の取りこぼしの原因は、明細表の表頭の行の分け方 2 形が未対応だったこと（`budget-request-detail-table.ts` の `headerBoundary`）。対応後、同じ方法で比べ直すと、rs-vis の数値 34,597 個（衆議院の URL エンコード違いを同一視した全体）は、すべて自前にある。取りこぼし 0、自前だけの金額は 22 個のまま。上の表の「34,071 個」は衆議院の 111 個を除いた数。

## 以前の数字の訂正

`20261019_0828_FY2027_PoC_vs_RsVis.md` の「金額が違う 519 組」「rs-vis だけ 2,748」「自前だけ 2,149」は、(頁, コード) をキーにしたときの数。コードの切れ方（空白を含む長いコードや U+2011 を含むコード）の差が主で、金額そのものの食い違いではない。

## 確認していない範囲

- 前年度予算額・比較増減の列。
- 画像（PDF を描画したもの）との照合。数字の存在確認は、PDF の文字層との照合だけ。
