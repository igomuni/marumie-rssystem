## 読み取り
- **文書セットの結びつけで対象に入るのは、文部科学省の `_1`（TOC）→ `_2`（総表）・`_3`（明細表）と、そのほか数 source（FY2025 は TOC を持たない source のうち 3 つ）。** FY2025 で 70 項、FY2024 で 68 項。
- **内閣府（`…r07__pdf__0` 〜 `_50`。`0` が cover-summary で総表のみ、`1`〜`50` が `detail-N`）と内閣官房（`r7_01`〜`r7_17`）は、TOC を持つ PDF が一つもない。** FY2025 で 68 source、明細表の目の行は 4,297 行のうちの大半。TOC を階層の根拠にする契約（確定事項 1）では、これらは起点がない。
- 契約の `CONTEXT` なし（財務省など 64 項）は、この記述の範囲外（別の原因）。

## 突合の出力の抜け（開示）
Matching Result の件数は、TOC を持つ source だけから数えたもの。TOC のない 75 source（FY2025）の総表・明細表の行は、対象外としても出力に記録されていない。

## 次の判断の材料
1. 文部科学省の分割: ファミリーに TOC の source が 1 つで、TOC のない source が属する場合、その TOC に付ける、という機械的な規則で救える（FY2025 で 70 項）。
2. 内閣府・内閣官房: TOC がないので、階層は別の手がかり（明細表の `CONTEXT`・`CODE3` の位置、総表の `HIER`）を使う規則が要る。TOC だけを階層の根拠にするという確定事項 1 を、これらに限って緩めるかを決める必要がある。
