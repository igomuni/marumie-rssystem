# 項一覧のサイドパネル化とページング廃止

`/mof-kou`のUIをインライン行展開からサイドパネル方式へ切り替えた。あわせて項単位の
経年推移機能（新規）を追加し、ページングを廃止、フィルタを`/sankey-svg`のような
折りたたみ式コントロールにまとめた。

## 変更点

1. **行クリック→サイドパネル**: `KouTable.tsx`から行展開ロジックを除去し、選択状態
   （`selectedId`/`onSelectRow`）だけを持つ薄いテーブルに変更。詳細は新設の
   `KouSidePanel.tsx`（幅26remの固定サイドパネル）に出す
2. **サイドパネルのタブ構成**: 年度推移・事項・目・RSの4タブ。事項・目・RSは既存の
   `/api/mof-kou/detail`をそのまま使用。年度推移は新規実装
3. **項の年度推移（新規）**: `app/lib/api/mof-kou-loader.ts`に`sectionHistory()`を追加。
   予算種別・所管を除いた識別子（会計区分・組織/特会/機関・勘定・項コード）で全年度を
   横断する（jikou/kou-mokuのidentityKeyと同じ設計、既存の所管表記変更対応の教訓を踏襲）。
   `/api/mof-kou/history`エンドポイントを新設
4. **ページング廃止**: 項単位の集約で件数が大幅に減った（最大でも2,000件弱）ため、
   フィルタ後の全件をスクロール1画面で表示
5. **フィルタの折りたたみ化**: 常時表示だった会計区分タブ・予算種別・所管・組織・勘定・
   RSフィルタの各コントロールを、`/sankey-svg`のフィルタパネルと同じ発想で「フィルタ」
   トグルボタンの中に格納。キーワード検索と該当件数は常時表示のまま。トグルボタンには
   有効フィルタ数のバッジを付けた
