# 決算の取り込みと事項単位の執行率 — 実現可能性の実測と次の一手

前提: `20260819_0832_予算と決算の違いと令和7年度データの確認.md`。
本書は「次に何ができるか」を、机上ではなく**実際に抽出・突合して測った結果**で判断する。

結論から:

- **決算の事項は取れる。** 令和6年度で1,446事項、5つの金額指標すべてが CSV と完全一致
- **予算の事項と突合できる。** 当初予算の事項の95.9%が決算側に存在し、決算の支出済の95.8%を説明できる
- **事項単位の執行率が出せる。** 中央値86.6%、執行率50%未満が174事項
- 行政事業レビューは一般会計の**執行額ベースで45.4%**をカバーしている（当初予算ベースの37.4%より高い）

---

## 1. 決算の事項抽出は成立する（実測）

令和6年度・一般会計の歳出決算報告書（112ページ）から事項を抽出し、
`DL202477001b.csv`（目レベル）の合計と突き合わせた。

| 指標 | 抽出（1,446事項） | CSV | 差 |
|---|---|---|---|
| 歳出予算額 | 126.51兆円 | 126.51兆円 | 0 |
| 歳出予算現額 | 137.58兆円 | 137.58兆円 | 0 |
| 支出済歳出額 | 123.02兆円 | 123.02兆円 | 0 |
| 翌年度繰越額 | 10.24兆円 | 10.24兆円 | 0 |
| 差引額（不用額） | 4.31兆円 | 4.31兆円 | 0 |

**全指標が1円単位で一致。** 予算の事項別内訳と同じ手法で抽出できる。

### 1-1. 実装上の差分（既存スクレイパへの追加点）

`scripts/generate-mof-jikou-data.ts` は列位置を `<header>` から解決しているが、
**決算では事項表のヘッダ行が `<header>` に入っていない**。`<header>` にあるのは
組織単位の総括表の見出しだけで、事項表の見出し（`項` `事項` `支出済歳出額(円)` …）は
本文の行として現れる。したがって決算では:

1. `running_title` に `歳出決算報告書` を含むページを対象にする（`title_for_list` は組織名で使えない）
2. 本文を走査し、`事項` と `支出済歳出額(円)` を含む行をヘッダとして列位置を取り直す
3. ヘッダ行はページごとに再出現するので、**現れるたびに列位置を更新する**
4. 事項名の列が空・数字のみの行は小計や見出しなので捨てる

この4点を入れないと総額が2倍以上に膨れる（実際に293兆円になった）。

## 2. 予算の事項 × 決算の事項（実測）

令和6年度の当初予算の事項（1,256件・112.57兆円）と決算の事項（1,446件・126.51兆円）を
`組織 + 項コード + 事項名` で突合した。

| 突合キー | 一致 | 当初側カバー | 決算側カバー |
|---|---|---|---|
| 組織 + 項コード + 事項名 | 1,205 | 95.9% | 83.3% |
| 組織 + 事項名 | 1,168 | 96.2% | 85.2% |

**一致した事項が決算の支出済 123.02兆円のうち 117.83兆円（95.8%）を説明する。**

決算にしか無い事項は補正予算で追加されたもので、内訳も明快:

```text
2.15兆  総務本省/物価高騰対応地方創生推進費/物価高騰対応重点支援地方創生臨時交付金に必要な経費
1.30兆  経済産業本省/半導体・人工知能関連技術基盤強化対策費/半導体・人工知能関連技術の基盤強化に必要な経費
0.31兆  文部科学本省/大学等修学支援費/大学等における修学の支援に必要な経費
0.11兆  財務本省/防衛力強化資金へ繰入/防衛力強化資金へ繰入れに必要な経費
```

補正予算の事項別内訳も取り込めば、この差もほぼ埋まる見込み。

## 3. 事項単位の執行率が出せる（実測）

一致した1,205事項の執行率（支出済 ÷ 歳出予算現額）:

```text
中央値      86.6%
90%未満     670件
50%未満     174件
```

事項には予算書の `説明`（所掌事務・根拠法）が付くので、
**「何に使う経費が、いくら積まれ、いくら執行され、いくら不用になったか」を説明文つきで並べられる。**
これは行政事業レビューに載らない事項（国債費・交付税・特会繰入・立法司法）も含めて出せる。

## 4. 行政事業レビューとの三点照合（実測）

| | 歳出予算現額 | 執行額 |
|---|---|---|
| MOF 決算（一般会計） | 137.58兆円 | 123.02兆円 |
| RS（予算年度2024・一般会計、4,450事業） | 66.59兆円 | 55.85兆円 |
| RS のカバー率 | 48.4% | **45.4%** |

当初予算ベースの37.4%（`mof-budget-data-guide.md` 5-4節）より高い。
繰越や予備費を含む「現額」で見ると RS の捕捉範囲が広がるため。

三点（MOF予算 / MOF決算 / RS執行）が揃うと、RS 側の執行額の妥当性を
決算という公式値に対して検証できる。ただし RS の 2-1 は事業単位で科目を持たず、
2-2 は科目を持つが執行額を持たないため、**科目単位の直接照合はできない**。
現実的には所管・項レベルの集計比較になる。

## 5. 次の一手（優先順）

### A. 決算の事項を既存パイプラインに追加する（推奨・小〜中）

`DOCUMENTS` に決算3帳票を足し、`settlement` レイアウトを実装する。

| 帳票 | 事項 | 備考 |
|---|---|---|
| `{YYYY}77001` 一般会計決算 | **あり** | 対象 |
| `{YYYY}78001` 特別会計決算 | なし | 勘定単位の決算・財務諸表のみ |
| `{YYYY}76001` 政府関係機関決算 | なし | 収入支出決算のみ |

`MOFJikouItem` に執行系のフィールド（`currentAmount` 現額 / `spent` 支出済 /
`carriedOver` 翌年度繰越 / `unused` 不用額）を任意項目として足す。
既存の当初・暫定・補正は null のままでよい。`budgetType` に `決算` を追加する。

対象年度: 令和5年度（`mof_2023`）と令和6年度（`mof_2024`）の決算が既にローカルにある。

### B. 事項単位の執行率ビュー（中）

`/mof-jikou` に決算年度を足し、予算↔決算を `組織+項コード+事項名` で結合して
執行率・不用額を列に出す。並べ替えは既にあるので、**不用額の大きい順**や
**執行率の低い順**がそのまま使える。95.9%が結合できるので実用に足りる。

### C. サンキー図（中〜大）

事項単位で「歳出予算額 → (＋補正・繰越・予備費) → 歳出予算現額 → 支出済 / 翌年度繰越 / 不用」
の流れが描ける。既存の `/mof-budget-overview` が当初予算の静的スナップショットなのに対し、
こちらは**執行の結果まで含む**ので情報量が違う。

### D. RS との三点照合（要検討）

科目単位の直接照合ができないため、所管・項レベルの集計比較に留まる。
B・C を先に作ってから、必要になった時点で判断するのが順当。

## 6. 留意点

- **決算は年度終了後に公表される**ため、常に最新年度は予算のみ。令和7年度の決算はまだ無い
- 決算 CSV は**円単位**（予算は千円）。JSON 側は既に円へ正規化済みなので、
  決算を足すときは1000倍しないよう注意する
- 予算と決算を同じ一覧に混ぜる場合、`budgetType` で明確に分けないと
  「同じ事項が2回出る」ように見える。会計区分の合算禁止と同じ扱いが要る
