# 項一覧ページの新設（/mof-kou）

`/mof-jikou`（事項＝目的別内訳）と`/mof-kou-moku`（目＝性質別内訳）は、共通の親である
「項」の下に並列にぶら下がる別系統の内訳（対応表なし）。両者をさらに一段引いて、
項ごとに「事項が何件・目が何件あり、目の完全一致でRS事業に何件紐づいているか」という
関係性だけを見る一覧ページを新設した。

## 実装

- `types/mof-kou.ts`: `MOFKouSectionSummary`（一覧行）・`MOFKouSectionDetail`（展開時の詳細）・`MOFKouData`
- `app/lib/api/mof-kou-loader.ts`: 専用の生成JSONファイルは持たず、既存3系統（mof-jikou・
  mof-kou-moku・mof-rs-kou-moku-linkage）の読み込み結果をリクエスト時に項単位へ束ねる。
  特別会計名の接尾辞差（事項側「〜特別会計」・目側接尾辞なし）を吸収した上で結合キーを作る
  （事項側・目側の金額合計が全1054項で完全一致することを2024年度で確認済み）
- `app/api/mof-kou/route.ts`: 一覧API（集計行のみ、事項・目の内訳やRS事業一覧は含まない）
- `app/api/mof-kou/detail/route.ts`: 行展開時にのみ取得する詳細API（事項一覧・目一覧・RS事業一覧）。
  一覧APIに全項ぶんの内訳を同梱すると数十MBになるため分離
- `client/components/mof-kou/`: `columns.ts`・`KouTable.tsx`
- `app/mof-kou/page.tsx`: フィルタ・ソート・列幅リサイズ・ページングは`/mof-kou-moku`と同じ操作感。
  行そのものが集計値（事項数・目数・RS事業数）を持つため、一覧側にRS紐づけ用のバッジ列は無い
  （既存2ページと異なる点）
- `PageNavMenu.tsx`にページを追加

## 列構成

予算種別・会計区分・所管・組織／特会／機関・勘定／業務・項コード・項名・事項数・目数・
RS事業数・本年度額・前年度額・増減額・増減率（主要経費は項単位では複数混在しうるため省略）。

## 確認

- 2024年度・当初予算: 全1,054項中、RS事業に1件以上紐づく項は692件
- 2024年度・全予算種別合計: 全3,321項中、RS事業に1件以上紐づく項は1,829件
- 展開時の詳細パネル（事項一覧・目一覧・RS事業一覧）、決算目の予算種別間引き継ぎ・
  年度をまたぐ引き継ぎの表示もブラウザで確認済み
