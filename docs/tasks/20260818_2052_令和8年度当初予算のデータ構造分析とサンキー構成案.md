# 令和8年度一般会計当初予算のデータ構造分析とサンキー構成案

目的: 予算（財務省 予算書DB）と RS システム（行政事業レビュー）の事業を紐づけ、新しいサンキー図を作る。本書は第1段階として「予算側のデータ構造」を確定し、突合の実測値をもとに構成案を壁打ちする。

対象:

- Web: `https://www.bb.mof.go.jp/server/2026/html/202611001Main.html`（令和8年度一般会計予算・当初予算）
- ローカル: `data/download/mof-2026/DL202611001.zip`
- RS側: `data/download/RS_2025/2-2_RS_2025_予算・執行_予算種別・歳出予算項目.zip`

---

## 1. 予算書DB（Web）の構造

`202611001Main.html` はフレームセット。実体は以下の3つ。

| フレーム | ソース | 中身 |
|---|---|---|
| titleFrame | `202611001top.html` | タイトル |
| menuFrame | `202611001menu.html` | 目次（`LineOut(階層, 子有無, 表題, リンク, 頁)` を並べた JS） |
| contentsFrame | `../xml/2026110019xxxxxa.xml` | 本文（Shift_JIS の XML + XSL） |

目次は `LineOut()` 437行。文字コードは menu が EUC-JP、本文 XML が Shift_JIS（宣言どおり）。

### 1-1. 書類の階層

```text
令和8年度一般会計予算
├ 予算総則
├ 甲号歳入歳出予算        … 歳入（主管別）/ 歳出（所管別）
├ 乙号継続費
├ 丙号繰越明許費
└ 丁号国庫債務負担行為
(添付) 公債償還計画表
令和8年度一般会計予算参照書
├ 歳入予算明細書          … 主管 > 部 > 款 > 項 > 目
└ 各省各庁予定経費要求書等
   ├ 予定経費要求書主要経費別表
   └ 所管ごと(19)
      ├ 甲号予定経費要求書
      │  ├ 〔組織別事項別内訳〕 ← 組織 > 項 > 事項（97ページ）
      │  └ 科目別内訳          ← 組織 > 項 > 目（96ページ）
      ├ 丙号繰越明許費要求書
      ├ 丁号国庫債務負担行為要求書
      └ 予算定員及び俸給額表
```

### 1-2. 本文 XML のスキーマ

`<budget>` 直下に `fiscal_year` / `types_of_account` / `types_of_budget` / `handings_of_budget` / `title_for_list` / `running_title`（= 「内閣府所管  内閣本府」）、続いて `<body layer="N">` に `<table><header>…</header><data>…</data></table>`。

セルは `<clm id="p{頁}-{行}.{行内連番}-{列}.{列内連番}">` で、`id` から**頁・行・列が復元できる**。テキストは `<p><l><![CDATA[…]]></l></p>`（折り返しごとに `<l>`）。つまり XSL を使わずとも `id` のパースだけで表を再構成できる。

〔組織別事項別内訳〕の列構成:

| 列 | 内容 |
|---|---|
| 1 | 組織 |
| 2 | 項コード |
| 3 | 項名 |
| 4 | 主要経費別分類コード |
| 5 | **事項名**（例「拉致被害者等の支援に必要な経費」） |
| 6 | 本年度要求額（千円） |
| 8 | 前年度予算額（千円） |
| 10 | 比較増△減額 |
| 11 | **説明**（所掌事務・根拠法の記述） |

全97ページを取得して機械抽出したところ、**事項は 1,309 件、合計 122,357,637,958 千円**（後述の CSV 合計との差 0.04%。折り返し行の取りこぼし分と見られる）。

## 2. ローカル ZIP との突き合わせ

`DL202611001.zip` の中身は2ファイル。既存の `mof_2021`〜`mof_2024` と同じ命名規則。

| ファイル | 行数 | 対応する Web 上の書類 |
|---|---|---|
| `DL202611001a.csv` | 431 | 歳入予算部款項目別表（主管/部/款/項/目 + 令和8年度予算額） |
| `DL202611001b.csv` | 6,791 | **科目別内訳**（所管/組織/項/目 + 令和8年度要求額） |

`DL202611001b.csv` のヘッダ:

```text
所管,組織,項コード,主要経費別分類コード,目的別分類コード,財政法公債金対象非対象別分類コード,
経済性質別分類コード,使途別分類コード,目別分類コード,項名,目名,
令和8年度要求額(千円),前年度予算額(千円),比較増△減額(千円)
```

`mof_2023` の `DL202311001b.csv` と**列構成は完全に同一**で、差は年号入り列名（`令和5年度要求額(千円)` → `令和8年度要求額(千円)`）のみ。既存パーサはこの1点だけ吸収すれば通る。

集計値:

- 所管 19 / 所管×組織 96 / 所管×組織×項 824 / 行（＝目レベル）6,790
- 合計 **122,309,247,035 千円 = 約 122.3 兆円**
- 組織数 96 は Web 目次の「科目別内訳」ページ数 96 と一致

### 2-1. 重要な差分：CSV には〔事項別内訳〕が入っていない

ZIP に含まれるのは**科目別内訳（目レベル）だけ**で、〔組織別事項別内訳〕の**事項名と説明文は CSV に存在しない**。

これは今回の目的に直接効く。目名は「庁費」「職員基本給」「委託費」といった**支出の性質**の分類であり、事業を指さない。事業らしい名前が付いているのは事項（「拉致被害者等の支援に必要な経費」）の方で、RS の事業名と意味的に対応するのはこちらである。

→ **事項レベルを使うなら Web の XML をスクレイピングする必要がある**（97ファイル・約1.7MB、`id` パースで機械可読）。

## 3. RS システム側との突合（実測）

RS の `2-2_予算・執行_予算種別・歳出予算項目` が結合キーを持つ。1行 = 予算事業ID × 歳出予算項目。

```text
シート種別,事業年度,予算事業ID,事業名,…,予算年度,会計区分,会計,勘定,予算種別,
所管,組織・勘定,項,目,歳出予算項目の補足情報,予算額（歳出予算項目ごと）,翌年度要求額（…）,備考
```

**`所管 / 組織・勘定 / 項 / 目` が MOF CSV の `所管 / 組織 / 項名 / 目名` と同じ語彙**。つまり目レベルでの結合は名前一致で成立する。

RS_2025・予算年度2025・一般会計・当初予算に限ると: 11,001行 / 4,097事業 / 科目キー3,314種 / 43.4兆円。

### 3-1. 結合率（MOF 令和8年度 × RS 2025年度）

年度が1年ずれている点は留保（RS 2026 は未公表）。構造キーの一致率として読む。

| 粒度 | MOF側キー数 | 一致 | MOF金額のカバー率 |
|---|---|---|---|
| 所管×組織 | 96 | 78 | 99.1% |
| 所管×組織×項 | 824 | 577 | 38.0% |
| 所管×組織×項×目 | 6,790 | 3,111 | **33.8%** |

### 3-2. 繋がらない 66% の内訳

| 区分 | 金額 | 比率 |
|---|---|---|
| A: RS に紐づく（科目キー一致） | 41.3兆円 | 33.8% |
| B: 他会計・地方への移転（国債費・交付税・特会繰入） | 68.8兆円 | 56.3% |
| C: RS 対象外機関（国会・裁判所・会計検査院・皇室費・人事院・宮内庁等） | 0.5兆円 | 0.4% |
| D: 未分類（要精査、年度ずれ由来を含む） | 11.6兆円 | 9.5% |

未一致の大口（項レベル）:

```text
31.3兆  財務省/財務本省/国債費
20.1兆  総務省/総務本省/地方交付税交付金
13.3兆  厚生労働省/厚生労働本省/基礎年金拠出金等年金特別会計へ繰入
 2.6兆  内閣府/こども家庭庁/児童手当等子ども・子育て支援特別会計へ繰入
 1.6兆  防衛省/防衛本省/自衛官給与費
 1.0兆  財務省/財務本省/予備費
```

**「予算のすべてが RS に繋がらない」の正体は、大半が構造的に当然の移転的経費**（国債償還・地方交付税・特会繰入）である。RS が事業として持たないのは設計どおりで、欠損ではない。逆に言えば、B を「繋がらない」ではなく**「別の行き先へ流れる」として可視化すれば、サンキー図として自然に閉じる**。

D の 11.6兆円は年度ずれ（R8 で新設・改称された項目は R7 の RS に無い）と、給与費・庁費など事業に割り付かない経費が混在している。ここは精査対象。

## 4. サンキー構成案（たたき台）

### 案1: 一般会計の出口を1枚で見せる（推奨の起点）

```text
一般会計 122.3兆
 ├→ 国債費 31.3兆 →（国債整理基金特会）
 ├→ 地方交付税等 20.9兆 →（交付税特会 → 地方）
 ├→ 特別会計へ繰入 16.5兆 →（年金・こども・エネ特会）
 ├→ 各省事業費 41.3兆 → 所管 → 組織 → 項 → 【RS事業】→ 支出先
 └→ 対象外機関・その他 12.1兆
```

左半分は MOF CSV だけで作れる。右半分の「RS事業 → 支出先」は既存 `/sankey-svg` のグラフそのものなので、**既存資産に MOF 側の上流3〜4層を接ぎ木する形**になる。既存の `/mof-budget-overview` が扱っていた「一般会計→特別会計」の流れは、この左半分に吸収できる。

### 案2: 事項を中間層に挟む（要スクレイピング）

```text
所管 → 組織 → 項 → 事項(1,309) → RS事業(4,097) → 支出先
```

事項は MOF 側で唯一「事業らしい」粒度で、しかも**説明文を持つ**。ただし事項と RS 事業は 1:N（1,309 対 4,097）で、両者を直接結ぶキーは無い。突合は次のいずれかになる。

1. 項レベルまで両者を落として集約（確実だが粒度が粗い＝577項）
2. 事項名 × RS事業名の文字列/意味的マッチング（`/project-bubble` で使った埋め込みが流用できる）
3. 事項の「説明」文と RS の事業概要の照合

まず 1 で骨格を作り、2/3 を精度改善として後付けするのが安全。

### 案3: カバー率そのものを主題にする

「予算のどこまでが事業として説明されているか」を可視化する図。A/B/C/D の4区分を色分けし、D を掘れるようにする。政策的な訴求力は高いが、分類の妥当性を説明できる状態にしてからでないと誤読を招く。

## 5. 論点（要判断）

1. **年度をどう揃えるか**。MOF は令和8年度（2026）、RS の最新は 2025年度。RS 2-2 には `翌年度要求額（歳出予算項目ごと）` があり R8要求額に相当するので、これを使えば同年度で並べられる可能性がある（要検証）。あるいは MOF 側を令和7年度（`DL202511001`）に揃える。
2. **事項レベルを取りに行くか**。取るならスクレイパを `scripts/` に新設し、`data/download/mof-2026/` に中間 CSV を落とす形。取らないなら項レベルで止まる。
3. **既存 `/mof-budget-overview` をどう扱うか**。ハードコード多数で年度更新できない状態なので、新ページとして作り直し、旧ページは残置か廃止かを別途決める。
4. **ローカルの ZIP は当初予算の一般会計のみ**。特別会計（`DL202612001`）・政府関係機関（`DL202613001`）は未取得。特会への繰入先を描くなら特会側も要る。
