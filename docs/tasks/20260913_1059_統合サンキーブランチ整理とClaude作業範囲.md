## Claude側の作業範囲

同一ディレクトリで作業するため、Codex復帰時のファイルはClaudeの変更後の状態になる。
元の状態から再開する場合は `git checkout feature/integrated-sankey-first-cut` で戻す。

競合を最小化するため、**1〜4に限定し、5は行わない**。

| # | 内容 | 実施 |
| --- | --- | --- |
| 1 | page.tsx:64 の構文エラー修正（`}` 1個）、tscを通す | 未 |
| 2 | e2eテストを新ページ仕様へ書き換え | 未 |
| 3 | 基準実測値（MOF一致119.37兆円等）との集計検証テスト追加 | 未 |
| 4 | 仕様書・INDEXの「未実装」表記を実態に合わせ更新 | 未 |
| 5 | page.tsxの構造整理（圧縮コードの可読化・分割） | **対象外** |

5を対象外とする理由：page.tsxは1行1000文字級の圧縮された書き方で統一されている。
これを整形するとCodex復帰後の差分が全面的に衝突し、どちらの変更も追えなくなる。
整形するならCodexがファーストカットを完了させた後、独立した変更として行う。
