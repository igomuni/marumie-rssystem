# 年度切替時の状態維持とサイドパネルヘッダー再設計

## 年度切替時の状態維持

`app/mof-kou/page.tsx`の`changeYear()`が年度変更のたびにフィルタ（`setFilters(INITIAL_FILTERS)`）と選択行（`setSelected(null)`）をリセットしていたのをやめ、`setYear`/`setData(null)`のみにした。列幅（`widths`）・フィルタパネル幅（`sidebarWidth`）・詳細パネル幅（`panelWidth`）は元々リセット対象外で既に維持されていた。

選択行の維持は、項の合成キー（`sectionKey`。所管を含む）が新年度のデータにも存在すれば`selectedRow`が引き続き解決される、という既存の仕組みにそのまま乗る形。所管の共管表記が年度をまたいで変わる項（例: 基礎年金給付費が「厚生労働省」→「内閣府及び厚生労働省」など）は、既存の別項判定の仕組み上、年度をまたぐと選択が外れる（`/mof-kou`の経年推移機能と同じ既知の制約で、今回新たに導入したものではない）。

## サイドパネルヘッダーの再設計

`client/components/mof-kou/KouSidePanel.tsx`のヘッダーを3行構成に変更:

- 1行目: 項名（大きめのフォント）＋予算種別バッジ＋会計区分バッジ（項名の右隣）
- 2行目: 所管・組織・勘定・出典リンク
- 3行目: 本年度額（大きめのフォント）・前年度額・増減率
- 事項数・目数・RS事業数は削除（タブのラベルに件数が出ているため重複）

## その他確認事項

- フィルタのチェックボックス付きコンボボックスは、外側クリックで既に正しく閉じることをPlaywrightで確認（新規の不具合は見つからず）

## 検証

- `npx tsc --noEmit` / `npm run lint`: クリーン
- Playwrightで、識別子が年度間で安定した項（財務省・国債整理支出）ではフィルタ・選択行ともに年度切替後も維持されることを確認
