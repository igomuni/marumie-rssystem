# 予算書と決算書の違い、および令和7年度データの確認

対象: `https://www.bb.mof.go.jp/archive/reiwa6.html`（令和6年度）と `reiwa7.html`（令和7年度）。
令和7年度の ZIP 5本を `data/download/mof_2025/` に取得済み。

要点:

- 決算は予算とは**別系列の帳票**で、**金額の単位が円**、列も executed ベースで完全に別物
- **一般会計の歳出決算報告書には事項レベルがある**。予算の事項と同じ粒度で「予算 → 執行 → 不用」まで取れる
- 特別会計の決算には事項レベルが無い（勘定単位の決算・財務諸表のみ）
- 令和7年度は**提出版と修正成立版の2系統**が同じファイル名で別ディレクトリに置かれている
- 令和7年度 補正特別会計だけ ZIP 内の `a` / `b` の役割が入れ替わっている

---

## 1. 同じ年度に予算と決算の2系列がある

令和6年度（`reiwa6.html`）の掲載物:

| 系列 | 区分 | 帳票ID | 表題 |
|---|---|---|---|
| 予算 | 当初・一般会計 | `DL202411001` | 歳入予算明細書及び歳出予定経費要求書(科目別内訳) |
| 予算 | 当初・特別会計 | `DL202412001` | 歳入歳出予定額科目別表 |
| 予算 | 当初・政府関係機関 | `DL202413001` | 収入支出予定額科目別表 |
| 予算 | 補正第1号・一般会計 | `DL202421001` | 歳入予算補正明細書及び歳出予定経費補正要求書 |
| 予算 | 補正第1号・特別会計 | `DL202422001` | 歳入歳出予算補正予定額科目別表 |
| **決算** | 一般会計 | `DL202477001` | 歳入決算明細書及び歳出決算報告書(科目別内訳) |
| **決算** | 特別会計 | `DL202478001` | 歳入歳出決算額科目別表 |
| **決算** | 政府関係機関 | `DL202476001` | 収入支出決算額 |

決算の区分コードは `76`（政府関係機関）/ `77`（一般会計）/ `78`（特別会計）。
令和7年度（`reiwa7.html`）には決算がまだ無く、予算のみ。

## 2. 決算 CSV は単位も列も別物

**単位が円**（予算は千円）。列は予算額から執行結果までを1行に並べる。

一般会計・歳出（`DL202477001b.csv`、6,962行）:

```text
所管,組織,項コード,主要経費別分類コード,目的別分類コード,財政法公債金対象非対象別分類コード,
経済性質別分類コード,使途別分類コード,目番号,項名,目名,
歳出予算額(円),前年度繰越額(円),予備費使用額(円),流用等増△減額(円),予算決定後移替増△減額(円),
歳出予算現額(円),支出済歳出額(円),翌年度繰越額(円),不用額(円)
```

予算 CSV との差:

- 金額列が3本（本年度・前年度・増減）から**9本**に増える
- `目別分類コード` が `目番号` に改称される
- 単位が千円から円になる

この列構成は行政事業レビューの `2-1_予算・執行_サマリ`（歳出予算現額・執行額・翌年度への繰越し・不用）と**同じ枠組み**で、概念がそのまま対応する。

歳入（`DL202477001a.csv`）は `歳入予算額 / 徴収決定済額 / 収納済歳入額 / 不納欠損額 / 収納未済歳入額 / 差` の6本。

## 3. 決算にも事項レベルがある（一般会計のみ）

Web 帳票の「各省各庁歳出決算報告書」は組織別で、その中に**事項の表**を持つ。

```text
項 / 事項 / 歳出予算額 / 前年度繰越額 / 予備費使用額 / 流用等増△減額 /
予算決定後移替増△減額 / 歳出予算現額 / 支出済歳出額 / 翌年度繰越額 / 差引額   （すべて円）
```

実例（内閣本府、`202477001000115a.xml`）:

```text
001 内閣本府共通費 95 内閣本府一般行政に必要な経費
    予算 25,474,895,000 → 現額 25,807,027,801 → 支出済 23,268,933,943 → 差引 2,328,290,040
    95 拉致被害者等の支援に必要な経費
    予算 416,165,000 → 支出済 12,649,582 → 差引 403,515,418
```

**事項名は予算書の事項別内訳と同じ**なので、予算側の事項と決算側の事項は名前で突き合わせられる見込み。
予算書の事項別内訳が持つ `説明`（所掌事務・根拠法）は決算には無く、代わりに組織単位の `備考` がある。

判別方法: `title_for_list` は組織名になるため使えない。`running_title` が
「内閣府所管　歳出決算報告書　内閣本府」の形になるので、**`歳出決算報告書` を含むかで判定する**。

特別会計の決算（`202478001`）は勘定ごとの歳入歳出決算・財務諸表・債務計算書で、
**事項レベルの歳出決算報告書は無い**。政府関係機関（`202476001`）も収入支出決算のみ。

## 4. 令和7年度は提出版と修正成立版の2系統

同じファイル名で置き場が違う。

```text
修正成立版: https://www.bb.mof.go.jp/server/2025/csv/DL202511001.zip
提出版    : https://www.bb.mof.go.jp/server/2025_teishutsu/csv/DL202511001.zip
```

2系統あるのは一般会計（`11001`）と特別会計（`12001`）のみ。政府関係機関と補正は1系統。

国会修正の内容が実際に効いている:

| ファイル | 提出版 | 修正成立版 | 差 |
|---|---|---|---|
| 一般会計 歳出 | 115,541,501,128 千円 | 115,197,845,248 千円 | **-3,436.6億円** |
| 特別会計 歳出 | 429,494,228,883 千円 | 429,481,228,883 千円 | -130億円 |

金額が動いた科目（一般会計歳出、上位）:

```text
財務省/財務本省/予備費                       1,000,000,000 → 739,482,688 (-2,605億円)
総務省/総務本省/地方交付税交付金             18,884,788,150 → 18,679,237,150 (-2,055億円)
文部科学省/文部科学本省/高等学校等修学支援事業費補助金  15,641,746 → 121,056,661 (+1,054億円)
```

`scripts/generate-mof-jikou-data.ts` は `BASE = .../server/{年度}` を見るので、
**令和7年度を取り込むと自動的に修正成立版になる**。意図としては正しいが、明示的な選択ではないので注意。

## 5. 配布物の不整合2件

### 5-1. `a` / `b` の役割が入れ替わっている帳票がある

全25 ZIP を調べたところ、通常は `a` = 歳入形式・`b` = 歳出形式だが、
**令和7年度 補正・特別会計（`DL202522001`）だけ逆**になっている。

```text
DL202522001a.csv → 歳出形式（主要経費別分類コードを持つ）
DL202522001b.csv → 歳入形式（款コードを持つ）
```

ファイル名で歳入・歳出を決め打ちすると壊れる。**ヘッダの列で判定すること**
（`主要経費別分類コード` があれば歳出、`款コード` だけなら歳入）。

### 5-2. 金額列名の `(千円)` の有無が揺れる

```text
令和6年度         : 令和6年度要求額           ← (千円) なし
令和7年度 提出版  : 令和7年度要求額           ← (千円) なし
令和7年度 修正成立: 令和7年度要求額(千円)
令和7年度 政府関係機関: 令和7年度予定額        ← (千円) なし
令和8年度         : 令和8年度要求額(千円)
```

`令和\d+年度` の前方一致で拾うこと（`mof-budget-data-guide.md` 2-5節に既出）。

## 6. 次に検討できること

1. **決算の事項を取り込む**。`generate-mof-jikou-data.ts` に決算レイアウトを足せば、
   事項単位で「予算 → 執行 → 不用」が見える。判別は `running_title` の `歳出決算報告書`
2. **予算の事項 × 決算の事項** を名前で突き合わせ、事項単位の執行率・不用率を出す
3. 行政事業レビューとの三点照合（MOF予算 / MOF決算 / RS執行実績）。
   決算の列構成が RS 2-1 と同じ枠組みなので、金額の妥当性検証に使える
