## 3. 範囲

- **一般会計と特別会計は分母を分ける。** `budget-jikou` は一般会計のみなので、特別会計の DETAIL 行は、K1〜K3 では「MOF 側に対応データが無い（out of scope）」とし、突合不能（unmatched）に入れない。`budget-items` は特別会計も持つ。
- 結果は2通りで出す: 明細表の全行に対する coverage と、MOF 側に対応データがある eligible subset に対する coverage。
- 「MOF にだけある」行は、明細表→MOF の unmatched ではなく、逆方向の coverage として別集計する。
- **目コード欠け（15.6%）は、`budget-jikou` との突合では原因にならない**（`jikou` は目コードを持たない）。`budget-items`（K4）では、厳密な形に合う行では欠けは第2区画のみで、第3区画（目）は残るので、影響は限定的な見込み（仮説。形に合わない188行は別）。P1 の原因分類は、対象データごとに、P0 の後に確定する。
