# FY2027（令和9年度）の概算要求を、この repo のパイプラインで作り、rs-vis と比べる

状態: 試行（PoC）。FY2027 の PDF 122 件（5,122 頁）を、FY2026 と同じ流れで plain text → 総表・明細表・TOC・表紙の CSV まで作った。rs-vis（`/budget-requests`、2027 年度）の抽出と、PDF・頁・コード・要求額の組で比べると、一致は約 88%。どちらが正確かは、まだ判定していない。

## 実施したこと
- 入口は財務省の令和9年度索引（`fy2027/index.html`）。一般会計 `20260904185021.html`（38 行）、特別会計 `2026yokyutokkai_link.html`（35 行）の掲載ページを巡回し（41 ページ、37 件が 200、PDF リンク 1,679）、候補 284 PDF から、令和9年度の歳出概算要求書 103 件を確認した。
- rs-vis にあって自前の探索で漏れていた 17 件（内閣官房 15・個人情報保護委員会 1・内閣府 29）を、rs-vis が拾ったURLから取得して追記した。防衛省・外務省の 2 件は、スクリプトからは 403 だったため、Codex（ブラウザ）で取得して追記した。計 **122 PDF**（一般 94・特別 26・会計不明 2）。FY2027 は MOF の予算書がまだなく、MOF との突合は行っていない。
- 未取得: 経産省（掲載ページが 403 で、PDF の所在が不明）と厚労省（rs-vis も数値を抽出できていない）。

## rs-vis との比較（accounting_table。FY2027）
- rs-vis: 資料 876（PDF 791）、うち数値を抽出できた会計表 116、レコード 41,430。値の状態は `numeric` 34,597・`blank` 89,672・`extraction_failed` 21。
- PDF の集合: 共通 97、rs-vis だけ 19（内閣官房 15 など。探索の違いによる。上のとおり取り込み済み）、自前だけ 6。
- 共通の 113 PDF で、(頁, コード, 要求額（千円）) の組を比較:
  - 完全に一致: 30,814 組。rs-vis だけにある組 3,672（rs-vis の 11%）、自前だけにある組 4,181（自前の 12%）。
  - (頁, コード) 単位では、一致 24,766、金額が違う 519、rs-vis だけ 2,748、自前だけ 2,149。
- 差の主な原因（確認できたもの）:
  - 比較のキー。自前は事項の先頭の語をコードとして使うため、空白の入る長いコード（`95199- 815…`）は切れて別のキーになる。rs-vis は完全なコードを持つ。一部は、比較の側の都合の差。
  - 同じ頁・同じコードの行が複数ある場合の扱い（rs-vis は別レコード。自前は事項の継続行にまとめることがある）。
  - 要求額が負の行は両方に現れる。jcrc `000002960.pdf` 9 頁の「定員合理化に伴う経費」は、原文でも要求額が `△12,718`。バグではなく原本の値。
- 精度の判定は未実施。差のある行を、原本（PDF）で確認する作業が要る。

## 参考にできそうな箇所（rs-vis から）
1. **PDF の探索（リンクをたどる深さ・絞り込み）**: PDF の取得・確認の段階ではなく、PDF を見つける段階の違い。
   - rs-vis は、掲載ページから HTML のリンクを最大 3 階層までたどり、途中のページの PDF も拾う。自前は、掲載ページを 1 回開いて、そのページに載る PDF のリンクだけを拾う。
   - 自前は、さらにリンク文字か URL に「概算要求」などと年度があるものに絞る。
   - 取りこぼし: 内閣官房（財務省の一覧が指す入口ページの 1 つ先の年度ページに PDF がある。階層の違い）、個人情報保護委員会（掲載ページに PDF のリンクはあるが、要求書のリンク文字に年度がなく、絞り込みで落ちた。絞り込みの違い）。FY2026 でも同じ型の取りこぼしがあった（内閣法制局・個人情報保護委員会・参議院）。
   - PDF をダウンロードして先頭 2 頁で令和N年度・歳出概算要求を確かめる段階は、両者とも同じように行っている。
2. **値の状態の区別**: rs-vis は `numeric` / `blank` / `extraction_failed` を持つ（仕様では `事項要求` も区別するとあるが、2027 年度のデータには `事項要求` の状態が 0 件。47 レコードの原文に「事項要求」が出る）。自前の CSV は空欄を空欄のまま出すだけで、状態を持たない。
3. **レコード単位の出所**: 各レコードに PDF の頁・座標・原文抜粋・原本ハッシュを持つ。自前は、CSV の行に頁・行番号（`source_page`・`source_line_start`）を持つ。
4. **コードの階層**: rs-vis は `itemCodes` で 組織→項→事項→目 の階層コードを配列で持つ。自前は、MOF との突合の段階で階層を作る。
5. **事項要求の数**: 自前の plain text で、FY2027 は 73 箇所・20 PDF（括弧書き 54）（防衛省・外務省を加えた後）。FY2023〜FY2026 は 80〜138 箇所。FY2027 が少ないのは、経産省・厚労省の PDF が未取得であることなどが理由と見られる（未確認）。

## 方向性の確認（大きなずれがないか）
- **集合**: PDF の集合は、共通 97、rs-vis だけ 19（PDF の探索の違い。取り込み済み）、自前だけ 6。
- **行の金額**: 共通の PDF で、(頁, コード) が両方にある 25,285 組のうち、金額まで一致が 24,766 組（97.9%）。金額が違う 519 組は、同じ頁・同じコードの行が複数ある場合の扱いの違いが主で、系統的な食い違い（桁・単位・列の取り違え）は見つかっていない。
- **合計額**: rs-vis が「合計（total）」とした 88 レコードのうち、自前の総表に対応する表がある 47 件は、**47 件すべて金額が一致**（食い違い 0）。残り 41 件は、自前に総表のない PDF（明細表の PDF にある合計行など）で、比較できない。逆に、自前の総表の TOTAL 行（rs-vis が total を持つ PDF）67 件のうち 57 件は、rs-vis の total に同額がある（残り 10 件は rs-vis が別の区分にしたとみられるが、未確認）。
- **単位**: rs-vis は円（千円×1,000）、自前は千円のまま。換算して一致する。
- 結論: 方向性として、大きなずれはない。差は、粒度・キー・区分の扱いの違いに見える。どちらが正確かの判定には、差のある行を原本で確認する作業が要る。
