## 4. 項 → 事項 hierarchy

分類（P3）: **B（Deterministic but indirect）**。
- [事実] 項と事項は XML の親子 tree になく、同一の平坦な `data/clm` 列に並ぶ。専用の group identifier・row span 属性もない（A ではない）。

## 5. Text reproducibility

- [事実] 名称は固定幅で折り返され `<l>` に分割される（事項名 1,256 件中 1,250、項名 784 件中 713 が複数 `<l>`）。折返しは語の途中でも起きる（例:「国際観光旅客税財｜源宮廷に必要な経｜費」）。`<l>` を区切り無しで連結した名称に空白は無い（字間スペース 0・全角スペース 0）。→ 行の区切りに意味は無く、連結で 1 つの名称になる[解釈]。
