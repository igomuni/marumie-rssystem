## 実装上の注意と、実行時に起きたこと
- **`所管` 列は、復興庁のファイルでは「ファイル内の所管の行」の値**（復興庁・総務省・財務省）。他のファイルでは目次の祖先 chain の所管（公式 CSV の `所管` と同じ文字列）。復興庁のファイルでは公式 CSV の `所管` は長い一覧で、ファイル内の所管は `共管所管名` に当たる。契約 §2 の「所管の行＝以降の組織の所管」に従った解釈で、契約の文言からは一意でないため、ここに記す。
- **最初の実行が、実装 commit の前に走り、1 回止まった**: 特別会計のタイトルは XML の中で空白を含む形で、一致比較が空白ありのままだったため target が 0 になり、population の検査で停止した（出力なし）。source set は空白を除いて作っていたので、parser 側も同じ（空白を除く）に直して commit し、その後に実行した。規則の追加ではなく、source set の定義との整合。
- 確認スクリプト `scripts/research/check-mof-jikou-special.py` は、実行前に commit した（確認の内容は契約 §5）。
- parser v0・一般会計の複製は無変更（部品の export のみ）。
