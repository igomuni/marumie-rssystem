# 明細表 CSV v0 の取りこぼしの原因分類（未解決の左側の行 1,573、頁が見つからない総表の行）

状態: 調査（read-only、実装なし）。結論: **未解決の左側の行1,573のうち、77.6%（1,220行）は、備考の内容が左側から始まっているもので、取り損ねではない。** 取れる可能性があるのは、22.4%（353行）で、これは**空欄の列が決まらなかった485行の、名称の継続行**（連鎖）。総表の `明細書頁数` が見つからない189行は、**149行が明細表側にラベルが無い**（エネルギー対策特別会計の5つの PDF が146行）ことによる。原因の族が別なので、集計と分類を分けた。
再現: `python3 -I scripts/research/isolate-detail-table-failures.py`（2回実行して出力が一致。標準出力の SHA-256 `a7779292…e432`）。入力は、ローカルの生成物（明細表・総表の CSV と、plain text の zip）。

## 1. 方法

- 対象は、明細表 CSV v0（`budget-request-detail-table-csv.md`）の `unresolved.csv` と、総表の CSV。
- 判定は、行の文字・位置・前後の行だけで行う。補完・推測・外部知識・PDF の目視は使わない。分類は記述的な集計で、精度の評価ではない。

## 2. A: 未解決の左側の行 1,573（`LEFT_*`）

内訳（理由）は、隣接しない 708、そのページに直前の行が無い 535、境をまたぐ 314、揃わない 16。**1,156行（73.5%）は、文部科学省の1つの PDF**（`mext…kaikesou01-000…`）に集中している。以下の分類は、理由とは別の軸（文字の特徴と前後の行）で行った。

| 族 | 行数 | 判定の根拠 | 意味 |
|---|---|---|---|
| A1 罫線の表 | 262 | 罫線の文字（`│` など）がある | 備考の表 |
| A2 備考の表の行 | 445 | 金額と括弧つきの金額（`168 (  168)`） | 備考の表（内訳表）の行 |
| A3 番号・箇条書きの文 | 12 | `１．`、`・` などで始まる | 備考の文 |
| A5 数字を含む短い文 | 1 | `９４人 12 月（内訳下表のとおり）` | 備考の文 |
| A6a 数字なしの短い文字、備考の表の中 | 497 | 直前の見出し行から、この行までに、`事務事業別内訳表`、`区分`、`国庫債務負担行為` のいずれかがある | 備考の表（見出し・左端の列・列の見出し） |
| A6b 数字なしの短い文字、連鎖 | 353 | 直前の見出し行（コード行）が、それ自体 unresolved（`BLANK_CELL_COLUMN_UNDETERMINED`） | 空欄の列が決まらなかった行の、名称の継続行 |
| A6c 上のどれでもない | 3 | 例: `政府開発援助留学生 …`、`諸謝金 褒賞品費 職員 …`、`６年度 増員` | 備考の表の列の見出しと見られる（根拠は弱い） |
| 計 | 1,573 | | |

**読み方**

- **備考の内容（A1〜A3、A5、A6a）は1,217行、A6c を加えると1,220行（77.6%）。** 左側から始まる備考の表（特に、事務事業別内訳表）で、表の左側の内容ではない。取り損ねではなく、unresolved に残すのが正しい。**ただし、「原因不明の未解決」と区別がつかないので、備考と判定できる行には、別の理由（例: 備考の表）を付けるのが整理しやすい。**
- **取れる可能性があるのは、A6b の353行のみ。** その行自体は、名称の継続行（`払戻しに必要な経費`、`金` など）で、直前の見出し行が unresolved になったため、連結先が無い。**原因は、空欄の列が決まらなかった行（485行）にある**（下の 2.1）。
- 隣接しない 708行、揃わない 16行は、ほぼ備考の表（A6a など）と、連鎖（A6b）に分かれる。連結の条件（直前の物理行、名称の開始位置が揃う）を緩めて取る必要は、見つからなかった。**条件を緩めると、備考の表を名称に取り込む**（A6a が497行ある）。

### 2.1 連鎖の根本原因: 空欄の列が決まらなかった485行

- 位置で決められなかった行（`BLANK_CELL_COLUMN_UNDETERMINED`）は485行。このうち、ページの右端を実測できなかった行の内訳は未集計。
- **表頭の見出しの語の位置だけから決める窓（`明細表 CSV` の仕様書にある、金額を読むための窓）を、列の位置合わせに使えるか** を調べた。
  - 窓だけで、2つの金額の列が一意に決まるのは、**140行**。残り345行は、窓が重なって決まらない。
  - その窓を、すでに実測の右端で置いた612行に当てると、**545行が同じ列**、67行は窓が重なって決まらず、**食い違いは0**。窓は、実測の右端と矛盾しない。
  - 140行は、算術（`要求額−前年度＝増減`）にも合う。ただし、これは診断としてだけ見たもので、列を決める材料には使っていない。
  - その140行を取れると、連鎖の353行のうち**99行**が、名称の継続行として連結できる。
- つまり、「窓による位置合わせ」を規則に足すと、**140行と、その継続行99行**が増える見込みがある。残り（345行と、その継続行）は、窓が重なって決まらない。

## 3. B: 総表の `明細書頁数` から、明細表の頁が見つからない行

- 総表で `明細書頁数` を持ち、同じ source に明細表がある行は3,003行。
- 以前の集計（行のあるページの `頁` だけ）で、番号が見つからないのは189行。**そのうち40行は、番号の頁が、左側に行が無い頁（備考だけの頁、または左側が unresolved）にある。** 全明細表ページのラベルで見ると、見つからないのは**149行**。

| 原因 | 行数 | 内容 |
|---|---|---|
| 明細表側にラベルが無い | 146 | 5つの PDF（`env…000157012` 39、`meti…eneju` 39、`env…000157013` 29、`meti…eneden` 29、`meti…enegen` 10）。エネルギー対策特別会計。総表は `エ 1`、`電 1` などの形で頁を指すが、明細表のどのページにも、ラベルの行が無い |
| 予測の位置が明細表ページでない | 3 | `ndl…` の3行。総表の頁 13 を、同じ source のラベルとページの差から、物理ページ16と予測したが、そのページは明細表ページではない |
| 番号の頁はあるが、左側に行が無い | （40） | 上の189行から外れる分。結合はできる（`頁` が、行のあるページにしか付かないだけ） |

- 146行は、明細表に、頁の番号が印字されておらず（テキストに無い）、`頁` では結べない。ページの順序などで結ぶことはできるが、観測した文字ではなく、推定になる。**この PDF 群の結合は、別の鍵が要る。**

## 5. 規則の直しの候補（実装は別。ユーザーの判断を待つ）

1. **空欄の列の位置合わせに、表頭の窓を足す（原因: 2.1）。** 140行と、その継続行99行が増える。窓は、観測した位置（表頭の見出しの語の位置）だけから決まり、算術は使わない。実測の右端との食い違いは0。
2. **備考の内容と判定できる行に、別の理由を付ける（原因: A の1,220行）。** 取るのではなく、名前を分けて、「原因不明の未解決」と区別する。判定は、罫線の文字、括弧つきの金額、番号の記号、直前の見出し行からの `内訳表` などの語、で行える。ただし、この判定の誤りが、取れる行を隠さないよう、備考と判定した行も `unresolved.csv` に残す。
3. **連結の条件は緩めない。** 緩めると、備考の表を名称に取り込む（A6a が497行）。
4. **エネルギー対策特別会計の5つの PDF（146行）:** `頁` の鍵が無い。結合が要るなら、別の鍵（推定を含む）を、別に検討する。

## 6. 限界

- 分類は、行の文字の特徴と前後の行による記述的なもので、PDF を見て確かめていない。A6a の「備考の表の中」は、`内訳表`、`区分`、`国庫債務負担行為` の語に依っており、他の形の備考の表は、A6c などに残り得る（3行）。
- 「窓だけで一意」の140行が正しい列かは、実測の右端で置いた612行との一致（食い違い0）で見たが、その140行自体の真値は確かめていない。
- 明細表を持たない source（text layer が無い法務省・金融庁を含む）は対象外。
