## 画面構成

### 左上：検索・フィルタ

`/sankey-svg` の検索ボックス（入力＋開閉式フィルタパネル一体型、カード外下の
小さな矢印で開閉）と同じ構造。ただし中身は以下の通り拡張する。

- 検索は**部分一致・正規表現トグル**（`.*`）を持つ、**ジャンプ機能**
  （グラフを絞り込まない。一致ノードを一覧し、選択でパン/ズーム）
- 検索ボックスは**項用・事業用の2本**（統合1本にしない）
- フィルタパネル（グラフを実際に絞り込む）:
  - 会計区分（一般・特別・なし、を含むチェックボックス付きコンボボックス。
    `/sankey-svg` の acGeneral/acSpecial/acBoth/acNone と同じ4択の考え方）
  - 省庁（項の所管。共管で複数省庁になる場合を考慮する。`/sankey-svg` の
    省庁コンボボックスを流用するが、値は「項の所管」という単一属性ではなく、
    共管時は分解した複数値の集合として扱う）
  - 所管（新規：項由来の所管という表現で会計区分の下に独立させる。
    上の「省庁」と実質同じデータを指す可能性が高いので、実装時に
    重複していないか確認し、重複するなら1つに統合する）
  - 項（新規：項名の文字列フィルタ。検索ボックスとは別に、フィルタパネル内の
    もう一つの絞り込み条件として持つ）
  - 事業（新規：事業名の文字列フィルタ。同上）
  - 項予算（新規：MOF項の総額レンジ、下限・上限）
  - 事業予算（新規：RS事業の当初予算額レンジ、下限・上限）

  「省庁」と「所管」が重複要件に見える点、「項/事業の文字列フィルタ」と
  「検索ボックスの文字列」が重複要件に見える点は、実装時に統合か分離かを
  再確認しながら進める（両方明記されているため、フィルタパネル内の絞り込みと
  検索ボックスのジャンプ機能は別物として両方実装する、という理解で進める）。
