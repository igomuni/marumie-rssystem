**追加の手直し（2026-09-13 後半）。** 実画面レビューで7件の指摘を受けて修正：
項・事業列の金額→高さ縮尺を共有（列間で見た目比較できるように）、検索結果・
コンボボックスのドロップダウンが親カードの `overflow:hidden` で見切れる不具合、
ウィンドウの高さを縮めるとラベル文字が縮小する不具合（`ResizeObserver` による
実測ピクセルの `Dims` を `viewBox` にそのまま使う設計へ変更）、フィルタの
チェックボックスコンボで「すべて選択/解除」の解除ができない不具合
（`string[] | null` 型への変更）、項/事業名フィルタへの正規表現トグル追加。
このうち `ResizeObserver` の実装は当初 `useRef` + 空配列 `useEffect` で
書いたため、データ読込中にコンテナが未マウントで observer が張られない
不具合があり、これが原因で「その他の項」集約ノードがビューポート外に
配置されるe2eテスト失敗として顕在化した（callback ref化で修正）。
紐づけ率バッジが `pointerEvents` 未設定でRS事業列上部のノードへのクリックを
奪っていた不具合も合わせて修正。詳細は `docs/integrated-sankey-graph-model.md`。

**さらに3件の手直し（2026-09-13 続き）。** 実画面レビューで、一定の高さ未満の
ノードラベルが非表示になる不具合（`/sankey-svg` は間隔を空けてでも表示する方式）、
2列の間が間延びして見える点、フィルタ解除ボタンがテキスト「解除」で
`/sankey-svg`（Material Icons の `filter_list_off`）と異なる点の指摘を受けて修正。
ラベル非表示条件を撤廃（`NODE_MIN_SLOT` の最低枠で常に収まるため）、フィルタ解除を
アイコンボタン化。列間隔は当初ラベルを列の内側（中央のギャップ）へ向ける構図で
修正したが、「左のノードは左に・右のノードは右にラベルがあるべき」という指摘を
受けて再修正。ラベルは列の外側へ戻し、代わりに2本のバー自体をキャンバス中央へ
寄せ合わせることで列間の間延びを解消した（`MID_GAP`＝60px）。
詳細は `docs/integrated-sankey-graph-model.md`。

**さらに3件の不具合修正（2026-09-13 続き）。** (1) オフセットを進めたときに、
窓の前方（オフセットで飛ばした値の大きい側）の項目まで「その他」集約ノードに
巻き込まれ、金額・件数が不自然に跳ね上がる不具合。`windowSlice()` が返す
`tail`（窓の後方のみ）だけを集約するよう修正し、前方は集約せず単純に非表示に
した（`/sankey-svg` の `tailRecipients` と同じ設計）。(2) サイドパネルの金額が
マイナスのとき兆/億表示にならず「-5000万円」のように万円表示に落ちる不具合。
`money()` の閾値判定に `Math.abs` を通すよう修正。(3) 1万円未満の金額が
「0万円」に丸められ実質見えなくなる不具合。1万円未満は素の円で表示するよう
修正（`client/components/mof-jikou/format.ts` の `formatYen` と同じ考え方）。
詳細は `docs/integrated-sankey-graph-model.md`。

## 画面構成

### 左上：検索・フィルタ

`/sankey-svg` の検索ボックス（入力＋開閉式フィルタパネル一体型、カード外下の
小さな矢印で開閉）と同じ構造。ただし中身は以下の通り拡張する。

- 検索は**部分一致・正規表現トグル**（`.*`）を持つ、**ジャンプ機能**
  （グラフを絞り込まない。一致ノードを一覧し、選択でパン/ズーム）
- 検索ボックスは**項用・事業用の2本**（統合1本にしない）
- フィルタパネル（グラフを実際に絞り込む）:
  - 会計区分（一般・特別・なし、を含むチェックボックス付きコンボボックス。
    `/sankey-svg` の acGeneral/acSpecial/acBoth/acNone と同じ4択の考え方）
  - 省庁（項の所管。共管で複数省庁になる場合を考慮する。`/sankey-svg` の
    省庁コンボボックスを流用するが、値は「項の所管」という単一属性ではなく、
    共管時は分解した複数値の集合として扱う）
  - 所管（新規：項由来の所管という表現で会計区分の下に独立させる。
    上の「省庁」と実質同じデータを指す可能性が高いので、実装時に
    重複していないか確認し、重複するなら1つに統合する）
  - 項（新規：項名の文字列フィルタ。検索ボックスとは別に、フィルタパネル内の
    もう一つの絞り込み条件として持つ）
  - 事業（新規：事業名の文字列フィルタ。同上）
  - 項予算（新規：MOF項の総額レンジ、下限・上限）
  - 事業予算（新規：RS事業の当初予算額レンジ、下限・上限）

  「省庁」と「所管」が重複要件に見える点、「項/事業の文字列フィルタ」と
  「検索ボックスの文字列」が重複要件に見える点は、実装時に統合か分離かを
  再確認しながら進める（両方明記されているため、フィルタパネル内の絞り込みと
  検索ボックスのジャンプ機能は別物として両方実装する、という理解で進める）。

- 事業オフセットコントロール（`RangeWindowRow` 相当、1本）

  今回のユーザー仕様は「項オフセット」「事業オフセット」を並列に明記しているため、
  **独立2本を維持する**（前回の判断を踏襲）。

- 年度切り替え（`YearSelect`。対象年度は上記の2つに限定）
- ページ切り替え（`PageNavMenu`）

- 「関連のみ表示」（`autoFocusRelated`）は**無し**

### 右サイドパネル

#### 項選択時

ヘッダー：項名、会計区分、所管、組織／特会、勘定、本年度金額、前年度金額、増減率

- 本年度金額：`IntegratedSectionNode.amount`（既存）
- 前年度金額・増減率：**新規集計が必要**。現状 `IntegratedSectionNode` は
  本年度の目金額しか合算していない。`MOFKouMokuItem.previousAmount` /
  `.difference` を項単位で合算する処理を `buildIntegratedGraph` に追加する

タブ：目一覧、RS事業一覧（事項一覧は前述の通り別タスク）

- 目一覧：既存の「目エッジ」相当を項側から見た一覧（接続先事業・状態・金額）
- RS事業一覧：この項から接続しているRS事業の一覧

#### 事業選択時

ヘッダー：事業名、会計区分、府省庁、部課局、PID、予算額、支出額

- 会計区分：**新規**。事業は複数の会計区分にまたがる目から接続されうるため、
  「一般」「特別」「一般・特別」の3値、または内訳表示にする（要実装時判断）
- 府省庁：`IntegratedProjectNode.ministry`（既存）
- 部課局：**新規・近似**。`budgetItems[0].organizationAccount` を代表値として使う
  （事業内で複数組織にまたがる場合があるため厳密ではない。他プロジェクトの
  詳細表示パターンを踏襲し、代表値である旨をUIで示す）
- PID：`IntegratedProjectNode.projectId`（既存）
- 予算額：`IntegratedProjectNode.initialBudget`（既存）
- 支出額：**新規だが実在する**。`IntegratedProjectNode.budgetSummary.executedAmount`
  （route.ts は既に `budgetSummary` を渡しているので、フィールドを追加参照するだけ）

タブ：予算執行一覧、目一覧

- 予算執行一覧：`budgetSummary`（当初・補正・繰越・予備費・執行率等）の表形式表示。
  既存の `BudgetSummary` 型がほぼそのまま使える
- 目一覧：既存の `budgetItems`（MOF接続済み/未接続バッジ付き）をそのまま流用
