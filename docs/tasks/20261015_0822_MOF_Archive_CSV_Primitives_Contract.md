# MOF の archive から 項・事項・目 の CSV を作る — 契約

状態: **契約（実行前に固定）。** 結果は別の task doc に書く。記述だけで、仮説・閾値は無い。照合・分類・昇格はしない。
前提: 検討（#470）。ユーザーの決定: (1) 特別会計も取れるなら取る、(2) 事項の読み取りは既存の凍結済み parser（`lib/mof-budget-xml-items.ts`）を使う、(3) 事項の列は安定させる（説明欄は要らないが、要確認）、(4) FY2025 は成立後と提出時の両方、XML の取得も許可。
範囲: FY2024（最初の対象）と FY2025（成立後・提出時）。原本は `data/download/mof.go.jp/archive/` で、`data/normalized` の jsonl には頼らない（照合の参考にだけ使う）。

## 方針（simple primitives）
- CSV は原本の形のまま。列名は原本の見出し。値の補正・正規化・推測・補完をしない。作る側が足す列は、原典の位置（`source_*`）と、数えた値（件数・合計）だけで、列名でそれと分かるようにする。
- 項・目は公式 CSV（`DL{年}11001.zip`＝一般会計、`DL{年}12001.zip`＝特別会計の `b.csv`）から。事項は XML から（CSV には無い）。事項と目は対応づけない（対応表は公表されていない）。
- 入力は SHA-256 を固定し、2回実行して出力が同一であること。1つでも違えば何も出さずに STOP する。

## 成果物（`tests/fixtures/mof-archive-csv/{version}/`。version = `2024`、`2025`（成立後）、`2025_teishutsu`（提出時））
1. **`kou-general.csv`・`kou-special.csv`**（項）: `b.csv` の項に当たる列を、そのまま一意にした行に、`目の行数` と、当年度・前年度の金額の合計（列名は `{原本の見出し}の合計`）を足したもの。
   - 一般会計の項のキー: 所管・組織・項コード・項名。特別会計の項のキー: 所管・特別会計・勘定・項コード・項名・共管所管名・共管組織名（共管の列が1つの項の中で一定であることを、数えて確認する。一定でなければ STOP）。
2. **`moku-general.csv`・`moku-special.csv`**（目）: `b.csv` の全行を、列名も値もそのままにし、`source_row`（`b.csv` のデータ行の番号、1始まり）を足したもの。
3. **`jikou-general.csv`**（事項。FY2024 のみ）: parser v0 の出力を列にしたもの。列は `所管, 組織, 項コード, 項名, 事項名, 主要経費別分類コード, 令和6年度要求額(千円), 前年度予算額(千円), 比較増△減額(千円), source_file, source_row, source_page`。金額は千円のままの整数。説明欄は含めない（parser v0 が出力しない。XML に説明欄があることと、その形は、結果 doc に確認結果を書く）。所管は parser の入力の目次（menu）の祖先から、parser の既存の関数で取る。
4. **`summary.json`**: 件数（所管・組織・項・目・事項）、金額の合計、整合の確認の結果。

## 確認（対応づけを使わない、構造だけの整合）
- 目の合計: 各 `b.csv` の当年度金額の合計と、`kou-*.csv` の合計の総和が等しい。
- 項の一致: FY2024 の一般会計で、`jikou-general.csv` の項（所管・組織・項コード・項名）の集合と、`kou-general.csv` の項が、件数・コード・名称で一致するか（差があれば、差を列挙する）。
- 金額の整合（記述）: 項ごとに、`jikou-general.csv` の金額の合計と、目の金額の合計が等しいか。崩れた項の数と崩れ方（例: 事項に金額が無い、「うち」書き）を記述する。
- 提出時と成立後（FY2025）: 行のキーの差と、金額が違う行の数を記述する。

## 既存 parser の適用範囲（実行前に分かっていること）
- parser v0 は FY2024 の一般会計（帳票 `202411001`）の凍結済みの source set に固定されていて、特別会計・FY2025・提出時の XML は `unsupported` または入力の契約の違反になる見込み。**parser は変えない**（変更には別の事前登録が要る）。使えないものは「使えなかった」ことと理由を記録し、特別会計と FY2025 の事項は、parser を一般化するかどうかをユーザーが決めるまで作らない。
- FY2025 の XML の取得（`download-mof-archive.ts --xml=`）は、parser を使える見通しが立ってから行う（使えない XML を先に取っても使い道がないため）。

## 範囲外
