# MOFデータとRSシステムデータの名寄せに必要な情報の洗い出し

目的: MOF（予算書）と RS（行政事業レビュー）を突合するために「何の情報が要るか」を、既存の実測結果（20260818_2052 / 20260818_2118 / 20260818_2138 / 20260819_0756 / 20260822_1524）を土台に一覧化する。

## 0. 前提 — 名寄せには2つのレベルがある

| レベル | 内容 | 現状 |
|---|---|---|
| L1: 科目レベル | RS の歳出予算項目 ↔ MOF の科目（所管/組織/項/目） | **名前一致で成立済み**（RS予算額の98%以上がMOF科目キーに載ることを実証済み） |
| L2: 事業レベル | RS 事業 ↔ MOF 事項 | **直結キーが無い**。名前一致は件数5.5%・金額32.2%止まり。1事項≒4事業のN対N |

L1 は追加情報ほぼ不要。洗い出しの主対象は L2。

## 1. 結合キーになる情報（両側で揃えるもの）

### 1-1. RS 側（すべて既存CSVにある）

| 情報 | 所在 | 用途 |
|---|---|---|
| 所管 / 組織・勘定 / 項 / 目 | 2-2（予算・執行_歳出予算項目） | L1結合キー。MOF CSV `b` と同じ語彙 |
| 会計区分 / 会計 / 勘定 | 2-2 | 一般会計・特会の振り分け（特会は 所管グループ>特会>勘定） |
| 予算年度 / 予算種別 | 2-2 | 年度・当初/補正の対応付け |
| 予算事業ID / 事業名 | 全シート | RS側の主キー |
| 主要経費 | 1-2（基本情報_事業概要等） | MOF主要経費別分類コードと同語彙。L2の候補絞り込み制約 |
| 事業の目的 / 事業の概要 | 1-2 | L2意味的照合の材料 |
| 歳出予算項目の補足情報 | 2-2 | ×使えない（充足率7.2%・書式不統一。実測済み） |

### 1-2. MOF 側

| 情報 | 所在 | 状態 |
|---|---|---|
| 所管 / 組織 / 項コード / 項名 / 目名 | ZIP同梱 CSV `b`（科目別内訳） | 取得済み（10年度） |
| 事項名 / 説明（所掌事務・根拠法） | Web XML〔組織別事項別内訳〕 | **取得済み**（/mof-jikou パイプラインで機械抽出済み） |
| 主要経費別分類コード | CSV `b`・事項別内訳の両方 | 取得済み |
| 特会の 会計 / 勘定 | 特会予算書（DL202612001系） | 取得済み |
| 事項のID | — | **存在しない**。合成キー `[会計種別\|所管\|組織\|特会\|勘定\|庁\|項コード\|事項名]` で代替（mof-jikou-loader の `identityKey()`） |
| 事項↔目の対応表 | — | **公表されていない**（事項=目的の括り、目=性質の括りで切り口が別） |

## 2. 年度の対応情報（名寄せの前提合わせ）

- RS の「事業年度」はシート公表年度、「予算年度」が実会計年度。**MOF令和N年度 ↔ RS予算年度(N+2018)** で揃える（実証済みの組合せ: MOF令和6年度 × RS_2025の予算年度2024）。
- RS 現形式は2024年度シート以降のみ → 突合可能なのは実質2年度。MOFは10年度あるが年度横断で項コードが動く（6.4%）ため、**年度をまたぐ名寄せに項コードは使えない**。
- 予算種別（当初/暫定/補正/決算）を両側で揃えること。当初+暫定の合算は二重計上。

## 3. 名称の正規化情報（表記揺れ辞書）

L1でもL2でも、文字列一致の前に以下の正規化材料が要る。

| 揺れの種類 | 例 | 必要な対応表 |
|---|---|---|
| 府省庁名の粒度差 | RS「林野庁」「水産庁」→ MOF「農林水産省」配下 | 外局→親省庁の対応表（RS側の局・庁の83.6%はMOF側に対応単位なし） |
| 特会の共管所管名 | 復興特会は共管省庁を全部並べた文字列で、**同一年度内でも変わる**（防災庁新設で当初と暫定が別文字列） | 所管グループ名の正規化規則 |
| 字体・仮名 | 「覚せい剤」↔「覚醒剤」 | 文字正規化（NFKC＋個別辞書） |
| 事項名の定型句 | 「〜に必要な経費」（RS事業名の4.5%がこの書式のまま） | 語幹抽出規則（定型句除去） |
| 同名事項の項またぎ | 「河川整備事業に必要な経費」が3項に存在 | 事項名単独ではキーにしない（項コードとセット） |

## 4. L2（事業↔事項）を詰める場合に必要な情報

実測済みの到達点: 完全一致80件＋語幹一致134件=214件（金額では32.2%）。ここから先は以下が要る。

1. **構造制約**: 同一の 所管×組織×項 に絞る（RS事業の99.8%がMOFの項に被覆される。項が候補空間を平均 事項1.6件 まで絞る）
2. **分類制約**: 主要経費コードの一致（両側同語彙）
3. **意味的照合の材料**: MOF事項の `説明` × RS の `事業の目的`/`事業の概要`。埋め込みは `/project-bubble` の `gemini-embedding-001` が流用可能
4. **金額整合**: 項内の事項金額配分と、RS 2-2 の項目別予算額の比率照合（1:Nの配分推定の裏取り）
5. **人手確認の受け皿**: 語幹一致には誤検出がある（「地域振興に必要な経費」⊂「過疎地域振興対策等に要する経費」）。確定/候補/不明の3値を持てるデータ構造

## 5. 構造的に紐づかない部分の識別情報（名寄せ対象外の明示）

名寄せ率を正しく評価するには「繋がらなくて正しい」領域の識別が要る。

- 国債費・地方交付税・特会繰入（MOF一般会計の56.3%）: 使途別分類コード6（繰入）等で機械判定可能
- RS対象外機関（国会・裁判所・会計検査院・皇室費等）: 所管名リストで除外
- 年度ずれ由来の未一致（新設・改称項目）

## 6. 欠けている（新たに作る必要がある）もの

| 情報 | 状態 |
|---|---|
| 事項↔RS事業の対応表 | **存在しない。名寄せの成果物そのもの**。N対N前提の設計が必要 |
| 外局→親省庁の対応表 | 未成果物化（調査時にアドホックに作った可能性はあるが辞書化されていない） |
| 事項名の語幹抽出・文字正規化規則 | 20260818_2138 の実験コードどまり。辞書として成果物化されていない |
| 確定214件のシードリスト | 実測はしたが成果物化されていない |

## 7. 実装（2026-08-25 追記）— 紐づけデータの生成と管理

洗い出しに基づき、L2（事項↔事業）の紐づけデータを実装した。

### 7-1. 構成

| 物 | パス | 管理 |
|---|---|---|
| 生成スクリプト | `scripts/generate-mof-rs-linkage.ts`（`npm run generate-mof-rs-linkage`） | Git |
| 型定義 | `types/mof-rs-linkage.ts` | Git |
| 手動判定 | `public/data/dictionaries/mof-rs-linkage-overrides.csv` | Git（人手で編集する唯一のファイル） |
| 生成物 | `public/data/mof-rs-linkage-2024.json`（+`.gz`） | `.gz` のみ Git（既存規約どおり） |

### 7-2. 管理の設計判断

- **自動判定と手動判定を分離する**。生成物は使い捨て（再実行でいつでも作り直せる）。人手の判断は overrides.csv だけに蓄積し、再生成しても消えない。
- **3値管理**: 自動の完全一致（構造キー＋名前一致）だけを `confirmed`、語幹一致は誤検出がありうるので `candidate`。人手は overrides.csv で `confirmed`（確定・新規追加）か `rejected`（誤検出の除外。出力から消える）を宣言する。
- **N対N前提**: レコードは事業×事項のペア。1事業複数事項・1事項複数事業を許す（20260822_1524 §8 の原則に従い、推定を確定と混ぜない）。
- **事項側のキー**は `jikouIdentity`（予算種別を除いた8要素連結）。mof-jikou の `identityFromKey()` と同じ構成で、`/api/mof-jikou/history` にそのまま渡せる。
- **範囲は v1 = 一般会計・当初予算**（予算年度2024 = MOF令和6年度 × RS_2025）。特会・補正への拡張はスクリプトのフィルタ拡張で対応可能。

### 7-3. 生成結果（予算年度2024）

```text
リンク 237件（confirmed 84 / candidate 153）
  exact-name 84 / stem-in-name 150 / exact-name-cross-section 3
事業カバレッジ: 226 / 3,861 事業、金額 14.04 / 42.22 兆円（33.3%）
事項カバレッジ: 215 / 1,256 事項
```

過去実測（20260818_2138: 211件・13.58兆・32.2%）と整合。上位（医療保険給付10.15兆・義務教育費1.56兆・年金生活者支援0.41兆）も実測と一致する。構造キー（所管×組織×項）で候補を絞ったため、過去のグローバル名前一致より精度が高い状態で件数はほぼ同数。

## 8. 留意 — 過去の設計判断との関係

20260822_1524 §8 の「名寄せはしない」は **MOF事項の年度間追跡**（元データに無いN対N関連を推定で作らない）についての判断で、本件（MOF↔RS の横断名寄せ）とは別。ただし同じ原則が効く: **推定で作った対応は「確定」と区別して持つ**こと（§4-5 の3値構造）。
