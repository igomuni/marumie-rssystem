# 当初↔決算の目数・金額変化パターン（全項への展開）

[医療保険給付諸費の当初補正決算の目件数比較](20260906_2130_医療保険給付諸費の当初補正決算の目件数比較.md)で見つけた「当初0円枠が決算で消える／決算で新規出現する」パターンが、他の項でも成り立つか、他にどんなパターンがあるかを2024年度・一般会計の全項に展開して調べた。

## 手法

2024年度の一般会計歳出CSV（当初・決算）を(所管,組織,項コード)単位でグルーピングし、当初・決算の両方に対応する項がある776項について、目名の集合差分を取った。

## 全項でのパターン分布

| パターン | 件数 | 割合 |
|---|---|---|
| 目数一致（差分なし） | 635 | 81.8% |
| 当初のみ・全て0円（決算で消える） | 64 | 8.2% |
| 決算のみ（当初に無い目が新規出現） | 44 | 5.7% |
| 当初のみ・実額あり（決算で消える） | 14 | 1.8% |
| 上記が混在 | 19 | 2.4% |

大半（81.8%）は目数が変わらない。変化がある項の大半は「医療保険給付諸費」で見た**当初0円枠パターン**（8.2%）と**決算での新規出現**（5.7%）で説明できる。

### 金額ベースの構成比

同じ776項について、当初予算合計・決算現額合計（歳出予算現額）を集計し、パターンごとの金額シェアも見た（全体: 当初合計112.0兆円、決算現額合計131.3兆円）。

| パターン | 件数（構成比） | 当初合計（構成比） | 決算現額合計（構成比） |
|---|---|---|---|
| 目数一致 | 635 (81.8%) | 86兆1,797億円 (76.94%) | 99兆9,518億円 (76.14%) |
| 決算で新規出現 | 44 (5.7%) | 11兆9,351億円 (10.66%) | 15兆3,452億円 (11.69%) |
| 混在 | 19 (2.4%) | 11兆3,800億円 (10.16%) | 12兆1,331億円 (9.24%) |
| 当初0円枠→決算で消える | 64 (8.2%) | 2兆2,202億円 (1.98%) | 3兆5,933億円 (2.74%) |
| 当初に実額あり→決算で消える | 14 (1.8%) | 2,961億円 (0.26%) | 2,456億円 (0.19%) |

**目数が変化する項ほど1件あたりの金額規模が大きい傾向がある。** 件数では少数派（5.7%・2.4%）の「決算で新規出現」「混在」パターンが金額では合わせて約20%を占める一方、件数の81.8%を占める「目数一致」項の金額シェアは76.94%どまり。一括計上予算・大型交付金・大規模プロジェクトほど決算で目の入れ替わりが起きやすいことを示唆する。「当初に実額あり→決算で消える」は件数・金額とも最小（0.26%）で、個別事例は目立つが全体への影響は小さい。

## パターンごとの実体

### (1) 当初0円枠→決算で消える（64項）

「医療保険給付諸費」の災害臨時特例補助金と同型。災害・特殊事態に備えて0円で名目上の枠を用意し、発動しなければ決算で省略される。例:

- 宮廷費「情報処理業務庁費」(0円)
- 衆議院「主要国首脳会議開催業務庁費」(0円)
- 会計検査院「通信専用料」(0円)

### (2) 決算のみ・新規出現（44項）

当初に無かった目が、補正等を経て決算にだけ現れる。「医療保険給付諸費」の災害臨時特例補助金（コロナ・能登地震で発動）と同型。他の実例:

- 内閣本府「地方創生支援費」→「能登創造的復興支援交付金」（能登半島地震関連。時期的に符合）
- 内閣本府「防災政策費」→「特定非営利活動法人等被災者支援活動費補助金」
- 内閣官房共通費→「安全保障業務旅費」「サイバーセキュリティ推進調整事務委託費」

いずれも当該年度に実際に起きた出来事（災害・政策課題）に対応する目が、当初になく決算にだけ現れるという共通構造。

### (3) 当初に実額あり→決算で消える（14項）。2つの異なる機序が混在

この分類だけ「医療保険給付諸費」には無かった新しいパターンで、金額規模に応じて性質が全く違う。

**(3-a) 少額の目が丸ごと消える（人件費の細目に多い）**

「短時間勤務職員給与」のような数百万円規模の細かい目が、金額を伴わずそのまま消えるケース（最高裁判所・こども家庭庁共通費・スポーツ庁共通費・観光庁共通費・気象研究所など、多数の項で共通して発生）。最高裁判所で実測すると:

```text
最高裁判所: 当初合計85,167,749,000円 → 決算現額合計91,088,304,641円（総額は補正でむしろ増加）
目数: 当初38 → 決算37（「短時間勤務職員給与」1,893千円のみ消滅）
```

項全体の金額は補正で増えているのに、この目だけ決算に出てこない。他の目（職員基本給等）への吸収も金額上は確認できず、**その年度に実際の支出が発生しなかった小口の目は決算CSVから省略される**とみられる（決算CSVの「歳出予算現額」自体が0になった目は掲載されない可能性。流用等で他の目に予算を回した結果と推測されるが、本調査だけでは断定できない）。

**(3-b) 高額の目が丸ごと消える＝「予算移替（一括計上予算）」**

[予算移替は一括計上予算という標準的な仕組み](20260901_2308_予算移替は一括計上予算という標準的な仕組み.md)で既に確認済みの機構と同一のものが、今回の機械的な差分抽出でも同じ項目として検出された。

```text
沖縄振興交付金事業推進費「沖縄振興公共投資交付金」: 36,805,907千円が消滅
  → 項全体: 当初合計76,255,375,000円 → 決算現額合計43,566,338,971円（約43%減）
  目数: 当初2 → 決算1

国際観光旅客税財源観光振興費: 出入国管理業務庁費(72億)・税関業務特別庁費(25億)等8目が消滅
  → 項全体: 当初合計32,993,333,000円 → 決算現額合計10,145,923,190円（約69%減）
  目数: 当初13 → 決算5
```

これらは他省庁への予算移替の送り手側で、決算段階で当該項からは消え、受け手側の別の所管・項に計上され直す（実額の消失ではなく会計上の付け替え）。同種の例として「水資源開発事業費」「離島振興事業費」「南極地域観測事業費」でも大口の目消滅を確認した。

**(3-a)と(3-b)の見分け方**: 消滅した目の金額規模と、項全体の金額変化率で判別できる。(3-a)は項全体の金額にほぼ影響しない小口（今回の最高裁判所の例は0.002%）。(3-b)は項全体の金額が大きく減少する（今回の例は43〜69%減）。

## 結論: 当初↔決算の目数変化は4類型に整理できる

1. **0円プレースホルダーの消滅**（過半数弱）: 実質的な変化なし
2. **災害・臨時事態対応の新規出現**: その年度に起きた出来事の裏付けとして使える
3. **小口の目の消滅（流用等の可能性）**: 項全体の金額にはほぼ影響しない
4. **予算移替（一括計上予算）による高額の目の消滅**: 既知の仕組みと合致。項全体の金額が大きく減る

年度推移のチャート化・目の同一性判定を行う際は、**目数や金額が変化したからといって即座に「異常」「データ欠損」と判断せず、上記4類型のどれに当たるかで解釈を変える必要がある**（特に4は他項への資金移動であり、単独の項だけを見ると予算が消失したように見える）。

## 補足: 分類の盲点「決算にしか無い項（一括計上予算の受け皿）」

> **訂正**: 本節の初稿では『情報通信技術調達等適正・効率化推進費』を「同じ所管（デジタル庁）内で同じ目名が86回重複する特殊構造」と書いたが誤り。決算の92行のうちデジタル庁自身の行は当初と同じ7行で、残り85行は**74の別の所管・組織**（項コード829〜842）に計上されたもの。項名で絞ったために別所管の受け皿行まで拾い、同一項に見えていた。

上記の4分類は「当初にある項」を起点に決算と突き合わせているため、**決算にしか存在しない項（当初側に無い）は最初から集計に入っていない**。これが[予算移替は一括計上予算という標準的な仕組み](20260901_2308_予算移替は一括計上予算という標準的な仕組み.md)で確認済みの受け皿項で、2024年度一般会計では**56項名・392行**ある。『情報通信技術調達等適正・効率化推進費』はその中の最大例に過ぎず、構造は他の一括計上予算と同じ。

### 調べ方

最初に試した「同一(所管,組織,項コード)内で目名が重複する項」を探す方法では、防衛省の艦艇建造費など**3項しか検出されない**（当初側の重複は0）。この項の特徴は目名の重複ではなく、**同じ項名が多数の所管・組織に決算だけ現れる**ことなので、次の手順で検出する:

1. 決算CSVの項を(所管,組織,項コード)でキー化し、当初CSVに同じキーが無いものを「受け皿」として抽出
2. 受け皿を**項名**で束ね、受け皿の組織数・行数・決算現額を数える
3. 同じ項名が当初側に存在するか（送り手の有無）、RS `2-2.csv`で同じ項名を持つRS事業数・所管数を突き合わせる

### 分かったこと

- **項名は送り手から受け皿へそのまま引き継がれる**（14件全てで当初側に同名の送り手がある）。「同じ項名が複数の所管に現れる」こと自体が一括計上予算の目印になる
- 『情報通信技術調達等適正・効率化推進費』が他と違うのは受け皿の広さ（74組織、他は最大15）だけで、構造は同型
- **RS側の分解度は項によってまちまち**。RS事業数は国際観光旅客税財源観光振興費31・情報通信技術21・沖縄開発事業費14が多く、他は1〜4件。「RSが内訳を持つ」のはデジタル庁固有ではない
- **RSは全て所管数1**、つまりRSの2-2は受け皿ではなく**送り手の所管・項**で記録している。MOF決算は「どの組織へ渡ったか」で分解し、RSは「何の事業か」で分解しており、両者は補完関係にある（両方揃えば「誰に×何のために」が復元できるが、突合キーが無いため機械的には結べない）
