# 事項単位RS紐づけ（mof-rs-linkage）の廃止

## 背景

MOF↔RS紐づけには2系統ある: 事項単位（mof-rs-linkage、名前照合・構造推定による自動突合でカバレッジが狭く精度も低い）と目単位（mof-rs-kou-moku-linkage、完全一致キーでカバレッジが広く正確）。事項単位は正確性に欠けるため、ユーザー指示により全面廃止した。目単位（mof-rs-kou-moku-linkage）は対象外で変更なし。

## 変更内容

削除:

- `app/lib/api/mof-rs-linkage-loader.ts`
- `app/api/mof-jikou/linkage/route.ts`
- `client/components/mof-jikou/JikouLinkage.tsx`
- `types/mof-rs-linkage.ts`
- `scripts/generate-mof-rs-linkage.ts`
- `public/data/dictionaries/mof-rs-linkage-overrides.csv`
- `public/data/mof-rs-linkage-{2023,2024}.json.gz`
- `package.json` の `generate-mof-rs-linkage` スクリプト

UI・ロジックの除去:

- `app/mof-jikou/page.tsx`: RS紐づけの取得（`/api/mof-jikou/linkage`）・`RSあり/RSなし`フィルタ・関連stateを削除
- `client/components/mof-jikou/JikouTable.tsx`: RS列・`JikouLinkage`表示を削除
- `client/components/mof-jikou/columns.ts`: `identityFromItem`・`bestLink`（事項単位専用）を削除
- `app/lib/api/mof-kou-loader.ts`: `sectionDetail()` の `jikouRsLinks` 算出を削除
- `types/mof-kou.ts`: `MOFKouSectionDetail.jikouRsLinks` を削除
- `client/components/mof-kou/KouSidePanel.tsx`: 事項タブのRS列（`rsByJikouKey`）を削除

## 確認

- `npx tsc --noEmit` / `npm run lint`: エラーなし（既存warningのみ）
- `/mof-jikou`: RS列・RSフィルタが表示されないことをブラウザで確認（展開詳細にも表示されない）
- `/mof-kou` サイドパネルの事項タブ: RS列が表示されないことを確認
