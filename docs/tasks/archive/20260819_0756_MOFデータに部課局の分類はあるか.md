# MOF データに RS の部課局にあたる分類はあるか

結論: **無い。** MOF の「組織」は会計機関（予算執行の単位）であって内部部局ではなく、
内部部局名（主計局・保険局・住宅局など）は予算書のどこにも現れない。
RS の `局・庁` の 83.6% は MOF 側に対応する単位を持たない。

検証: MOF 令和8年度（`mof-jikou-2026.json`、8帳票2,685事項）× RS_2025 `1-1_基本情報_組織情報`（事業年度2025、8,540件）。

---

## 1. 両者の「組織」は別の軸

| | RS | MOF |
|---|---|---|
| 階層 | 府省庁 > 局・庁 > 部 > 課 > 室 > 班 > 係 | 所管 > 組織 > 項 > 事項 |
| 意味 | 事業を担当する**内部部局** | 予算を執行する**会計機関** |
| 例 | 厚生労働省 / 保険局 / 医療課 | 厚生労働省 / 厚生労働本省 |

RS 側の充足率（事業年度2025・8,540件）:

| 列 | 非空 | ユニーク |
|---|---|---|
| 府省庁 | 8,540 | 37 |
| 局・庁 | 7,008 | 168 |
| 部 | 2,188 | 107 |
| 課 | 7,779 | 836 |
| 室 | 2,088 | 513 |
| 班 | 573 | 64 |
| 係 | 1,658 | 343 |

MOF 側の「組織」は一般会計で96種。中身は `厚生労働本省` `地方厚生局` `検疫所`
`国立ハンセン病療養所` `資源エネルギー庁` のような**会計機関**で、
本省の内部部局はすべて `〇〇本省` に畳まれている。

## 2. 名前の重なりは外局・施設等機関だけ

MOF 組織（96）と RS 局・庁（168）の名称一致は **21件**。中身は
`中小企業庁` `国税庁` `消防庁` `出入国在留管理庁` `国土地理院` `日本学術会議`
`地方創生推進事務局` など、**それ自体が独立した会計機関である外局・特別の機関・施設等機関**に限られる。

RS の事業単位で見ると:

```text
RS事業 8,540 件中、局・庁が入っているのは 7,008 件
  うち MOF の組織としても存在する名前   1,147 件 (16.4%)
  MOF 側に対応する単位が無い（内部部局） 5,861 件 (83.6%)
```

## 3. 他の帳票にも無い

- **事項別内訳**: 項名・事項名・説明文に現れる「局・庁」名は延べ65/49/46件で、
  いずれも上記の外局・施設等機関。内部部局名はゼロ
- **予算定員及び俸給額表（組織別等内訳）**: 職名ベースで、局は
  「官房長、局長 11人」のように**人数だけが集約**される。個別の局名は出ない
- 主計局・保険局・年金局・住宅局・道路局・医政局・大臣官房などを全文検索しても**すべてヒットなし**

## 4. 紐づけへの含意

- **部課局を軸にした MOF↔RS の突合はできない。** MOF 側にその情報が無い
- 組織軸で確実に合うのは `所管`（府省庁）まで。その下は
  「MOF: 会計機関」対「RS: 内部部局」で階層の意味が違うため、単純な対応付けにならない
- 実務上の結合キーは既存方針どおり `所管 / 組織 / 項 / 目`（`mof-budget-data-guide.md` 5節）。
  部課局は **RS 側だけが持つ属性**として、結合後に RS から引く扱いになる
- 逆に言えば、MOF の事項に「どの局の所掌か」を付けたい場合は、
  紐づいた RS 事業の `局・庁` から逆算するしかない
