# 目ページリンクのスクレイピング可否調査（特別会計の補正／決算）

[前回調査](20260830_0615_目の出典ページリンクが補正決算で無い理由.md)で未実装と判明した2箇所について、実際にMOFサイトのXMLを取得し実現可能性を確認した。

## 特別会計の補正予算 → スクレイピング可能（確認済み）

国債整理基金特別会計（項「国債整理支出」）の令和6年度補正予算(第1号)の目次（`202422001menu.html`）を確認したところ、目的の帳票が実在した:

```text
LineOut(06,0,"歳出 事項別内訳","202422001000037a.xml#p37","p. 37")
LineOut(06,0,"歳入歳出予算補正予定額科目別表","202422001000038a.xml#p38","p. 38")
```

`202422001000038a.xml`（p.38）の`title_for_list`は`歳入歳出予算補正予定額科目別表`、`running_title`は`財務省所管　国債整理基金特別会計`で、項「国債整理支出」・目「国債事務取扱手数料」等の行を実際に含んでいた（`generate-mof-kou-moku-data.ts`のCSV側と同じ項・目名で突合できる）。

ただし列構成（`<clm>`のcolSub配置）は当初・暫定の「歳入歳出予定額科目別表」（`buildSpecialPageMap`が読む帳票）とは異なる（補正独自の列: 成立予算額・追加額・修正減少額・差引額・予定額）。**既存の`parseTable`等の汎用XMLパーサはそのまま使えるが、列位置の解釈は補正専用に新規実装が必要。**

対応帳票は特別会計・勘定ごとに1本ずつ存在する（p.30, p.38, p.48, p.53, p.71...）ため、`buildSpecialPageMap`と同様に目次を辿って`歳入歳出予算補正予定額科目別表`のページを収集すれば良い。

## 決算（全会計区分） → スクレイピング不可（該当XML帳票が無い）

一般会計決算（`202477001`）・特別会計決算（`202478001`）いずれの目次も確認したが、歳出側に目レベル（科目別・款項目別）のXML帳票が存在しない:

- 一般会計決算の目次には歳入側の`歳入決算部款項目別表`はあるが、歳出側は`各省各庁歳出決算報告書`（事項レベルまで。目レベルの表は無い）のみ
- 特別会計決算の目次には歳出関連の科目別・款項目別表自体が無い（`docs/mof-budget-data-guide.md`の「特別会計の決算は勘定ごとの歳入歳出決算・財務諸表・債務計算書で、事項レベルの歳出決算報告書は無い」という記載と整合）

**目→事項の対応表もRS紐づけと同様に公式には存在しない**ため、事項レベルのページ番号を目に流用するのも不正確になりうる。決算の目ページリンクは今回確認した範囲の一次資料だけでは実装できない。

## 結論・対応方針

- 特別会計の補正予算: 実装可能。`buildSpecialPageMap`に相当する専用パーサ（列構成が違うため別関数）を追加すれば、当初と同様にページリンクが付けられる。
- 決算: 実装不可（材料となるXML帳票が存在しない）。将来的にMOF側が帳票を追加公開しない限り対応できない。

今回は調査のみで実装はしていない。特別会計補正の対応を実装するかはユーザー判断。
