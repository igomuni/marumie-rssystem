# 目の出典ページリンクが当初のみで補正・決算に無い理由（国債整理支出の例）

## 結論

**「目データがCSV由来でXMLに無いから」ではない。** 目データ自体は当初・補正・決算いずれもCSV（科目別内訳）が出どころで共通。差はページ番号を特定するための**後付けの名称突合処理**が、特別会計の補正予算と、全会計区分の決算について未実装であること。今回の「国債整理支出」（国債整理基金特別会計＝特別会計）は両方の未対応パターンに該当したため、当初だけリンクが付いた。

## 根拠（`scripts/generate-mof-kou-moku-data.ts`）

目（kou-moku）はCSVの行としてまず読み込まれ、`page`は一律`null`で初期化される（`extractStandard`/`extractRevised`/`extractSettlement`、421-511行目）。ページ番号は別途スクレイピングした「科目別内訳」等のXML帳票と名称突合するステップ（`buildGeneralPageMap`/`buildSpecialPageMap`）で後から埋める。この突合処理に会計区分・予算種別ごとの対応漏れがある:

- **特別会計の補正予算**: `buildSpecialPageMap`は`歳入歳出予定額科目別表`（当初・暫定と同じ帳票）のみ対象。補正は`歳入歳出予算補正予定額科目別表`という別帳票で列構成が異なるため、呼び出し側で`layout === 'standard'`のみに絞っており対象外（321-322行目のコメントで明記）。
- **決算（全会計区分）**: 545-546行目のコメント「決算は別調査が必要なため対象外・帳票単位のまま」の通り、決算はどの会計区分でも目レベルのページ突合が未実装。

対して一般会計の補正予算は`buildGeneralPageMap`が対応しており、ページリンクが付く（`generalSpecs`のフィルタは`layout !== 'settlement'`のみで補正を除外していない）。

## 事項（jikou）の決算だけは別

`/mof-kou`のサイドパネルで事項タブの決算行にはページリンクが付く（例: pid=4のjikouItemsで`page: 218`）。これは目とは別パイプライン（`generate-mof-jikou-data.ts`）が、一般会計に限り存在する事項レベルの「歳出決算報告書」というXML帳票を直接ページ単位でスクレイピングしているため（`docs/mof-budget-data-guide.md`参照）。目の決算とは仕組みが異なり、たまたまページが取れている。

## 対応方針

質問への回答のみで、今回は実装はしていない。直すなら:
1. 特別会計の補正予算帳票（`歳入歳出予算補正予定額科目別表`）用のページマップ関数を追加
2. 決算の目レベルページ突合（一般会計・特別会計とも「別調査」）を実装

いずれもスクレイピング対象の帳票レイアウト解析が新規に必要なため、影響件数を見てから着手判断でよい。
