# 「普通国債等償還財源等国債整理基金特別会計へ繰入」（目）と「定率による公債等償還財源の国債整理基金特別会計へ繰入れに必要な経費」（事項）の関係

[前回調査](20260830_0919_債務償還費の一次情報とYahoo記事の16.3兆円の出典.md)の続き。両者は同じ項「国債費」（一般会計・財務省）の下にある、事項別内訳（目的別）と科目別内訳（性質別）という別系統の分類（対応表は無い）。金額を突き合わせて実際の対応関係を確認した。

## 法的根拠（1次情報）

**特別会計に関する法律 第42条**（e-Gov/厚労省法令データより）:

> 「第六条の規定にかかわらず、国債整理基金に充てるため、毎会計年度、予算で定める金額を、一般会計から国債整理基金特別会計に繰り入れるものとする」
> 「前年度期首における国債の総額の百分の一・六に相当する金額とする」

これがいわゆる「60年償還ルール」（1.6%≒60分の1）の法的根拠で、事項「定率による公債等償還財源の国債整理基金特別会計へ繰入れに必要な経費」の計上根拠そのもの。

**財務省 国債整理基金特別会計 決算ページ**（`mof.go.jp/about_mof/mof_budget/special_account/kokusaiseiri/`）の説明:

> 「一般会計から定率繰入等の形で資金を繰り入れ、普通国債等の償還財源として備える」

定率繰入（事項）でお金を繰り入れ、それが目「普通国債等償還財源」として積み立てられる、という関係が明記されている。

## 結論

- 定率繰入（事項）は普通国債等償還財源（目）の主要な構成要素の一つだが、1:1対応ではない。目は複数の目的別事項を性質（「他会計へ繰入」等）でまとめた集計であり、一部（出資国債等・事務取扱い分）は別の目に切り出されている。
- 唯一きれいに1:1対応するのは「年金特例公債」グループ（2事項合算＝1目、誤差ゼロ）。
- 一次情報としては、法的根拠（特別会計に関する法律第42条）とMOFの国債整理基金特別会計解説ページで「定率繰入→普通国債等償還財源」という関係の記述は取れるが、目⇔事項の詳細な対応表（今回の数値突き合わせに相当するもの）自体は財務省の公開資料としては見当たらず、今回は予算書データベースの実額から逆算して確認した。
