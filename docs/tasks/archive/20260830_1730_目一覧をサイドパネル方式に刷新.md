# 科目別内訳（目）一覧を項一覧と同じサイドパネル方式に刷新

## 変更内容

- **RSあり/なしトグルボタンを廃止**。RS列は `/mof-kou`（項一覧）と同じ「紐づくRS事業数」の数値表示に変更（0件は「—」、1件以上はエメラルド色）。
- **行クリックの詳細をインライン展開から右サイドパネルに変更**。新規 `client/components/mof-kou-moku/KouMokuSidePanel.tsx`（`/mof-kou`のKouSidePanelと同じ構成）で「年度推移」「RS事業」の2タブを表示。年度推移タブは既存の`KouMokuHistory`をそのまま再利用、RS事業タブは新規`DataGrid`ベースの一覧（事業名・府省庁・RS計上額・引継ぎ）。
- **行の詳細（合成キー・行ID・目分類コード等のdl表示）は廃止**。サイドパネルのヘッダーに主要な情報（目名・予算種別・会計区分badge・所管・組織・項・出典ページ・本年度額・前年度額・増減率）のみ集約。
- **`該当 N 件`の合計を常時表示**。項一覧と同じく、予算種別・会計区分が混在していても`filtered.reduce`でそのまま合計する（従来の「合計は予算種別・会計区分が混在のため非表示」抑制ロジックを削除）。

`KouMokuTable.tsx`はインライン展開（`Fragment`・`expandedId`・`KouMokuHistory`直接描画・RSリンクdl）を削除し、`selectedId`/`onSelectRow`ベースの行選択に統一。`app/mof-kou-moku/page.tsx`は`expanded`ステートを`selected`に置き換え、`/mof-kou`と同じ`panelWidth`/`panelTab`/`panelGridStates`とリサイズハンドルを追加。

## 確認

- `npx tsc --noEmit` / `npm run lint`: エラーなし（既存warningのみ）
- ブラウザで確認: RS列が件数表示になっていること、行クリックで右サイドパネルが開き年度推移テーブル・RS事業一覧（事業名・府省庁・RS計上額）が表示されること、合計金額がフィルタの組み合わせに関わらず常に表示されること
