# 暫定予算は当初予算の内数であることのデータ検証

**問い**: 暫定予算の金額が当初予算より小さいのは「追加の予算」だからか？

**結論**: 違う。暫定予算は本予算成立までの**つなぎ**であり、成立時点で本予算に吸収される。
令和8年度（2026）の事項別内訳データで検証したところ、**当初を上回る事項は1件も無かった**。

## 検証方法

`GET /api/mof-jikou?year=2026` の `items` を、予算種別を除いた識別子
（会計区分・所管・組織・特会・勘定・機関・項コード・事項名）で当初予算と暫定予算に分けて突合。

## 結果

| 予算種別 / 会計 | 件数 | 合計 |
|---|---:|---:|
| 当初予算 / 一般会計 | 1,303 | 122.31兆円 |
| 当初予算 / 特別会計 | 361 | 441.73兆円 |
| 当初予算 / 政府関係機関 | 48 | 4.72兆円 |
| 暫定予算 / 一般会計 | 777 | 8.56兆円 |
| 暫定予算 / 特別会計 | 166 | 29.81兆円 |
| 暫定予算 / 政府関係機関 | 27 | 0.04兆円 |
| 補正予算（第1号）/ 一般会計 | 3 | 4.11兆円 |

識別子ベースの突合（暫定 970事項）:

- 当初に存在しない事項: 35件 → いずれも東日本大震災復興特別会計で、**項コードの揺れが原因**。
  項コードを外して（会計区分・特会・事項名）で照合すると **0件**
- **当初より金額が大きい事項: 0件**（項コードあり・なしのどちらでも0）
- 暫定と当初が同額の事項: 0件（＝全事項が当初の一部だけを計上）

一致した935事項の比率:

- 合計比 **8.3%**（暫定38.41兆円 / 当初465.31兆円）。
  **実際の対象期間は4月1日〜11日の11日分**（365日中3.0%）なので、
  日割りの2.7倍が積まれている。均等按分ではなく必要額を積む方式であることの裏付け
- 事項別の比率は 中央値2.9% / 最大97.7%。均等按分ではなく、事項ごとに必要期間分を積む
- 比率が高い上位: 国債整理基金特別会計へ繰入れ97.7%、国際法の形成・発展82%、
  情報通信技術を活用した教育の推進71.9%、基礎年金相当給付費の他勘定へ繰入れ56.8%、地方特例交付金50%
  （期日が暫定期間内に来る繰入・交付は満額に近く積まれる）

## 実装上の含意

既存の記載どおりで矛盾は無い。あらためて確認された点:

- `当初 + 暫定` の合算は**二重計上**。`docs/api-guide.md` の「予算種別をまたいだ合算は意味を持たない」は正しい
- 暫定予算に比較欄（前年度額・増減額）が無いのは、年度間比較の対象として設計されていないため
  （`docs/mof-budget-data-guide.md` §3-3）
- 年度の最終予算額を見るなら補正予算の `amount`（改予算額）を使う

## 制約

- 暫定予算が編成されたのは収録4年度のうち令和8年度のみ。他年度での再検証はできない
- 事項名の改称は追えないため、35件の不一致が「改称」由来でないことまでは確認していない
  （項コード無視の照合で0件になったので実害なし）

## 追記: 逆方向は成り立たない（当初 ⊄ 暫定）

「暫定 ⊆ 当初」は成り立つが、**当初の事項が全て暫定にあるわけではない**。
項コードを除いた識別子で照合した結果:

| 会計区分 | 当初の事項数 | 暫定にある | カバー率 |
|---|---:|---:|---:|
| 一般会計 | 1,261 | 765 | 60.7% |
| 特別会計 | 349 | 127 | 36.4% |
| 政府関係機関 | 48 | 27 | 56.3% |
| **合計** | **1,658** | **919** | **55.4%** |

暫定に載らない739事項の当初額は **103.3兆円**（当初総額568.75兆円の18%）。

選別基準は「暫定期間内に支払いが発生するか」で、主要経費別のカバー率がそれを裏付ける。

- 高い: 年金給付費70.6%、その他の事項経費68.7%（人件費・庁費）、雇用労災対策費66.0%
- ゼロ: 介護給付費0/3、地方譲与税譲与金0/7、社会資本総合整備事業費0/6、文教施設費0/3、育英事業費0/3
- 低い: 医療給付費1/12（8.3%）、国債費11/46（23.9%）

国債費では**利子の支払い・事務費は暫定に入るが、定率繰入（元本償還財源、17.2兆円）は入らない**。
予備費は当初27件のうち暫定にあるのは1,000億円の1件だけ。

結論を1行にすると:

```text
暫定予算 = 当初予算の事項の55%を選び、それぞれ必要期間分だけを計上したもの
```

## 追記: 補正は性格が違う（新設事項がある）

同じ突合を補正予算に対して行うと、暫定とは逆の結果になる。

| | R5 (2023) | R6 (2024) |
|---|---:|---:|
| 当初 → 補正にある | 64.2% | 68.5% |
| 補正 → 当初にある | 99.0% | 97.5% |
| **補正で新設（当初に無い）** | **11件** | **28件** |

**暫定は新設ゼロ・当初超過ゼロだが、補正は当初に無い事項を立てる。**
これが「内数のつなぎ」と「追加の予算」の構造的な差。新設事項は例外なく `成立予算額 = 0`
（R6は28件全件、R5は11件中10件）。

新設の中身は2種類。

- 政策的な新規計上（R6: 半導体・人工知能関連技術の基盤強化 +1,305億、防衛力強化資金へ繰入れ +110億）
- 施設整備・災害復旧・船舶建造の定型枠（R6の28件中13件、大半が増減額0）

補正の突合上の注意:

- **増減額0でも掲載される事項がある**（R5で245件、R6で227件）。「載っている＝金額が動いた」ではない
- 補正の `成立予算額` が当初額と一致しない事項が R5で5件・R6で7件（約0.5%）。
  同名事項が複数勘定にまたがるケースの集約副作用と見られる。事項名ベースの突合は1%弱の取りこぼしを前提にする
