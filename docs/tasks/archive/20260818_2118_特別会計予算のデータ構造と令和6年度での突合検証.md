# 特別会計予算のデータ構造と、令和6年度での RS 突合検証

前編: `20260818_2052_令和8年度当初予算のデータ構造分析とサンキー構成案.md`（一般会計側）。

本書は (1) 特別会計予算書（`202612001`）の構造確認と ZIP の突き合わせ、(2) RS_2025 の対象年度に合わせた**令和6年度（2024）での実測突合**を扱う。令和8年度データは RS 側に対応年度が無く、現時点では紐づけに使えない。

## 1. 特別会計予算書（Web）の構造

`202612001Main.html` も一般会計と同じフレームセット。目次 `LineOut()` は400行。

```text
令和8年度特別会計予算
├ 予算総則
├ 甲号歳入歳出予算   … 所管グループ(10)別
├ 丙号繰越明許費
└ 丁号国庫債務負担行為
令和8年度特別会計予算参照書
└ 歳入歳出予定計算書等
   └ 所管グループ > 特別会計(14) > 勘定 > 甲号歳入歳出予定計算書
      ├ 歳入 款・項・目別区分並びに各目の見積の事由及び計算の基礎
      ├ 歳出 事項別内訳
      └ 歳入歳出予定額科目別表
   （会計により + 丙号/丁号要求書・予算定員及び俸給額表・損益計算書・貸借対照表・積立金明細表）
財政投融資計画 / コード番号について / 予算書情報について
```

一般会計との違いは、所管が単独省庁ではなく**共管グループ**（「内閣府、総務省及び財務省所管」等）であること、そして階層に**勘定**が挟まること。

`歳出 事項別内訳` / `歳入 …見積の事由…` / `歳入歳出予定額科目別表` はいずれも **34ページ** ずつあり、これは CSV の 特会×勘定 = 34 と完全一致する。

XML スキーマは一般会計と同一（`<clm id="p{頁}-{行}.{n}-{列}.{n}">`）。事項別内訳の列は `項 / 事項 / 令和8年度予定額 / 前年度予算額 / 比較増△減額 / 説明`。全34ページを抽出して**事項 361件**。

一般会計の事項が1,309件だったのに対し特会は361件で、しかも85件が東日本大震災復興特会に集中している。特会の歳出は少数の巨大な繰入・給付で構成されるので、当然の分布。

## 2. ZIP との突き合わせ

`data/download/mof-2026/DL202612001.zip` の中身:

| ファイル | 行数 | 対応 |
|---|---|---|
| `DL202612001a.csv` | 395 | 歳入（所管/特別会計/勘定/款/項/目 + 予定額） |
| `DL202612001b.csv` | 1,240 | 歳出＝**歳入歳出予定額科目別表**（所管/特別会計/勘定/項/目 + 予定額） |

`mof_2023/DL202312001b.csv` と**列構成は完全に一致**。`共管所管名` `共管組織名` を持つのが一般会計版との差。

集計（令和8年度）:

- 特別会計 14 / 特会×勘定 34 / 項 260 / 目行 1,239
- 歳出合計 441.7兆円、歳入合計 445.5兆円（会計間の重複計上を含む粗計）
- 「他会計より受入」計 113.1兆円（うち款名が「他会計より受入」の項 87.9兆＋「一般会計より受入」24.1兆ほか）

一般会計と同様、**ZIP に入るのは科目別（目レベル）だけで、〔事項別内訳〕と「見積の事由」は Web の XML にしか無い**。特会の場合、歳入側の「各目の見積の事由及び計算の基礎」に一般会計からの繰入の根拠が書かれているため、繰入フローを説明つきで描くならここも取得対象になる。

### 2-1. 年次で列名が揺れる

同じ `b` ファイルでも年度により金額列名が変わる。

```text
令和6年度: 令和6年度要求額 , 前年度予算額(千円) , 比較増△減額(千円)   ← 「(千円)」なし
令和8年度: 令和8年度要求額(千円) , 前年度予算額(千円) , 比較増△減額(千円)
```

パーサは列名の完全一致で拾わず、**列位置または `令和\d+年度(要求額|予定額)` の正規表現**で解決すること。

## 3. 令和6年度（2024）での RS 突合 ← 本命

RS_2025 が扱う予算年度のうち 2024 を使い、MOF 側も `mof_2024`（令和6年度当初予算）に揃えて実測した。結合キーは前編どおり `所管/組織/項/目`、特会は `特別会計/勘定/項/目`。

**単位に注意**: MOF CSV は千円、RS の `予算額（歳出予算項目ごと）` は**円**。

| | MOF側キー数 | MOF総額 | RS側キー数 | RS総額 | 一致キー | MOF金額カバー | **RS金額カバー** |
|---|---|---|---|---|---|---|---|
| 一般会計 | 6,716 | 112.6兆 | 3,227 | 42.2兆 | 3,223 | 37.4% | **98.2%** |
| 特別会計 | 1,225 | 436.0兆 | 573 | 78.9兆 | 559 | 18.0% | **98.9%** |

一致キー上での金額整合は 一般会計で MOF 42.1兆 vs RS 41.5兆（98.6%）。**RS の予算額はほぼ完全に MOF の科目コードの上に載る**。名前ベースの結合で実用に耐えることが確認できた。

RS 側の事業数は 一般会計 3,861 / 特別会計 781。

### 3-1. 逆方向（MOF → RS）で落ちるもの

一般会計は前編と同じ構図（国債費・地方交付税・特会繰入）。特別会計で未一致の大口:

```text
209.2兆  国債整理基金 / 国債整理支出 / 債務償還費
 29.7兆  交付税及び譲与税配付金 / 国債整理基金特別会計へ繰入
 20.9兆  年金・厚生年金勘定 / 基礎年金給付費等基礎年金勘定へ繰入
 18.2兆  交付税及び譲与税配付金 / 地方交付税交付金
 15.5兆  財政投融資・財政融資資金勘定 / 国債整理基金特別会計へ繰入
 12.6兆  エネルギー対策・原子力損害賠償支援勘定 / 国債整理基金特別会計へ繰入
 11.5兆  国債整理基金 / 国債整理支出 / 利子及割引料
 10.0兆  財政投融資・財政融資資金勘定 / 財政融資資金へ繰入
```

**特会歳出 436兆のうち 8割超が償還・会計間繰入**であり、事業ではない。特会の総額をそのまま棒にすると図が破綻するので、サンキーでは会計間フローとして別レイヤーに追い出す設計が必須。

### 3-2. 会計・勘定名の正規化

- MOF `特別会計` は「エネルギー対策」、RS `会計` は「エネルギー対策特別会計」→ **RS 側から `特別会計` を除去**して一致。
- `勘定` は両者とも「労災勘定」形式で**そのまま一致**（除去してはいけない）。
- 令和6年度時点で「子ども・子育て支援特別会計」は MOF 側では年金特会内の勘定。会計の新設・再編があるため、年度をまたぐ場合は会計名のマッピング表が要る。

## 4. 前編の論点に対する回答

1. **年度の揃え方** → 決着。**MOF は令和6年度（`mof_2024`）、RS は RS_2025 の予算年度2024** を使う。令和8年度（`mof-2026`）は RS に対応年度が無く現時点では使えない。`翌年度要求額` の利用は不要。
2. **特別会計は必要** → 一般会計から 24.1兆円が繰り入れられ、その先に RS 事業 781件・78.9兆円がある。特会を入れないと RS 事業の大半（金額ベースで約65%）が図から落ちる。
3. **事項レベル** → 依然として Web スクレイピングが必要。ただし §3 で目レベルの結合が実証されたので、**事項層は無くても図は作れる**。優先度は下げてよい。
