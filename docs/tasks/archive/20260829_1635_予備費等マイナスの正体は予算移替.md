# 予備費等マイナス(-5,097億円)の正体は「予算移替」（MOF決算報告書で確認）

[前回調査](20260829_1622_pid4予算あり支出なしと予備費等マイナス調査.md)の続き。RS側のデータだけでは「予備費等」としか分からなかったが、MOFの決算報告書XMLを直接確認し、実態が特定できた。

## 結論

**予備費の使用でも、補正予算の未使用による繰り戻しでもない。デジタル庁の項「情報通信技術調達等適正・効率化推進費」から、他の14府省庁の所管へ予算そのものを付け替えた「予算移替」。** 金額は1円単位でRSの「予備費等1」(-509,690,849,950円)と完全一致。

## 根拠: MOFの決算報告書XML（一次情報）

`https://www.bb.mof.go.jp/server/2024/xml/202477001000217b.xml`（デジタル庁所管 令和6年度歳出決算報告書、`/api/mof-kou/detail?year=2024&id=...003` の `sourceUrl` から辿った）に、通常の事項別決算表とは別建てで **〔予算現額移替調書〕** という表がある。項003「情報通信技術調達等適正・効率化推進費」の行:

| 列 | 値 |
|---|---|
| 歳出予算現額（移替前） | 779,122,893,447円 |
| 移替増加額 | 0円 |
| 移替減少額 | **509,690,849,950円** |
| 差引歳出予算現額（移替後） | 269,432,043,497円（＝RS・マルミエの`budgetAmount`と一致） |
| 備考 | 「会計検査院、内閣、内閣府、総務省、法務省、外務省、財務省、文部科学省、厚生労働省、農林水産省、経済産業省、国土交通省、環境省及び防衛省の各所管へそれぞれ移替減」 |

同じXML内、事項別の歳出決算報告書（通常の列: 歳出予算額・前年度繰越額・**予備費使用額**・**流用等増△減額**・歳出予算現額・支出済歳出額・翌年度繰越額・不用額）では、この事項の予備費使用額・流用等増△減額はいずれも **0円**。予備費は一切使われていない。

## ユーザーの3つの問いへの回答

1. **当初・補正・決算に-5,097億円の痕跡はあるか** — 当初予算・補正予算（歳出予算項目ベース）には出ない（Diet承認額そのままで、移替は予算成立後の行政措置のため）。決算報告書の「事項別歳出決算」表にも出ない（予備費使用額列・流用等増△減額列はともに0）。**決算報告書内の別表「予算現額移替調書」にのみ**、移替減少額として明記されている。

2. **補正で確保した予算が使われず予備費へ繰入られた動きか** — 違う。予備費使用額は0円。実態は「予算移替」＝デジタル庁の項003から、会計検査院・内閣・内閣府・総務省・法務省・外務省・財務省・文部科学省・厚生労働省・農林水産省・経済産業省・国土交通省・環境省・防衛省の**14府省庁の所管へ予算そのものを付け替えた**もの。RS側の列名「予備費等」がやや紛らわしいだけで、予備費とは無関係。

3. **甲乙丙丁号（予備費使用調書）から分かることは** — 甲号・乙号・丙号・丁号は予備費使用の個別案件をまとめた調書のカテゴリだが、今回は予備費使用額が0円のため、これらの調書には本件は載っていない可能性が高い。裏付けとなるのは予備費使用調書ではなく、決算報告書内の「予算現額移替調書」。

## 未解明点

移替先14府省庁ごとの内訳金額はこの表に無い（合計509,690,849,950円のみ）。RS側の支出先ブロック（前回調査）では「各府省庁25先」と件数のみで、府省庁単位・事業単位の按分もRS側で非公開。したがって pid=4 と個別の受け皿事業（例: 他府省庁のIT関連事業）を金額ベースで機械的に紐づけることは、現状公開されている一次資料だけでは不可能。
