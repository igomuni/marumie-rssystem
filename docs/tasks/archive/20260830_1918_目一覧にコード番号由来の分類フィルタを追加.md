# 目一覧にコード番号由来の分類フィルタ（目的別・財政法公債金対象非対象別・経済性質別）を追加

前回追加した使途別に続き、目の複合コード（例: `95016-2111-02`）を構成する残り3つの分類（`docs/mof-budget-data-guide.md` 4-3〜4-5節）も絞り込めるようにした。データ自体は`MOFKouMokuItem`に元から入っていたが、フィルタUIが無かった。

## 追加した3分類

- **目的別**（3桁・`objectiveName`）: 国家機関費・地方財政費・防衛関係費・社会保障関係費・国債費…（政府関係機関の帳票には無い）
- **財政法公債金対象非対象別**（1桁・`fiscalLawName`）: 財政法公債金対象経費／上記以外のもの（一般会計にしか無い）
- **経済性質別**（2桁・`economicNatureName`）: 経常支出・雇用者報酬・資本形成・現金による社会保障給付…（政府関係機関の帳票には無い）

`client/components/mof-kou-moku/FilterSidebar.tsx`に使途別と同じ複合選択コンボとして追加、`app/mof-kou-moku/page.tsx`で連鎖絞り込み（勘定までの上位フィルタで候補を絞る）に組み込んだ。

## 確認

- `npx tsc --noEmit` / `npm run lint`: エラーなし
- ブラウザで「目的別」コンボを開き、35件の分類（一般行政費・国土保全費・防衛関係費等）が候補に出ることを確認
