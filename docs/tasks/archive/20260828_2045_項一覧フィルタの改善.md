# 項一覧フィルタの改善（複数選択コンボ・sankey-svg準拠スタイル・幅調整ハンドル）

前回実装（左サイドパネル化）へのフィードバックを反映。

## 対応内容

- **コンボを複数選択チェックボックス化**: 予算種別・会計区分・所管・組織/特会/機関・勘定/業務の5コンボを`<select>`から`MultiSelectCombo`（新規）に変更。`/sankey-svg`の省庁・会計区分フィルタと同じ実装（ボタン→`createPortal`でdocument.body直下にドロップダウン→外側クリックで閉じる→スクロール/リサイズで位置再計算）を踏襲。空配列=絞り込みなし、1件でもチェックするとホワイトリストになる挙動も同じ
- **検索テキストボックス・スライダーを`/sankey-svg`準拠に**: `RegexTextFilter`は`.*`トグルを入力欄内に埋め込み、有効時は青（`bg-blue-600`）、placeholderを「正規表現」/「部分一致」に動的切替。レンジスライダーはトーン（枠線・文字色・フォントサイズ）を揃えた
- **左サイドパネルの幅調整ハンドル**: サイドパネルと一覧の間のマージン部分（`w-3`＝12px）自体をドラッグ可能な要素にした。以前はKouSidePanel同様パネル自身の端に細い帯を重ねる方式だったが、今回は明示的に「一覧と一覧の間」に独立した`role="separator"`要素を置く実装にした（`app/mof-kou/page.tsx`の`startSidebarResize`）

## 実装上の注意

- 複数選択化に伴い、`FilterSidebarState`の5フィールド（account/budgetType/ministry/organization/subAccount）は`string`から`string[]`に変更。カスケード（会計区分→所管→組織→勘定）は、上位を変更したときに下位の選択済み値が新しい選択肢に存在するものだけを残す`pruneToOptions()`で処理（旧実装のような全リセットではなく、有効な選択だけ温存）
- 会計区分は内部的に`accountType`（`general`/`special`/`agency`）だが、`MultiSelectCombo`は値＝表示ラベルの単純な文字列リストという設計にしたため、選択状態は`ACCOUNT_LABEL`の表示ラベル（"一般会計"等）で保持し、フィルタ時に`ACCOUNT_LABEL[row.accountType]`と比較する
