# サイドパネルのタブ・列幅維持とコンボの排他開閉

## 右サイドパネルの列幅調整・タブ選択状態の維持

`client/components/mof-kou/DataGrid.tsx`のソート・列幅（`useState`で内部管理）が、タブ切り替えのたびにそのタブのコンポーネントごとアンマウントされてリセットされていた。また`KouSidePanel.tsx`の`tab`（アクティブタブ）も内部`useState`で、年度切替時に一瞬`selectedRow`が無くなり`KouSidePanel`自体がアンマウントされることでリセットされていた（フィルタ・選択行の維持と同じ根本原因）。

DataGridを`state`/`onStateChange`のcontrolledコンポーネントに変更し、`KouSidePanel`の`tab`・4タブぶんのグリッド状態（`PanelGridStates`）を`app/mof-kou/page.tsx`（`KouSidePanel`がアンマウントされても消えない層）に持ち上げた。

## コンボの排他開閉

`client/components/mof-kou/MultiSelectCombo.tsx`は各インスタンスが独立して`open`をuseStateで持っていたため、あるコンボが開いた状態で別のコンボのボタンをクリックすると、前者は閉じ後者が開く（意図した動作だが紛らわしい）挙動になっていた。`FilterSidebar.tsx`に`openField`（今どのフィールドが開いているか）を集約し、`MultiSelectCombo`の`open`/`onOpenChange`をcontrolled propsに変更。開くときは他を必ず閉じる排他制御にした。

なお、ユーザー報告の「外側クリックでマウスダウン時は消えるがマウスアップで再度表示される」現象はPlaywrightで複数パターン再現を試みたが再現せず、正確な原因は特定できていない。排他制御への変更により、体感上の「閉じたはずが別のものが開く」ケースは解消される見込み。

## 検証

- `npx tsc --noEmit` / `npm run lint`: クリーン
- Playwrightで: コンボの排他開閉（同時に開くのは常に1つ）、タブ切替時の列幅維持、年度切替時のタブ・列幅維持（識別子が安定した項で）を確認
