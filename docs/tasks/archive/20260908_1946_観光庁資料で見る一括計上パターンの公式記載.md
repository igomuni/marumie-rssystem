# 観光庁資料で見る『国際観光旅客税財源観光振興費』一括計上パターンの公式記載

[『情報通信技術調達等適正・効率化推進費』のあるべき姿](20260906_2221_情報通信技術調達等適正効率化推進費のあるべき姿.md)で「良好な比較対象」として挙げた『国際観光旅客税財源観光振興費』について、観光庁自身の公式資料（`https://www.mlit.go.jp/kankocho/yosan_zeisei/yosan/index.html`）を実際に確認した。**「一括計上」という言葉そのものが、閣議決定レベルの公式文書に明記されている**ことが分かった。デジタル庁の資料には無かった記載の仕方で、比較材料として有用。

## 核心の記載: 「観光庁に一括計上した上で、関係省庁に移し替えて執行する」

`02_kettei_gaiyou_r6.pdf` p.48（「国際観光旅客税の使途に関する基本方針等について②」、令和3年12月24日観光立国推進閣僚会議決定）に、この予算の仕組みそのものを説明する一節がある。

> また、受益と負担の関係を明確化し、予算の総合性の確保等を図る観点から、旅客税財源を充当する具体的な施策・事業について、予算書においても旅客税財源を充当する予算を明確化し、**観光庁に一括計上した上で、関係省庁に移し替えて執行する**。ただし、三の丸尚蔵館及び皇居東御苑大手休憩所（仮称）の整備に係る経費については、皇室経済法（昭和22年法律第4号）を踏まえ、皇室費における宮廷費として整理する。

デジタル庁の資料18点にはこの種の説明は一切無く、「一括計上」という言葉自体も登場しなかった（前回調査済み）。**観光庁側は、閣議決定という最上位の政策文書レベルで、一括計上→移替という会計処理そのものを明文化している。**

**この表は、以前MOF決算CSVを項名で串刺しして機械的に復元した受け皿4省庁（法務省・財務省・文化庁・環境省）の内訳と金額規模がほぼ一致する**（法務省72.0億円＝出入国管理業務庁費、財務省24.9億円≈25億円＝税関業務特別庁費、文化庁80.9億円≈81億円＝文化資源活用委託費+事業費補助金の合算、環境省51.0億円＝国立公園等資源整備関連の合算）。つまり**決算CSVを機械的に処理しなくても、観光庁のこの1枚の表を読むだけで受け皿と金額が分かる**。

### 新たな発見: 宮内庁37億円（以前のMOF決算調査では未検出）

前回のMOF決算CSVによる受け皿調査では**法務省・財務省・文化庁・環境省の4省庁しか受け皿として検出していなかった**が、この表には**宮内庁37億円**が別枠で明記されている。p.4の記載と符合する。

> 上記のほか、宮内庁計上の三の丸尚蔵館の整備20億円（前年度3億円）及び皇居東御苑大手休憩所（仮称）の整備17億円についても、国際観光旅客税財源を充当。

20億円＋17億円＝37億円で一致。ただし上記の「一括計上→移替」の説明文にあるとおり、**この宮内庁分は一括計上・移替の対象外で、皇室費の宮廷費として別途整理される**（会計処理上、観光庁の項を経由しない）。したがって以前のMOF決算CSV調査（項『国際観光旅客税財源観光振興費』の決算での受け皿を項名で串刺し）で宮内庁が出てこなかったのは正しい挙動で、**観光庁の項自体からは宮内庁分への移替は行われていない**（別の財源充当の仕組み）と分かる。これは前回調査の見落としではなく、対象範囲が違うことの確認。

## 概算要求段階（01）でも同じ仕組みが説明されている

`01_gaisan_yokyu_r6.pdf` p.26に、概算要求段階（令和5年8月）でも同じ閣僚会議決定への参照がある。

> 令和6年度に国際観光旅客税の税収を充当する施策については、「国際観光旅客税の使途に関する基本方針等について」（令和4年12月23日観光立国推進閣僚会議決定）に基づき、既存施策の財源の単なる穴埋めをするのではなく、①受益と負担の関係から負担者の納得が得られること、②先進性が高く費用対効果が高い取り組みであること、③地方創生をはじめとする我が国が直面する重要な政策課題に合致することを基本的な考え方とし、特に新規性・緊急性の高い施策に充てる。

概算要求額は42,000百万円（420億円）で、決定額440億円（p.48）と差がある（要求→決定で20億円増加）。ただし「一括計上」の明文化・執行官庁別内訳表は**概算要求段階の01には無く、決定段階の02・03で初めて登場**する（要求段階ではまだ各府省への配分が固まっていないためと見られる）。

## デジタル庁との比較

| 観点 | 国際観光旅客税財源観光振興費（観光庁） | 情報通信技術調達等適正・効率化推進費（デジタル庁） |
|---|---|---|
| 「一括計上」の明文化 | **あり**（閣議決定文書に明記、02のp.48） | **無し**（18資料のどこにも「一括計上」という言葉が登場しない） |
| 制度の根拠 | 観光立国推進閣僚会議決定（令和3年12月24日、毎年改定） | 見当たらない（デジタル庁設置法等の一般的な所掌規定のみ） |
| 執行官庁別の金額表 | **あり**（3分野×執行官庁で440億円を完全に内訳表示） | **一部あり**（06の補正予算概要に主要事業のみ、「等」で打ち切り） |
| 受け皿の一覧の網羅性 | 4省庁＋宮内庁（別枠）まで含めて100%説明済み | 74組織のうち主要なもの（財務省393億円等）のみ判明、全体は不明 |
| 決算段階での同種資料 | 未確認（今回は予算段階のみ調査） | 04・11（政策対応表）はあるが項1本のまま分解されない |

**観光庁は「なぜ一括計上するのか」「誰にいくら渡すのか」を制度・金額の両面で説明しているのに対し、デジタル庁は「一括計上」という自覚的な説明そのものが無く、受け皿の内訳も主要事業に限られる。** 同じ会計処理（一括計上・移替）でも、府省庁による情報公開の姿勢に明確な差があることが、両者の一次資料を実際に比較して確認できた。
