# 明細表 ↔ MOF 突合 X carry-forward（項 X* を source のみで上方向走査で取れるか）— preregistration

状態: **契約（実行前に固定）。** 結果は別の task doc に書く。閾値なし、記述のみ。昇格・matched はなし。
前提: K2 feasibility（#450、マージ済み）。J1、eligible の定義、入力 hash guard は P1/K2 から**変えない**。H1 全体は PAUSED のまま。O（組織）の一般化は本段の範囲外（source のみでの組織の認識は別問題）。

## 問い
K2 で「直前の行が項」でなかった行（単一694行のうち220、複数215行のうち121）について、DETAIL から上方向に走査して最初に現れる項の行 X* は、MOF の `sectionName` と一致するか。走査の距離と間にある行の種類から、X* が本当に項の scope の持ち越しかをどう判断できるか。

## X*（事前固定。MOF の値は探索条件に使わない）
- 同じ source の行順で、DETAIL の1つ前から上方向へ走査し、**最初に現れる `row_type` が `CODE3` または `CODE2` で、`事項` が `^([0-9]{2,3}) (.+)$` に合う行**の名称部を X* とする。見つからなければ X* なし。
- X* を取った**後に**初めて MOF と比較する。比較は `sectionName == X*` の exact のみ。正規化・部分一致・NFKC・金額・辞書・O は使わない。
- K2 の X（直前の行が項の行）と X* は、直前の行が項なら一致する（距離1）。

## 集計（単一694行・複数215行を、それぞれ「距離1（K2 で X あり）」と「距離2以上（carry）」に分ける）
- 距離の分布: 1 / 2 / 3〜5 / 6〜20 / 21以上 ／ X* なし。
- 走査で飛ばした行（DETAIL の1つ前から X* の1つ後まで）の `row_type` 別の行数: `DETAIL`、`CODE_5_4_2_4`、`CODE_NN_NNNN`、それ以外の `CODE3`/`CODE2`（`NN[N] 名称` に合わないもの）、その他。DETAIL を1行以上またぐ行数（X* が前の DETAIL より上にある）の分布。
- **単一694（対照）:** `sectionName == X*` の行数を、距離1と、carry の距離帯ごとに示す。carry（220行）での一致数が本題。
- **複数215:** `sectionName == X*` を満たす J1 候補の数（0 / 1 / 2+）を、距離1と carry に分けて示す。1件でも matched に昇格しない。1件になる行で、その候補の `col4Raw` が末尾2桁と一致する数（K3 の記述。独立な裏付けではない）。
- carry の不一致行について、X* の名称と MOF の `sectionName`（単一の場合は唯一の候補）の例を、各距離帯から最大5件、行コードとともに列挙する（原因の観察用。分類は結果レビューで決める）。

## 禁止・限界
- 一致・不一致を見て走査規則を変えない（規則は上の1つだけ）。「項の子の CODE3 を飛ばす」などの変種は、結果を見たうえで別に事前登録する。
- X* が項であることは仮説で、単一694での一致率で見るだけ。昇格・正規化の採否は別。
