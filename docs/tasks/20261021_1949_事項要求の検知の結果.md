# 事項要求の検知の結果（FY2023〜2027）

状態: 実装・集計済み（`scripts/pipeline-v2/build-budget-request-jikou-youkyu.ts`、仕様は `docs/budget-request-jikou-youkyu.md`）。

- 金額を示さない要求の候補は、年度ごとに 62〜95 項。
- 印のある項の多くは、当初予算が要求額を上回る（FY2023 で 60 項中 41 項）。
- 要求0 の項は、約 4 割で編成の段階で額が付く。毎年同じ項が繰り返し現れる。

## 残る課題

- 組織の行に付いた印（年度ごとに 10〜27 件）は、項に割り振っていない。その組織のどの項の事項要求かは、備考の本文を読まないと分からない。
- 項に結びつかない印（年度ごとに 3〜34 件）。
  - 多くは、直前の明細表の行から 12 行より離れたもの。備考の長い文の途中などで、厚生労働省の介護職員の処遇改善の文や、文部科学省の分冊にある。
  - 残りは、勘定の行に付いたもの（子ども・子育て支援勘定）と、明細表以外の説明の頁。
- UI（年度推移の「データの状態」・バッジ・詳細の注）には、備考に記載がある項（印・文）だけを載せた。要求0 は前年度限りの経費（例: FY2027 の財務局施設費。備考に「前年度限りの経費」）なども含み、事項要求とは言えないため（ユーザーの指摘）。「前年度限り」の記載で除く案は、要求0 の項のうち記載が見つかるのが年度ごとに 2〜5 項で、範囲の取り方でも漏れるため採らなかった。
