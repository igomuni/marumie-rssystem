# docs/tasks 整理: archive 移動候補の洗い出し

## 目的

`docs/tasks/` 直下が 78 本まで増え、`INDEX.md` が 1 画面に収まらなくなっている。
`INDEX.md` は「過去の検討を探すときに最初に読む」索引であり、その読み込みコストが
探索コストの下限になるため、役目を終えた doc を `archive/` に移して索引を短く保つ。

## 前提: 現行の archive 運用

- `docs/tasks/archive/` には 2025-11 〜 2026-05-18 の doc が約 200 本入っている
- `INDEX.md` は **archive 内の doc を一切列挙していない**（直下 78 本のみ）
- したがって「archive に移す」= ファイル移動 + `INDEX.md` から該当行を削除、の2操作

## 最重要の注意: コードから参照されている doc がある

一部の task doc は実装コードやガイドから「設計の正典」として参照されている。
これらは実装済みでも**移動するとリンクが切れる**ため、A 群からは外した。

## 実施手順（A 群のみ適用する場合）

```bash
cd docs/tasks
git mv 20260525_0505_rs-vis反映対応案.md archive/
# … A 群24本を同様に移動
```

その後 `INDEX.md` から該当24行を削除する（78行 → 54行）。
移動と索引更新は必ずセットで行う（片方だけだと索引がリンク切れになる）。

- `INDEX.md` が 78 行 → 54 行（A 群のみ）／ 46 行（A+B 群）
