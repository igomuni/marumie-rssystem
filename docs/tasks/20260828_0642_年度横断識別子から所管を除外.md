# 年度横断識別子から所管を除外

`基礎年金給付費`（特別会計・年金・基礎年金勘定）は令和6→7年度で所管表記が
「内閣府及び厚生労働省」→「厚生労働省」に変わっていた（共管解消。組織・特会・勘定・
項コード・目コード・目名は完全に同一）。年度をまたぐ同一性判定（`identityKey`）が
所管も含めていたため、この境目で「別の目/事項」として扱われ、令和6年度以前のRS紐づけ・
年度推移が途切れていた（`/mof-kou-moku`のRS引き継ぎ機能・年度推移、`/mof-jikou`の年度推移
すべてで同じ症状）。

## 対応

所管（ministry）を`identityKey`の構成要素から外した。会計区分・組織・特別会計・勘定・
機関・項コード・（目の場合は目分類コード・）名称が一致すれば同一とみなす。

- `app/lib/api/mof-jikou-loader.ts`: `identityKey`/`identityFromKey`
- `app/lib/api/mof-kou-moku-loader.ts`: `identityKey`/`identityFromKey`
- `scripts/generate-mof-rs-linkage.ts`: `jikouIdentity`（`identityFromKey`と突き合わせるため同じ構成に追従。`mof-rs-linkage-2024.json`を再生成）

`generate-mof-rs-kou-moku-linkage.ts`の決算目引き継ぎ（`carryoverIdentity`）は同一年度内の
突合なので対象外（所管表記は年度内では変わらない）。

## 衝突チェック

所管を外したことで別所管の項目が誤って同一視されないか、全10年度分・jikou/kou-moku両方で
機械的に確認した。結果は0件（衝突なし）。組織名・特別会計名が実質的に所管を一意に含意する
ため、所管を外しても実害が無いことを確認済み。

## 確認

- `基礎年金給付費`のkou-moku年度推移: 平成29〜令和8年度（10/10年度）に復元
- 同一項目のjikou年度推移: 同じく全期間に復元
- `/mof-kou-moku`の2026年度でRS↗バッジが復活（2024年度から引継ぎ表示）
