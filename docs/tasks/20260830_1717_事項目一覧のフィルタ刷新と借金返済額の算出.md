# 事項・目一覧のフィルタを項一覧に統一、使途別フィルタ追加、予算書データベースへのリンク、借金返済部分の算出

## 実装内容

### 1. `/mof-jikou`・`/mof-kou-moku` のフィルタを `/mof-kou` と同じ左サイドパネル構成に統一

従来はヘッダー下に横並びの `<select>`/トグルボタン列だったものを、`/mof-kou` と同じ「フィルタ」ボタン開閉式の左サイドパネル（チェックボックス付き複数選択コンボ・正規表現トグル付きテキスト検索・範囲スライダー）に置き換えた。

- `client/components/mof-jikou/FilterSidebar.tsx`（新規）: 予算種別・会計区分・所管・組織/特会/機関・勘定/業務・主要経費（コンボ化）、事項名・横断検索（テキスト）、本年度額・前年度額・増減額・増減率（スライダー）
- `client/components/mof-kou-moku/FilterSidebar.tsx`（新規）: 同上に加えて**使途別**（後述）を追加。項名・目名の横断検索、同じ数値スライダー群
- `app/mof-jikou/page.tsx` / `app/mof-kou-moku/page.tsx`: 個別 `useState` の羅列だったフィルタ状態を `FilterSidebarState` 1本にまとめ、`/mof-kou` と同じ連鎖絞り込み（会計区分→所管→組織→勘定→主要経費）ロジックに統一。ページングは維持（件数が多いため）。`/mof-kou-moku` の RSあり/なしトグルは目特有の状態のためツールバーに残した。

### 2. 目の使途別フィルタ

`MOFKouMokuItem.purposeName`（予定経費要求書の科目別内訳の各目に付したコード番号の1桁目による分類: 人件費・旅費・物件費・施設費・補助費及委託費・他会計へ繰入・その他）を新しいコンボフィルタとして追加。「他会計へ繰入」で絞ると令和8年度当初+暫定+補正の目12,467件中170件に絞れることを確認。

### 3. ヘッダーに予算書・決算書データベースへのリンク

`app/lib/mof-archive-url.ts`（新規）: 会計年度→財務省アーカイブページURL（`https://www.bb.mof.go.jp/archive/{heisei29〜30|reiwa1〜8}.html`）の変換。`/mof-kou`・`/mof-jikou`・`/mof-kou-moku` のヘッダー「◯年度／財務省 予算書（・決算書）データベース」をこのURLへのリンクにした。

### 確認

- `npx tsc --noEmit` / `npm run lint`: エラーなし（既存warningのみ）
- ブラウザで両ページのサイドパネル表示・使途別フィルタの絞り込み・ヘッダーリンク（`reiwa8.html`へ正しく遷移）を確認

## 一般会計歳出における「借金返済部分」の合計額（メソドロジーと実例）

`/mof-kou` の新フィルタで「所管: 財務省」「項名: 国債費」に絞ると、令和5年度（2023）決算の内訳（事項別）が確認できる:

| 区分 | 事項 | 金額 |
|---|---|---|
| 元本償還財源 | 定率繰入・社会資本整備事業特別会計整理収入等・年金特例公債償還財源・その他公債等償還財源（4事項） | **16,756,068,008,000円（16.76兆円）** |
| 利払い財源 | 公債利子等の支払財源・年金特例公債利子の支払財源（2事項） | **7,581,978,475,000円（7.58兆円）** |
| 事務取扱い・諸費 | 事務取扱いに必要な経費・諸費財源（2事項） | 21,989,007,000円（0.02兆円） |
| 決算剰余金繰入 | 決算上の剰余金の繰入 | 1,314,727,567,000円（1.31兆円） |
| **国債費合計（決算）** | 上記9事項 | **25,674,763,057,000円（25.67兆円）** |

「借金返済部分」をどう定義するかで答えが変わる:

- **元本償還のみ**（狭義の「返済」）: **約16.76兆円**
- **元本＋利払い**（借金にまつわる支出全体、事務取扱い・剰余金繰入を除く）: **約24.34兆円**
- **国債費全体**（決算ベース、事務取扱い・剰余金繰入を含む）: **約25.67兆円**

いずれも一般会計側の「繰入」ベースの数字で、実際に国債整理基金特別会計が執行した償還・利払い総額（借換債分を含む、[前回調査](20260830_0958_国債の深堀り調査.md)参照）とは別物である点に注意。
