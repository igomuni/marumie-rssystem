# 2024年度MOF項 公式移替全件照合

## 結果
- 決算のみ: 254項
- 令和6年度一般会計予算総則第15条の公式移替と「項名＋移替先所管」が一致: **164項 (64.6%)**
- 同名別所管として機械分類済み: 173項
- そのうち公式移替一致: **164項 (94.8%)**
- 同名別所管だが第15条だけでは一致しない: 9項

## 解釈
「同名項が別所管・組織に存在」という決算増加パターンの大部分を、財務省の公式移替表で直接裏付けられた。
決算時の項数増加には、一括計上等された項を年度中に他所管へ移替し、移替先側にも同名項が立つ構造が大きく寄与している。

## 次
残る9項について、令和5年度予算の繰越分に対する移替、組織・事務移管、別条項等を照合する。
また、決算のみ254項の残り90項について、補正新設・コード変更/分割・ゼロ額項等の既存分類と統合し、254項を100%分類する。
