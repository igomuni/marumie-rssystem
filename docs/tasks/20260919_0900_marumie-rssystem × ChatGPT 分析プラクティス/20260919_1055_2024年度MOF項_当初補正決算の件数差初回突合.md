# 2024年度MOF項 当初・補正・決算の件数差 初回突合

## 目的

2024年度MOF「項」データについて、当初予算・補正予算（第1号）・決算で件数が異なる理由を、ChatGPTローカル環境に保存済みのデータだけでどこまで追えるか確認する。

今回は理由を先に決めず、まず同一キーで機械突合できる比較土台を作る。

## 使用データ

- `mof-kou-2024.json.zip`
- `DL202411001.zip`（当初・一般会計）
- `DL202412001.zip`（当初・特別会計）
- `DL202413001.zip`（当初・政府関係機関）
- `DL202421001.zip`（補正第1号・一般会計）
- `DL202422001.zip`（補正第1号・特別会計）
- `DL202477001.zip`（決算・一般会計）
- `DL202478001.zip`（決算・特別会計）
- `DL202476001.zip`（決算・政府関係機関）

## 突合キー

`mof-kou-2024.json` の各sectionについて次を複合キーとした。

```text
accountType
ministry
organization
specialAccount
subAccount
agency
sectionCode
sectionName
```

単なる項名一致ではなく、会計・所管・組織等を含めた同一項として比較する。

## 当初 → 補正

- 共通: 972件
- 当初だけ: 82件
- 補正だけ: 25件

当初だけ82件の内訳:

- 特別会計: 51件
- 政府関係機関: 22件
- 一般会計: 9件

補正だけ25件の内訳:

- 一般会計: 24件
- 特別会計: 1件

したがって、当初1,054→補正997の57件減は、主として「政府関係機関が補正データに0件」「特別会計の掲載項が減る」ことと、補正で新たに現れる一般会計項が相殺された結果である。

### 重要な訂正

以前の会話では補正の `○○外N目` 集約が「項の件数差」の有力要因と考えたが、今回の突合ではこれは直接の原因ではないと分かった。

`外N目` は項の内部にある `detailNames`（目側）の表現であり、今回比較しているsection＝項そのものの件数とは階層が異なる。目の件数差を説明する要素にはなり得るが、項1,054→997の差を直接説明するものではない。

## 当初 → 決算

- 共通: 1,016件
- 当初だけ: 38件
- 決算だけ: 254件

決算だけ254件の内訳:

- 一般会計: 203件
- 特別会計: 51件

決算だけの項名には同じ名称が複数の所管・組織で現れるものが多い。

上位例:

- 情報通信技術調達等適正・効率化推進費: 74件
- 科学技術イノベーション創造推進費: 15件
- 放射能調査研究費: 7件
- 沖縄振興交付金事業推進費: 7件
- 沖縄開発事業費: 6件
- 南極地域観測事業費: 6件
- 宇宙開発利用推進費: 6件
- 地球環境保全等試験研究費: 6件
- 北海道開発事業費: 5件
- 地方創生基盤整備事業推進費: 5件

この並びは、一括計上・移替等によって決算時に執行側の所管・組織へ項が現れる既存の観察と整合的。ただし254件すべてを移替由来と断定はしない。

決算CSVの `予算決定後移替増△減額(円)` を項単位に集計した初回確認では、決算だけ254件のうち同列が非ゼロだったものは一般会計30件・特別会計3件だった。したがって「決算だけ＝すべて移替」と単純分類することもできない。項の生成理由をさらに分類する必要がある。

## 現時点で分かったこと

項の件数差は「同じ母集団を予算段階ごとに単純増減した数字」ではない。

特に、

1. 補正には政府関係機関22項が含まれていない
2. 補正では特別会計の掲載項が当初より50件少ない（純減）
3. 一方で一般会計は当初784→補正799と15件増える
4. 決算では一般会計978、特別会計270まで増え、当初に存在しない複合キーが254件現れる
5. 決算だけの項には一括計上・移替で既知の項名が大量に含まれる

ところまで、ローカルデータだけで機械的に確認できた。

## 次のタスク

次は「件数差」から「差が生じた理由」の分類へ進む。

優先順:

1. 当初だけ82件 / 補正だけ25件を全件分類し、補正帳票の掲載仕様による差か、本当に項が新設・消滅したのかを分ける
2. 決算だけ254件を、移替受け皿・予備費使用・組織/コード変更・その他に分類する
3. 当初あり→決算なし38件について、移替元として消えたのか、名称・コード変更なのかを確認する
4. 必要に応じて「項コードを外した名称ベース」「項名を外したコードベース」の第二突合を行い、単なる識別子変更を分離する

この分類までできれば、1,054 / 997 / 1,270という3つの件数がなぜ異なるのかを、件数付きで説明できる状態に近づく。
