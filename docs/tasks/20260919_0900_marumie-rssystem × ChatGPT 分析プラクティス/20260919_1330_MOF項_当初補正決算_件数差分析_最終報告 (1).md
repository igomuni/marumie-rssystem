# 2024年度 MOF「項」当初・補正・決算 件数差分析 最終報告

## 1. 目的
令和6年度（2024年度）の財務省予算・決算データについて、当初予算・補正予算第1号・決算で「項」の件数が異なる理由を明らかにする。

## 2. 件数
| 区分 | 全体 | 一般会計 | 特別会計 | 政府関係機関 |
|---|---:|---:|---:|---:|
| 当初予算 | 1,054 | 784 | 248 | 22 |
| 補正第1号 | 997 | 799 | 198 | 0 |
| 決算 | 1,270 | 978 | 270 | 22 |

当初→決算では見かけ上 +216項。ただし、当初に存在せず決算に存在する行は254項あり、逆に当初のみ38項もあるため、単純な純増ではない。

## 3. 補正第1号997項の内訳確認
補正第1号997項について、各項に属する「目名」に `外N目` 表記が含まれるかを確認した。

| 区分 | 項数 | 補正997項に占める比率 |
|---|---:|---:|
| `外N目` を含む項 | 433 | 43.4% |
| `外N目` を含まない項 | 564 | 56.6% |
| 合計 | 997 | 100.0% |

ここでの `外N目` は「目」レベルの省略・集約表記であり、それ自体を「項」件数減少の原因とは扱わない。

### 3.1 `外N目` を含まない564項と当初予算の関係
564項を当初予算と突合すると、次のようになった。

| 当初予算との関係 | 項数 |
|---|---:|
| 当初にも項が存在し、当初金額が0円 | 37 |
| 当初には項自体が存在しない | 25 |
| 上記合計（当初段階で実質0または未存在） | 62 |
| その他 | 502 |
| 合計 | 564 |

したがって、`外N目` の影響を除いて見ても、補正第1号には当初段階で金額0円だった項や、当初には存在しなかった項が一定数含まれる。

### 3.2 当初に存在しなかった25項と決算の関係
当初に存在しなかった25項を決算まで追跡すると、24項が決算にも存在し、1件は決算側に同じ項として残らなかった。

決算にも存在する24項のうち、23項は本報告の「決算のみ254項」の最終分類で **「補正第1号で新設・計上」** に分類した23項と一致する。残る1項は **「脱炭素成長型経済構造移行推進エネルギー対策特別会計へ繰入」** で、補正第1号で新規計上されている一方、決算側の同名項との関係から最終分類では「所管・組織展開」側に含めている。

つまり、補正側から独立に追った結果と、決算254項側から逆向きに分類した結果はほぼ一致している。これは「補正第1号で新設・計上23項」という分類のクロスチェックにもなっている。

> 注：先の口頭確認では「25項のうち23項が完全一致」と説明したが、厳密には **25項中24項が決算にも存在し、その24項中23項が最終分類の『補正第1号で新設・計上』と一致**する。ここではデータ突合結果に基づき訂正して記載する。

## 4. 決算のみ254項の最終分類
| 分類 | 件数 | 比率 |
|---|---:|---:|
| 所管・組織展開（移替・繰越・行政移管等） | 173 | 68.1% |
| 項コード差（実質同一項） | 51 | 20.1% |
| 補正第1号で新設・計上 | 23 | 9.1% |
| 前年度繰越＋行政移管（厚労省→国交省） | 4 | 1.6% |
| 前年度繰越のみ（当年度歳出予算額0） | 3 | 1.2% |
| 合計 | 254 | 100.0% |

## 5. 結論
「決算のみ254項」は「年度中に新しい政策項が254件追加された」ことを意味しない。

最大要因は、同じ項が決算段階で別所管・別組織へ展開する移替等（173項）。次に、実質的に同一の項であるにもかかわらず項コードが異なるもの（51項）が続く。補正第1号で新規に計上されたと確認できたものは23項で、254項の約9%にとどまる。

したがって、当初1,054項→決算1,270項という +216 の件数差を「項が216個増えた」と解釈してはいけない。決算の項集合は、当年度予算、補正、予算決定後移替、前年度繰越、繰越分の行政・組織移管、特別会計固有処理、コード体系差が合成された集合である。

## 6. 主な検証結果
### 6.1 予算総則による移替
決算のみ254項のうち「当初に同名項があるが決算では別所管・組織にも現れる」173項を抽出。そのうち164項は、財務省「令和6年度一般会計・特別会計移替経費内訳」の予算総則第15条による移替先と、項名＋移替先所管で一致した。

代表例：
- 情報通信技術調達等適正・効率化推進費
- 科学技術イノベーション創造推進費

### 6.2 前年度繰越
決算では当年度歳出予算額が0円でも、前年度繰越額によって項が存在し得る。

例：
- 児童福祉施設整備費：前年度繰越 395,623,100円
- 新型コロナウイルス感染症対応地方創生推進費：前年度繰越 1,468,224,766円
- 独立行政法人農林水産消費安全技術センター施設整備費：前年度繰越 511,693,166円

### 6.3 水道行政移管
令和5年度からの繰越分について、水道行政移管に伴う厚生労働省→国土交通省の移替を確認。

- 水道施設災害復旧事業費：4,330,561,500円
- 生活基盤施設耐震化等対策費：45,258,792,360円

厚労省側で同額のマイナス移替、国交省側で同額のプラス移替となり、移替元・移替先双方が決算項として現れる。

### 6.4 項コード差
51項は会計・範囲・項名が実質同一で、項コードのみが異なった。東日本大震災復興特別会計に集中しており、項コードを年度・予算種別を超えた永続IDとして扱うことはできない。

### 6.5 補正第1号
補正第1号CSVとの直接照合で23項を補正による新設・計上として分類した。代表例：
- 半導体・人工知能関連技術基盤強化対策費
- 海洋気象観測船建造費
- 各種独立行政法人施設整備費
- 独立行政法人エネルギー・金属鉱物資源機構出資
- 防衛力強化資金へ繰入

## 7. 金額構造
決算では概ね次の関係を保持する。

`歳出予算額 + 前年度繰越額 + 予備費使用額 + 予算総則による増額 + 流用等増減額 + 予算決定後移替増減額 = 歳出予算現額`

`歳出予算現額 = 支出済歳出額 + 翌年度繰越額 + 不用額`

今回検証した主要項では、この関係が成立した。

## 8. まるみえRSへの示唆
1. 項コードを永続IDとして使用しない。
2. 「予算上の項レコード」と「実質的に同一の項（canonical item）」を分離する。
3. 当初・補正・決算を単純な上書き時系列にせず、budget eventとして保持する。
4. 移替は金額属性だけでなく source→destination のエッジとして保持する。
5. 繰越には元予算年度を保持する。
6. UIでは「新設」「補正追加」「移替受入」「前年度繰越」「行政移管」「コード変更」を区別する。
7. 件数比較では raw 項数と canonical 項数を併記する。
