# 2024年度MOF項 公式移替表との照合
財務省「令和6年度決算の説明」付表を一次資料として照合。

- 情報通信技術調達等適正・効率化推進費: 歳出予算現額 685,739,597千円、移替額計 509,690,849千円、差引 176,048,747千円。14所管へ移替。
- 科学技術イノベーション創造推進費: 歳出予算現額 77,243,878千円、移替額 73,198,357千円、差引 4,045,521千円。8所管へ移替。
- 主要ケースについて予算総則第15条に基づく移替が制度的根拠であることを確認。
- 受け皿側決算CSVの移替列だけでは復元不十分。公式移替経費内訳を正本として照合する。
- デジタル庁の個別14所管額はWeb抽出値の合計と公式総額に8千円差があり、個別額は再照合対象。

次: 公式移替表全体を構造化し、決算のみ254項・同名展開173項との説明率を算出。
