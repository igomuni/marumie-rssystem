# 2024年度MOF項 決算増加と移替構造の深掘り

## 目的

当初1,054項→決算1,270項の増加について、決算一次CSVの「歳出予算額」「予算決定後移替増△減額」まで使って、同名項が別所管・組織に現れる現象を検証する。

## 結果

- 決算のみ254項のうち、一般会計で「当初に同名項があり、決算では別所管・組織に現れる」ものは173項、29項名。
- この173項のうち、決算CSVの「予算決定後移替増△減額」が非0なのは26項だけ。したがって **同名項の別組織出現 = 当該列の移替額非0** とはならない。
- 代表例「情報通信技術調達等適正・効率化推進費」は受け皿74項すべてで当該移替列が0だが、受け皿側の歳出予算額合計は509,690,849,950円。つまり受け皿への配賦は「歳出予算額」自体に既に織り込まれており、決算CSVの「予算決定後移替」列だけでは一括計上・移替の全体像を復元できない。
- 「科学技術イノベーション創造推進費」は受け皿15項のうち10項で移替列が非0。項名によって記録のされ方が異なる。

## 含意

件数増の構造説明には、(1) 同名項が複数組織へ展開された事実、(2) 金額が受け皿側の歳出予算額として現れるケース、(3) 予算決定後移替列にも増減が記録されるケース、を分ける必要がある。

次段階では、主要29項名について「当初の送り手→決算の受け皿」のネットワークを作り、金額保存性と一次資料上の一括計上/移替根拠を突合する。
