# 2024年度MOF項 残余9項の解明

同名別所管173項のうち、令和6年度予算総則第15条で直接一致した164項以外の9項を一次資料で再調査。

## 結果
- デジタル庁「科学技術イノベーション創造推進費」：令和5年度決算で500,000千円を翌年度繰越。令和6年度に継続。
- こども家庭庁「初等中等教育振興費」：前年度繰越。
- 内閣本府「内閣官房共通費」：前年度繰越＋組織移管。
- 厚労省「水道施設整備費」「沖縄開発事業費」「水資源開発事業費」「離島振興事業費」「北海道開発事業費」：令和5年度からの繰越分。水道行政移管に伴い令和5年度予算総則第14条で厚労省→国交省へ移替。
- GX関連1項：特別会計固有の会計間繰入。

## 結論
同名別所管173項は制度上の経路を全件分類できた。
重要なのは、決算の項集合には当年度予算だけでなく前年度予算の繰越項も含まれること。したがって当初・補正・決算の項件数は、単純な同一母集団の増減として比較してはいけない。

次は決算のみ254項の残り81項を分類する。
