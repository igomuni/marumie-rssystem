# 2024年度MOF項 一括計上元と決算受け皿ネットワーク

## 実施内容
当初一般会計CSVと決算一般会計CSVを項名で接続し、前段で抽出した29項名について、当初側の項と決算側の同名項を組織単位で比較した。

## 重要な結果
- 「情報通信技術調達等適正・効率化推進費」: 当初はデジタル庁1項 480,327,293,000円。決算では75項、歳出予算額合計685,739,597,000円。元のデジタル庁以外74項の合計は509,690,849,950円。全項で予算決定後移替増△減額は0円。したがって受け皿額を当初額からの直接移替と解釈できない。
- 「科学技術イノベーション創造推進費」: 当初は内閣府1項 55,500,000,000円。決算では16項、歳出予算額合計77,243,878,000円。元項には -4,958,761,000円の移替、受け手側に対応するプラスがあり、同名項全体の移替増減は0円。
- 同じ「当初1項→決算多組織」の形でも、決算CSV上の金額記録方式は異なる。

## 解釈
同名項ネットワークは「項数が増える構造」の説明には使えるが、金額フローの証明には使えない。件数分析と金額移動分析を分離する。

## 次段階
29項名について、前年度繰越額・予備費使用額・流用等増減額・予算決定後移替増減額・歳出予算現額を分解し、補正第1号との接続も行う。
