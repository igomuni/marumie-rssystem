# 2024年度MOF項 当初から支出までの金額変化分解

## 目的
前段で抽出した29項名について、当初予算、補正第1号、決算の年度中調整、予算現額、支出済額を接続する。

## 使用データ
- DL202411001b.csv: 一般会計 当初
- DL202421001b.csv: 一般会計 補正第1号
- DL202477001b.csv: 一般会計 決算

## 集計結果
- 対象: 29項名
- 補正第1号差引が非0: 16項名
- 前年度繰越が非0: 22項名
- 予備費使用が非0: 2項名
- 流用等増減が非0: 1項名
- 予算決定後移替が非0: 0項名

## 確認できた構造
決算CSVでは、項名単位の集計でも概ね「歳出予算額 + 前年度繰越 + 予備費使用 + 流用等増減 + 予算決定後移替増減 = 歳出予算現額」と、「歳出予算現額 = 支出済歳出額 + 翌年度繰越額 + 不用額」を検算できる。

重要な追加結果として、29項名すべてで、補正第1号の「改令和6年度予算額」の項名別合計と、決算の「歳出予算額」の項名別合計が完全一致した。したがって金額総額は補正第1号から決算へ連続している。一方、項数・配置は大きく変化しており、たとえば「情報通信技術調達等適正・効率化推進費」は補正第1号ではデジタル庁1項だが、決算では75項へ展開される。

## 次段階
補正第1号の1項が決算で多数の所管・組織へ展開される制度上の処理を、財務省一次資料で確認する。
