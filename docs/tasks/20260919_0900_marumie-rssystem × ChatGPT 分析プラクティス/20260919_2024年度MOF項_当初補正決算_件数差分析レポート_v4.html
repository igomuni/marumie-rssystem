新しく見えたこと

29項名では、補正第1号後の改予算額と決算の歳出予算額が全件一致した。
項名単位で合算すると29項名すべてで「補正第1号の改予算額 = 決算の歳出予算額」となった。つまり金額総額は補正第1号時点で決算側へ連続している一方、項の配置はその後、決算表示では多数の所管・組織へ展開している。決算CSV内部では 歳出予算額 + 前年度繰越 + 予備費使用 + 流用等 + 移替 = 歳出予算現額、さらに 予算現額 = 支出済 + 翌年度繰越 + 不用額 を検算できる。

重要な解釈

この29項名は「同名項が複数組織へ展開したもの」を選んでいるため、当初額と決算側の同名項合計をそのまま保存則のある資金フローとして扱わない。今回の価値は、どの列で年度中の変化が説明でき、どこに未説明差が残るかを切り分けた点にある。

次段階

次は、補正第1号では1項のままなのに決算で75項へ展開される過程を一次資料で確認する。焦点は「金額がいつ増えたか」ではなく、「確定した改予算額が、決算上どの制度・処理によって各所管・組織の項へ配置されるのか」である。特に「情報通信技術調達等適正・効率化推進費」を優先ケースとする。
