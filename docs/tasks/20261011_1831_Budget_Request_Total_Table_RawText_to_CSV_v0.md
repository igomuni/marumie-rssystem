## 想定外の観察

1. **同一の総表が別 source に重複して掲載されている**: env `000157012` ＝ meti `eneju_o`（40行）、env `000157013` ＝ meti `eneden_o`（30行）。`total-table.csv` には両方が入る。
2. **CODE3 が複数の階層に現れる**: env `000157010` では、字下げの異なる3桁コード行が入れ子になっている（例: p18 の `010 地域脱炭素推進体制強化費` と `010 …強化事務費`）。指示書のとおり CODE3 のまま出力した。
3. **数値トークン8個の行の曖昧さ**: 「7セル＋頁」と「名称末尾の ASCII 数字＋7セル（頁なし）」はテキストだけでは区別できない。名称中の ASCII 数字が0件で、検算の不一致も0件のため、FY2024 では実害はない。読み方はテストで固定した。
4. HIER 行（69件）にも明細書頁がある（例: `05 エネルギー対策 … 1`、`2 電源開発促進勘定 … 電 1`）。
5. 事前観測にない符号の表記揺れ（`▲`・全角数字の金額）や、ハイフンの異体字は0件だった。
