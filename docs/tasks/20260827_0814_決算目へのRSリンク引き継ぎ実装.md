# 決算目へのRSリンク引き継ぎ実装

`generate-mof-rs-kou-moku-linkage.ts` はこれまで当初予算・補正予算にしかRSリンクを付けられなかった
（決算目は0件）。RSの `2-2` CSVは項目別の決算・執行額を持たない（予算種別が当初/補正/繰越/予備費のみ）
ため、決算目を直接キー一致させることは原理的に不可能。そこで、決算目と予算側（当初・補正）の目が
共有する識別子（会計区分・所管・組織/特会・勘定・項コード・目分類コード・目名。予算種別を除く。
`/mof-kou-moku` の年度推移機能と同じ前提）を使い、予算側の既存RSリンクを決算目に引き継ぐ方式で実装した。

## 実装

- `types/mof-rs-kou-moku-linkage.ts`: `MofRsKouMokuLinkageRecord` に `carriedOverFrom?: MOFBudgetType` を追加（引き継ぎ元の予算種別。直接一致では undefined）
- `scripts/generate-mof-rs-kou-moku-linkage.ts`: 完全一致突合の後に「3.5 決算目への引き継ぎ」ステップを追加
  - 既存リンクを識別子でグルーピングし、同一pidが当初・補正の両方にリンクしていればrsAmountの大きい方を代表として採用
  - 決算目ごとに識別子が一致する代表リンクを探し、`mofBudgetType: '決算'`・`kouMokuAmount`は決算目自身の額・`rsAmount`は引き継ぎ元のまま・`carriedOverFrom`に引き継ぎ元の予算種別をセットして新規レコードを作成
- UI（`KouMokuTable.tsx`）: RS↗バッジのtitleと詳細パネルのRSリンク一覧に「〇〇から引継ぎ」の表示を追加。決算目の見出しは「完全一致」ではなく「予算側から引継ぎ」と表示

## 結果（予算年度2024）

```text
決算目: 8,213件中 11,259件（事業×目ペア）に予算側リンクを引き継ぎ
目カバレッジ: 8,559 / 11,177 目（引き継ぎ前は当初+補正のみの3,617目が対象範囲だった）
```

`rsAmount` は決算額に対する実際のRS計上額ではなく、当初/補正予算時点でのRS計上額をそのまま引き継いだ
推定値である点に注意（`carriedOverFrom` の有無で判別可能）。
