# Pipeline V2 download層 ファイル一覧と重複分析

`scripts/pipeline-v2/download-rs-csv.ts`・`download-rs-sheets.ts`・`download-mof-archive.ts` で取得した
`data/download/` 配下（gitignore対象、リポジトリには含まれない）の全611ファイルの内訳。

## サマリ（拡張子別）

| 分類 | 拡張子 | 件数 | 合計サイズ |
|---|---|---:|---:|
| RSレビューシート | .pdf | 246 | 130.2MB |
| MOF予算書・決算書 | .pdf | 34 | 73.0MB |
| RS CSVデータ | .zip | 30 | 51.8MB |
| RSレビューシート | .csv | 246 | 7.6MB |
| MOF予算書・決算書 | .xlsx | 15 | 4.7MB |
| MOF予算書・決算書 | .zip(csv) | 15 | 1.1MB |
| MOF予算書・決算書 | .html(frameset) | 25 | 24.9KB |
| **合計** | | **611** | **281.4MB** |

## 1. RS CSVデータ（`download-csv/{year}/*.zip`）— 重複なし

2024・2025年度各15グループ、計30ファイル。1グループ1形式（ZIP）のみで重複要素なし。

## 2. RSレビューシート（`sheets/{year}/{省庁}/*.{csv,pdf}`）— **完全重複あり**

2024年度122タイトル・2025年度124タイトル、**全タイトルがCSV+PDFの組で存在**（例外なし）。

- CSV: 246ファイル・7.6MB（機械可読、構造化データ）
- PDF: 246ファイル・130.2MB（同一内容の帳票を画像/レイアウト保持で出力したもの。テキスト抽出は非構造化で、パイプラインでの利用価値は低い）

**PDFはCSVと完全に同一データの別形式**であり、全体の重複容量の大半（130MB / 281MB）を占める。

## 3. MOF予算書・決算書（`archive/{year}/**`）— 一部重複、一部PDFのみ

帳票ID単位で見ると2パターンある。

**(a) csv・excel・dlpdf・htmlの4形式が揃う帳票（8件、両年度合計10件）**

一般会計・特別会計・政府関係機関の当初予算・補正予算・決算等、主要帳票。
`csv`（構造化データ）と`excel`は実質同一内容の別形式、`dlpdf`はさらにその人間可読版、
`html`は本文ではなく1KB程度のフレームセットの入れ物（実データは`menu.html`→XML、V1が別途キャッシュ済み。前回報告の通り今回は取得対象外）。

→ **dlpdf・excelはcsvと重複**。csv（構造化）のみ保持すれば足りる可能性が高い。

**(b) dlpdfのみ（html含む場合あり）の帳票（15件）**

決算参照・国税収納金整理資金・物品増減現在額報告・債権現在額報告・予備費使用総調書等。
これらは**公式サイトにCSV/Excel版が存在せず、PDFが唯一の入手経路**。重複ではないが、
Pipeline V2の当面のスコープ（MOF当初/補正/決算の金額サマリ）では優先度が低い可能性がある。

**(c) 2025年度: `2025_teishutsu/` と `2025/` に同一帳票ID（202511001・202512001）が重複**

前者は概算要求時点、後者は国会修正議決後の最終版。内容は異なる（提出時点と成立時点で金額が変わりうる）ため
厳密には重複ではないが、V2で使うのは基本的に成立版（`2025/`）のみで足りる。

## 追記（2026-09-19）: `data/download` をV1/V2で分離

整理のため、`data/download/` 配下のV1（既存パイプライン）が使っていたデータ一式
（`RS_{YEAR}/`・`mof_{YEAR}/`・`mof_archive/`・`digital_agency_budget_2024/`等28件）を
`data/download_old/` へ移動した。`data/download/` にはV2の新規取得分
（`mof.go.jp/`・`rssystem.go.jp/`）のみが残る。

**影響**: `npm run generate-mof-data`・`generate-mof-jikou`等、V1のCSV/XML生成コマンドは
`data/download/mof_{YEAR}/`を直接参照するため、移動後はこれらのコマンドが動かない。
元に戻すには `data/download_old/*` を `data/download/` へ戻す（`data/`はgitignore対象で
Git管理外のため、この移動はローカル状態のみに影響し、リポジトリ・他環境には影響しない）。

## 対応方針の提案

| 対象 | 提案 |
|---|---|
| RSレビューシートのPDF（246件・130MB） | 削除して再DL対象から外す（CSVのみ保持） |
| MOF (a)のdlpdf・excel（両年度合計約77MB） | 削除してcsvのみ保持を検討 |
| MOF (b)のPDFのみ帳票（15件） | 当面保持（他に入手経路がない）。V2スコープで使わないなら後回しでも可 |
| MOF `2025_teishutsu/`（提出時点版） | 保持要否は要判断（差分把握に使うなら残す、使わないなら削除） |

いずれもダウンロード科目のダウンロードスクリプト側でフォーマットを絞り込む対応が可能（RSシートはbutton textが`CSV`/`PDF`で判別済み、MOFはリンクのkind別に判別可能）。
