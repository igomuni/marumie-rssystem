# 複数年度にわたる予算をどう判別するか

結論: **判別できる。ただし「複数年度」には制度上4つの別物があり、置き場も粒度も違う。**

| 仕組み | 帳票 | 粒度 | 年度範囲の明示 | 規模（令和8年度） |
|---|---|---|---|---|
| 継続費（財政法14条の2） | 乙号 継続費 | 項 | **総額＋年度別の年割額** | 10件 / 1.57兆円 |
| 国庫債務負担行為 | 丁号 | 独自の「事項」 | **「国庫の負担となる年度」欄** | 596件 / 限度額10.53兆円 |
| 繰越明許費 | 丙号 ＋ 決算 | 項 / 事項 | 翌年度への繰越のみ | 決算の `carriedOver` |
| 事項が年度をまたいで継続 | 事項別内訳 | 事項 | 合成キーの一致で判定 | 4年度連続 1,335事項 |

---

## 1. 継続費（乙号）— 唯一「年割額」が公表されている

`202611001000087a.xml`（`title_for_list` = `継続費`）。列構成:

```text
所管 / 組織 / 項 / 総額(千円) / 年割額（令和4年度・5年度・…・9年度） / 事由
```

総額と年割額はいずれも `既定` と `改定` の2値を持つ（前年度計上時の計画と今回の改定後）。

令和8年度は**10件・総額1.57兆円で全て防衛省の艦船建造**（潜水艦・甲Ⅴ型/甲Ⅵ型警備艦）。
継続費は制度としては存在するが、実際の適用はこの範囲に限られている。

### 1-1. 事項一覧の中でも判別できる

継続費の項は**項名に年度が入る**（「令和6年度潜水艦建造費」）。事項名も同じ形になる。

```text
項名が /^令和\d+年度/ にマッチする事項: 12件（令和8年度・当初予算）
  防衛省/防衛本省 項=令和4年度甲Ⅴ型警備艦建造費 事項=令和4年度甲Ⅴ型警備艦建造に必要な経費 164.6億
  防衛省/防衛本省 項=令和6年度潜水艦建造費       事項=令和6年度潜水艦建造に必要な経費       282.9億
```

つまり `mof-jikou-{YEAR}.json` だけで継続費を抽出できる。
**その年度の額は年割額**であって総額ではない点に注意（総額は乙号でしか取れない）。

## 2. 国庫債務負担行為（丁号）— 年度範囲が文章で明示される

`202611001000125a.xml`（`title_for_list` = `国庫債務負担行為`）。列構成:

```text
所管 / 組織 / 事項 / 限度額(千円) / 行為年度 / 国庫の負担となる年度 / 事由
```

令和8年度で **596件・限度額10.53兆円**。継続費よりずっと大きい。
「国庫の負担となる年度」は定型の文字列で、そのまま年数に読み替えられる。

```text
182件  令和8年度以降5箇年度以内
150件  令和8年度及び令和9年度
 96件  令和8年度以降3箇年度以内
 47件  令和8年度以降4箇年度以内
 27件  令和9年度
 15件  令和8年度以降6箇年度以内 / 15件 令和8年度以降7箇年度以内
 13件  令和13年度以降10箇年度以内
```

### 2-1. ただし事項別内訳とは結合できない

丁号の「事項」は**契約・行為の名前**で、事項別内訳の「事項」（経費のまとまり）とは別語彙。

```text
丁号        : 皇室費//皇室施設公開業務、国会/衆議院/電子計算機等借入れ
事項別内訳  : 皇室費/皇室費/宮廷に必要な経費
```

596件を `所管+組織+事項名` および `事項名` で突合したが、**一致は0件**。
共通するのは所管・組織までで、事項単位の紐づけはできない。丁号は独立した台帳として扱うしかない。

## 3. 繰越（丙号・決算）— 事項単位で取れる

決算の歳出決算報告書に `翌年度繰越額` があり、事項一覧では `carriedOver` に入っている。
繰越が発生した事項＝その年度で完了しなかったもの、として抽出できる。
ただしこれは「複数年度の計画」ではなく「単年度予算の未執行分の持ち越し」で、性質が違う。

## 4. 同じ事項が年度をまたいで存在するか（実測）

合成キー `key`（会計区分・予算種別・所管・組織・特会・勘定・機関・項コード・事項名）で
2023〜2026の当初予算を突合した。

```text
2023 当初 1,698事項 / 2024 1,664 / 2025 1,700 / 2026 1,712

4年度すべてに出現  1,335事項（2026の78.0%）
3年度              245
2年度              191
1年度のみ          317
```

**約8割の事項は4年度連続で存在する**。制度上の継続費でなくとも、事項という単位は年度をまたいで安定している。
これは事項を軸に経年比較できるということでもある。

2026で新規に現れた事項（2025に無いもの）は240件。上位は組織再編・新規施策:

```text
0.39兆  エネルギー対策特別会計 / 脱炭素成長型経済構造移行推進に係るNEDO…
0.36兆  農林水産本省 / 国内食料供給対策に必要な経費
0.27兆  農林水産本省 / 食料自給力確保対策に必要な経費
```

ただし**事項名の改称と新規計上は区別できない**。上の農林水産省の例は食料・農業・農村基本法の改正に伴う組替えで、
実態としては継続だが名前が変わったために「新規」に見える。名寄せには意味的な照合が要る。

## 5. 行政事業レビュー側

`1-2_基本情報_事業概要等` に `事業開始年度` / `事業終了（予定）年度` / `終了予定なし` がある。

```text
2025年度 6,061事業
  事業開始年度あり     5,948
  終了予定年度あり     1,848
  終了予定なし         4,725
```

事業単位では終期が明示されているが、これは MOF の継続費・国庫債務負担行為とは別の概念
（事業としての存続期間であって、複数年度契約の有無ではない）。

## 6. 使い分け

- **「複数年度にわたる契約・支出の約束」を知りたい** → 丁号国庫債務負担行為。件数・金額とも最大で、
  年度範囲が明示される。ただし事項別内訳とは紐づかない
- **「年割額まで確定した長期計画」を知りたい** → 乙号継続費。ただし防衛省の艦船建造10件のみ
- **「事項が経年で続いているか」を知りたい** → 事項一覧の合成キーで足りる（4年度連続78%）
- **「使い切れずに翌年度へ回ったか」を知りたい** → 決算の `carriedOver`

## 7. 取り込むとしたら

丁号は596件と小さく、`所管 / 組織 / 事項 / 限度額 / 行為年度 / 国庫の負担となる年度 / 事由` が
そのまま表になるので、独立したデータセットとして持つのが素直。
事項別内訳に混ぜると粒度も語彙も違うものが同居して誤読を招く。
