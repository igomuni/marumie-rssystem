# 事項要求の出現と、MOF と対応しない項・要求額 0 の項の調査票

状態: 調査（FY2023〜2027 の明細表の plain text と、MOF 突合・年度推移の fixture を照合）。結論:

- 「事項要求」は年度ごとに 73〜149 件あり、ほぼすべて明細表の備考の列に出る。
- 4 年度続けて MOF と対応しない 23 項のうち 22 項は、前年度・要求とも 0 の「空の項」だった。
- 要求額 0 で当初予算に額がある項は、事項要求の印より、勘定ごと 0 で要求する形と、一括計上の推進費が多い。

## 1. 「事項要求」の出現

`data/work/budget-request-plain-text/{year}/*.txt` を全文検索した（空白を除いて「事項要求」）。出現した位置は、明細表 CSV（`tests/fixtures/budget-request-csv/{year}/detail-table/sources/`）の `source_line_start` と照合し、同じ頁で直前にある行に結びつけた。

| 年度 | 件数 | 印（括弧付き） | 文中 |
|---|---:|---:|---:|
| FY2023 | 149 | 114 | 35 |
| FY2024 | 113 | 87 | 26 |
| FY2025 | 96 | 71 | 25 |
| FY2026 | 82 | 65 | 17 |
| FY2027 | 73 | 54 | 19 |

- **印:** 「（事項要求）」の形のもの。金額のすぐ右か、その下の行の先頭にある。
- **文中:** 例は「…財源の確保については、事項要求とする」「(注3) 下記について、事項要求を行う」。

**出現した場所**

- **ほぼすべてが明細表の備考の列。** 境（表頭の「前年度」の桁）より右にある。
  - 左側と判定されたのは 17 件あった。うち 16 件は、境が取れなかった頁（内閣府・内閣官房の分冊の先頭の頁など）で、桁の位置で見ると備考の列だった。
- **明細表以外は 7 件。**
  - 農林水産省の説明の頁が 6 件（FY2023〜2025。「…体制整備について事項要求。」）。
  - 法務省 FY2027 が 1 件（「以下の事項要求がある。」）。

**付いている行の階層**（5 年度の合計 513 件）

| 階層 | 件数 |
|---|---:|
| 組織または項（CODE3） | 282 |
| 事項（要求番号の行） | 98 |
| 目 | 65 |
| 特別会計・勘定 | 21 |
| 明細表 CSV の行に結びつかない | 47 |

- 組織の行に付く例: 文化庁、海上保安庁、地方防衛局。
- 結びつかない 47 件の多くは、公正取引委員会の FY2023 のように、事項名に「(事項要求)」が付いた備考の内訳表。

**金額との関係**

項の範囲（その項の行から次の項の行まで）に印か文がある項は、年度ごとに 12〜24 項あった。FY2023〜2026 の MOF 突合と比べると、そのうち半分〜3 分の 2 で、当初予算が要求額を上回る（MATCHED 全体では 35〜41%）。

**備考を取り込まずに拾える。** 印はほぼ「（事項要求）」の固定形で出るので、行の範囲に結びつけるだけで拾える。

- 原文で確かめた例: 国土交通省 FY2026 の治水事業調査諸費。明細表の 426 頁で、目（職員旅費）まで 0 が並ぶ。

**残る 1 項: 国際観光旅客税財源観光振興推進費（観光庁）**

| | 前年度 | 要求 |
|---|---:|---:|

| 観光振興費 | 前年度の額（FY2026 は 366 億） | 0 |

- 編成の段階で、観光振興費や国際観光振興機構運営費の項に配分される。
- MOF には推進費の項がないので、要求側の推進費が未対応になる。逆に、要求額 0 の観光振興費が MOF の額のある項と対応する。5 年度とも同じ形。

**事項要求の印だけでは拾えない。** 金額を示さずに要求する形には、次の 3 つがある。

- 推進費に一括するもの

## 4. 調査票 C: 突合の取り違え

次の 2 項は、要求書に同じ名前の項が 2 つある。片方は空の項（0/0）で、もう片方は額のある項。空の項の行も MOF の項と MATCHED になっている。

- 厚生労働調査研究等推進費（FY2026: 額のある行は前年度 599 億 → 要求 608 億）
- 地方創生基盤整備事業推進費（FY2026: 額のある行は 598 億 → 598 億）

空の項は、名前が同じだと候補に入ってしまう。

## 5. ここから言えることと次の手

- **未対応の理由の分類に「空の項」を足す。** 4 年度続けて残る未対応の最大の要因で、制度上の違いでも抽出の失敗でもない。
- **MOF 突合: 空の項（前年度・要求とも 0）を候補から外すか、同じ名前で額のある行を優先する。** 調査票 C の取り違えが消える。「概算要求のみ」から空の項を別に数えれば、残りの未対応の実態が見える。
- **年度推移 UI: 空の項に印を付けるか、既定で隠す。** 5 年度とも 0/0 の項は、推移として意味がない。
- **事項要求の検知: 次の 3 つを合わせて拾う。**
  - 備考の印・文（行の範囲に結びつける）
  - 前年度に額があり要求額が 0 の項（勘定ごとの 0 を含む）
  - 一括計上の推進費（目が括弧書きの一つだけの項）
- **推進費と配分先の項の対応づけ。** 国際観光旅客税は毎年同じ形なので、推進費と配分先の項を一つの出来事として扱える。
