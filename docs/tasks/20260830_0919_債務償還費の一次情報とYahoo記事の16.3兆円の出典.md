# 「債務償還費」の一次情報と、Yahoo記事「約16.3兆円」の出典確認

## 「債務償還費」の内訳を見られる一次情報（財務省 予算書・決算書データベース）

「債務償還費」には2つの階層がある（別物として計上されている）:

1. **一般会計側**（毎年度、国が特別会計へ繰り入れる分。60年償還ルールに基づく定率繰入が中心）
   項「国債費」の下の事項別内訳。令和5年度（2023）当初予算の例:
   `https://www.bb.mof.go.jp/server/2023/xml/202311001000556a.xml`（p.557）
   事項名「定率による公債等償還財源の国債整理基金特別会計へ繰入れに必要な経費」＝**15兆8,629億2,868万円**

2. **特別会計側**（国債整理基金特別会計が実際に償還を行う総額。借換債による借換分も含むため一般会計側よりずっと大きい）
   項「国債整理支出」の下の目別内訳。同年度の目「債務償還費」は224.7兆円規模（借換込みの総額のため）。

`/mof-kou`（本アプリ）でも「所管: 財務省」「項名: 国債費」または「国債整理支出」で絞り込めば、年度ごとの事項・目とその出典XMLへ直接リンクできる。

## Yahoo記事「2023年度予算案（当初）では、債務償還費として、約16.3兆円が計上されている」の出典

記事本文を確認したが、**この数字に対する具体的な資料名・URL・脚注は記事中に無い**。前後の文脈:

> 「厳密には、法律に基づき、国債発行残高の1.6%に相当する金額を、債務償還費として国の予算（一般会計）に計上し、後述の「国債整理基金特別会計」に繰り入れた上で返済を行っている」
> 「例えば、2023年度予算案（当初）では、債務償還費として、約16.3兆円が計上されている」

著者は「1.6%（60年償還ルール）× 国債残高」から概算しており、直接のリンク・引用は提示していない。

予算書データベースの実際の対応値（上記1.の事項）は**約15.86兆円**で、記事の「約16.3兆円」とは0.4兆円ほど差がある。この差は、記事執筆時点（令和5年度予算の**政府案・概算要求ないし閣議決定段階**の見込み額）と、国会議決後に確定し予算書データベースに載る最終額との間の通常のズレ、または1.6%算定のベースとなる前年度末国債残高の推計値の違いによるものと考えられる（記事側で確認は取れないため推測の域）。

**結論**: 記事の16.3兆円に対応する一次情報を記事自体からは特定できない。予算書データベース上で最も近い正式な数字は「定率による公債等償還財源の国債整理基金特別会計へ繰入れに必要な経費」＝約15.86兆円（令和5年度当初予算、確定値）。
