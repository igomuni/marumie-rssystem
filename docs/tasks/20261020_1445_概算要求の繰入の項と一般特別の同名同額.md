# 概算要求の繰入の項と、一般・特別の同名同額の項

状態: 調査（FY2026・FY2027 の歳出概算要求書の明細表）。繰入は「目名に『繰入』を含む行」で洗い出した。会計をまたいで合計すると二重になる項の候補。

## 繰入の項（目名に「繰入」を含む）

- FY2026: 繰入の目 192 行（項 × 繰入先で 147 件）。一般会計の所管と特別会計の両方にある。繰入の要求額は一般会計の所管の分が約 68.4 兆円、特別会計の分が約 100.2 兆円（目の合計。項の計ではない）。
- FY2027: 繰入の目 129 行（102 件）。厚労省の歳出概算要求書が corpus に無いため、FY2026 より少ない。
- 繰入先は、国債整理基金特別会計（財務省・総務省・各特会から）、年金特別会計の基礎年金勘定、子ども・子育て支援特別会計、交付税及び譲与税配付金特別会計、エネルギー対策特別会計、労働保険特別会計の各勘定（労災・雇用）、財政融資資金など。
- 繰入の「受け側」は歳入なので、歳出概算要求書には載らない。送り側（一般会計の項、または別の特別会計の項）だけが載る。

下の表は、項の下の目のうち名前に「繰入」を含む行を、会計・所管、項、繰入先ごとに合計した。「繰入の要求額」は、その繰入先への目の合計。「項の要求額」は項全体（繰入以外の目を含む）。

## 一般会計と特別会計で、同じ項名の項

年度ごとに、同じ項名が一般会計と特別会計の両方にあるものを調べた（FY2026 に 22 項、FY2027 に 11 項）。

- **同名・同額（会計をまたいだ二重の可能性）は、地方特例交付金だけ**（FY2024〜FY2027）。一般会計は総務省・総務本省の項100で、事項が「地方特例交付金財源の交付税及び譲与税配付金特別会計へ繰入れに必要な経費」。特別会計は交付税及び譲与税配付金の項020で、同額。一般会計側が繰入、特会側が地方公共団体への交付と考えられる（特会側の目は未確認）。FY2023 は特別会計側の行が無い（未調査）。
- **同名・金額が近い**: 地方交付税交付金（総務省 FY2026 要求 18.46 兆円、交付税特会側 19.34 兆円）。額は一致しない。復興特会にも同名の項がある。
- **同名・金額が違う（別の資金で払う、もしくは分担）**: 日本原子力研究開発機構運営費、新エネルギー・産業技術総合開発機構運営費、エネルギー・金属鉱物資源機構運営費、産業技術総合研究所運営費（以上、文科省・経産省の一般会計とエネルギー対策特会）、労働保険特会と厚労省一般会計の雇用関係の費用（高齢者等雇用安定・促進費、職業能力開発強化費、男女均等雇用対策費ほか）、自動車安全特会と国交省の運営費、特定国有財産整備費（財務省と財政投融資特会）。二重ではなく、別の財源の支出。
- **名称に繰入を含む同名**: 児童手当等子ども・子育て支援特別会計へ繰入（内閣府の一般会計 約 2.6 兆円と、年金特会 7,220 億円）、育児休業給付費等子ども・子育て支援特別会計へ繰入（厚労省の一般会計 1,114 億円と、労働保険特会 8,807 億円）、職務上年金給付費年金特別会計へ繰入（厚労省 93 千円と、労働保険特会）。同名だが送り元が別で、金額も違う。
- 予備費は同名でも別の予備費。

結論: 会計をまたぐ同名同額で、完全に二重になるのは地方特例交付金のみ。ただし繰入の項は、送り側の項が一般会計の所管と特別会計にまたがる形で金額が重なる（例: 一般会計の国債費の繰入と、国債整理基金特別会計の歳出）。会計をまたぐ合計では、繰入の項を除くか、印を付けるのが安全。
