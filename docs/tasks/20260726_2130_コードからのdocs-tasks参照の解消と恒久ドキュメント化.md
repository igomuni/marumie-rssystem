# コードからの docs/tasks 参照の解消と恒久ドキュメント化

## 目的

コードや公開ドキュメントが `docs/tasks/*.md`（作業ログ）を「設計の正典」として参照しているが、
task doc は rs-vis へ展開されないため、展開先ではリンクが切れる。また archive 移動のたびに
パスが壊れる。**恒久情報は `docs/*.md` のガイドに置き、コードはそちらを指す**形に直す。

（前提: [20260726_2120_docs-tasks整理_archive移動候補の洗い出し.md](20260726_2120_docs-tasks整理_archive移動候補の洗い出し.md) で
「コードから参照されている11本は archive できない」と整理した件の根本対処）

## 現状: 問題はすでに顕在化している

実測で確認した事実。

1. **rs-vis 側に task doc はほぼ存在しない** — `rs-vis/docs/tasks/` は
   `20260616_1749_AI支出先データ品質スコアリング再設計.md` の **1本だけ**（marumie 側は直下78本 + archive 約200本）
2. **rs-vis で既に2件リンク切れ** — `rs-vis/docs/rs-data-scope.md:192-193` が
   `tasks/20260201_1400_...`・`tasks/20260202_0000_...` を指しているが、rs-vis に該当ファイルは無い
3. **marumie 自身でも同じ2件が切れている** — 参照先は `docs/tasks/archive/` へ移動済みで、
   `docs/rs-data-scope.md:192-193` のリンクパスが更新されていない
4. **AI チャット・highlights 系はまだ rs-vis 未展開** — `app/lib/highlights.ts`、`app/lib/ai/*`、
   `client/lib/ai/*`、`client/components/SankeySvg/AiChatPanel.tsx` は rs-vis に存在しない。
   つまり**次の rs-vis 反映で 6 件のリンク切れが新規発生する**

## 方針

```text
恒久的な仕様・制約・設計判断 → docs/*.md（ガイド）に置く。コード・公開ドキュメントはここだけを参照する
一過性の検討過程・実験・経緯     → docs/tasks/*.md に残す。参照してよいのは .claude/ 配下と他の task doc のみ
```

`.claude/commands/*.md` は rs-vis へ展開されない内部設定なので、task doc を参照してよい（現状維持）。
