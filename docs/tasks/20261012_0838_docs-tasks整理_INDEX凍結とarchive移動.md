# docs/tasks 整理: INDEX 凍結と archive 移動（2026-10-12）

状態: 実施済み。`INDEX.md` の更新を停止し、2026-09-12 以前の task doc のうち107本を `archive/` へ移した。`archive/` は `.ignore` で検索対象から外した（GitHub には残る）。

## 1. INDEX.md の更新停止

- **理由:** 並行ブランチが毎回 `INDEX.md` の先頭に1行足すため、ほぼ確実にコンフリクトする（#424 でも発生）。
- **ルールの変更:**
  - `.claude/CLAUDE.md`: task doc 作成時の INDEX 追記をやめた。代わりに、タイトル直後に1〜2行の要約（状態・結論）を書く。探すときは `ls docs/tasks | rg <語>` で絞り、冒頭の要約だけを読む。
  - `.claude/commands/pr.md` 手順7: INDEX の同期をやめ、新規 task doc に要約行があるかの確認に置き換えた。
  - `.claude/commands/plan.md`・`review.md`: INDEX への誘導を `ls | rg` に置き換えた。
  - `.gitignore` のコメントから INDEX への言及を消した。
- `INDEX.md` は凍結した。冒頭に注記を書いたうえで残す。凍結時点までの文書の当たり付けには引き続き使える。索引の整備が必要になったときは、独立したタスクとして行う。

## 2. archive の検索除外

- 圧縮（zip / tar.gz）は採らなかった。
  - git は内部で圧縮済みで、履歴にも元の md が残る。そのため、リポジトリの容量はほぼ減らない（2.9MB → 0.9MB。pack 全体 561MB の0.3%）。
  - 圧縮すると GitHub 上で読めず、diff も取れない。他の文書から archive へのリンクも切れる。
- 代わりに、リポジトリ直下の `.ignore` に `/docs/tasks/archive/` を書いた。`.ignore` は ripgrep などの検索ツールだけが読み、git の追跡には影響しない。
- **確認結果:**
  - `rg` で `docs/tasks` を検索すると、archive に当たらない（`rg --files` で archive 0件）。
  - `rg … docs/tasks/archive` とパスを直接指定すれば、archive も検索できる。
  - `git check-ignore` では、archive は追跡されたまま。
- **未確認:** Claude Code の専用 Grep/Glob ツールが `.ignore` を尊重するか。今回の環境には専用ツールが無かった。
