# デジタル庁の概算要求・予算決定資料から見る予算プロセスと項の内訳表現

[『情報通信技術調達等適正・効率化推進費』のあるべき姿](20260906_2221_情報通信技術調達等適正効率化推進費のあるべき姿.md)の続き。同項の透明性の低さ（決算で74組織に同名目「情報処理業務庁費」として計上、RSは親事業に予算を丸める）について、MOF・デジタル庁自身が公表している令和6年度の概算要求〜予算決定〜各目明細書〜政策対応表を実際に取得し、この項がどう説明されているかを確認した。

## 取得資料

## 概算要求→予算決定→当初予算の金額推移

「情報システムの整備・運用に関する経費」（＝項『情報通信技術調達等適正・効率化推進費』とほぼ同義。デジタル庁の分類上の呼称）の総額を時系列で追うと:

| 段階 | 時期 | 金額 |
|---|---|---|
| 令和5年度当初予算（参考） | - | 4,811.9億円 |
| **概算要求額**（要望込み） | 令和5年8月31日 | **5,670.4億円**（うち要望額1,187.7億円） |
| 令和5年度補正追加額（参考） | - | 1,631.8億円 |
| **予算決定額（＝当初予算額）** | 令和5年12月 | **4,803.3億円** |

概算要求から予算決定までに約867億円（15.3%）圧縮されている。予算決定額4,803.3億円（480,327,293千円）は、MOF科目別内訳CSVの`医療保険給付諸費`調査で使った手法と同じ突合で確認済みの当初予算額（`sectionCode: "003"`、7目合計480,327,293,000円）と**完全に一致**する。

## 各目明細書（03）: 目「情報処理業務庁費」はコスト種別に分解されている

MOF科目別内訳CSVでは`情報処理業務庁費 453,911,195千円`の1行だが、各目明細書（各目ごとの積算内訳を記す公式帳票）を見ると、この1目は複合コード`95016-2123-09`の下で以下のコスト種別に分解されている:

| 費目 | 金額（千円） |
|---|---|
| 備品費 | 1,078,404 |
| 消耗品費 | 3,606,503 |
| 印刷製本費 | 38,462 |
| 通信運搬費 | 5,641,398 |
| 光熱水料（電気・水道・ガス） | 424,556 |
| **借料及び損料** | **155,409,059** |
| 賃金 | 46,171 |
| 保険料 | 378 |
| 子ども・子育て拠出金 | 14 |
| **雑役務費** | **287,651,533** |
| 燃料費 | 435 |
| その他 | 16,189 |
| **合計** | **453,911,195** |

さらに以下の内訳も明記されている:

- **繰越明許費のうち**「政府情報システム整備費」124,293,595千円
- **国庫債務負担行為の歳出化**（複数年契約の当年度執行分）296,707,031千円、令和2〜6年度の5か年度分がそれぞれ内訳付きで記載（例: 令和6年度国庫債務負担行為65,581,223千円）

**つまり「情報処理業務庁費」はコスト種別（賃金・備品・借料・雑役務費等）へは分解されているが、システム・事業単位へは分解されていない。** 雑役務費2,876億円・借料及び損料1,554億円という2大費目が合計で全体の94.9%を占めるが、これがどのシステムの委託費・クラウド利用料なのかは各目明細書からも読み取れない。

## 政策対応表（04）: 政策体系との対応も項単位止まり

「政策ごとの予算との対応について」は、政策評価の政策体系（施策の分類）と予算科目（項）を対応付ける公式資料。デジタル庁の令和6年度分を見ると:

```text
政策体系「情報通信技術等の適正・効率化に関する施策の推進」
  └ 事項「情報システムの整備」
      └ 組織: デジタル庁 / 項: 情報通信技術調達等適正・効率化推進費
          / 事項: 情報通信技術調達等適正・効率化の推進に必要な経費
          → 480,327,293千円（100%がこの1項に対応）
```

デジタル庁の政策評価では、この巨大な項に対応する政策体系が実質1つしかなく（`<1,033,584>の内数`という他の小さい政策体系はデジタル社会形成推進費側の話で、情報システム整備費側には対応する内訳が無い）、**政策評価の枠組み自体がこの項を1本のまま扱っている**。RSの行政事業レビューのような「事業単位」の管理とは別に、政策評価上もこれ以上の分解が存在しない。

## 予算決定資料（02）の説明文: システム名は列挙されるが金額は無い

予算決定の説明文には「マイナポータルの利便性向上・利用拡大のためのオンライン申請機能」「マイナンバーカード機能のスマートフォンへの搭載」「国家資格等のオンライン・デジタル化」「情報連携基盤（公共サービスメッシュ）」「ガバメントソリューションサービス」「ガバメントクラウド」等、具体的なシステム名が列挙されている。**しかしこれらは説明のための例示であり、個々のシステムへの金額配分は一切示されていない。**

## 結論: 「あるべき姿」の答え合わせ

前回のレポートで「MOFの決算CSV・RSのどちらでも内訳が追えない」と指摘したが、今回、MOF・デジタル庁自身が公表する概算要求〜予算決定〜各目明細書〜政策対応表という一連の公式資料を確認した結果、**行政のどの公式資料を見てもシステム単位の金額内訳は存在しない**ことが裏付けられた。

- 概算要求・予算決定の説明文: 政策的なトピック単位の説明のみ、金額は項全体
- 各目明細書: コスト種別（賃金・備品・借料・委託費相当の雑役務費等）への分解のみ。システム単位ではない
- 政策対応表: 政策体系との対応も項単位止まり
- 決算CSV: 74組織への配分は分かるが目名は「情報処理業務庁費」のまま（前回レポート）
- RS（行政事業レビュー）: 240事業に分解されているが、親事業に予算が丸められ子事業は予算0円（前回レポート）

**システム単位の金額を知る手段は、事実上RSの5-1「支出先の支出情報」（契約単位の支出額）しかない。** それも前回確認した通り、親事業側に紐づく形なので、どの子事業（システム）にいくら支出されたかを完全に復元できるわけではない。デジタル庁の予算の透明性向上には、RS側で子事業に移替後の予算額を記録する（前回提案）ことに加え、**各目明細書レベルで「雑役務費」「借料及び損料」の内訳をシステム単位に分ける**ことが、公式資料の側からできる改善案として追加できる。
