# 概算要求 年度推移 CSV（項, FY2023〜FY2027）の試作

状態: 試作済み。5 年度 5,511 行の CSV を出した。仕様は `docs/budget-request-trend-csv.md`。

## 決めたこと（ユーザーとの対話）

- 目的は現時点の年度推移。MOF 突合は参考情報。FY2027 も載せる。
- キーは `会計・勘定 + 所管 + 組織 + 名称`（コードは組織内の連番でキーにならない: FY2026 の 1,181 行で項コードは 319 種類）。名称変更の紐づけは別のロジック。
- 所管は表紙の見出し（コード付き）から取る。前年度金額も列に持つ（初版で落としていたので足した）。
- 特別会計の共管は按分しない（按分の根拠は概算要求本体や各所管の資料にある可能性。今回は扱わない）。

## 結果

- 重複キーの主因は、共管の特別会計の項が複数府省の要求書に載ること（額は同じ。FY2026 71 件中 66 件）。
- 組織が空の行は、総表の「CODE3 の次も CODE3」の行を組織見出しとして補い、各年度 70〜116 行 → FY2023 の 1 行だけに減った。
- `2025_teishutsu` の突合 fixture は、今回触れていない（#516 のパーサ変更が未反映で、再生成すると m3-moku 等が変わる。別件）。
