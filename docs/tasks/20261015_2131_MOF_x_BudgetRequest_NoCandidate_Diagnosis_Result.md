- **`variant_in_scope`（22 件）は、すべて全角／半角の違いだけ**（NFKC だけで一致する）。例: `令和２年度潜水艦建造費`（概算要求）と `令和2年度潜水艦建造費`（MOF）。防衛省の国庫債務負担の項が中心。契約は正規化を禁じているので、突合では一致にしていない。
- **`exact_elsewhere`（5 件）:** 同じ名称が MOF の別の範囲にある。例: `施設整備費`（概算要求は年金・業務勘定、MOF は労働保険の勘定など）、`科学技術イノベーション創造推進費`（概算要求は厚生労働本省、MOF は内閣府）。同じ名称でも所属が違う別の項。
- **`prefix_in_scope`（M1 は 1〜2、M2 は FY2024 のみ 3）:** 例: `会計検査院施設費`（概算要求）と `会計検査院`（MOF）。
- **`absent`:** 概算要求にあって、MOF の同じ範囲には名称がない。例: 子ども・子育て支援特別会計の新しい給付（`妊婦のための支援給付の支給に必要な経費`）、厚生労働本省の `補充費（義務）` など。概算要求の項目が予算案で統合・改称・新設されたもの、または MOF の側が別の構成のものと考えられるが、原因は項目ごとに確かめていない。
- 概算要求は予算案の前の資料のため、名称が予算に残らないことがある。`absent` を直ちに誤りとは見ない。

## 判断が要ること
全角／半角の違い（22 件）を一致として扱うかどうか。扱う場合は、契約の「正規化をしない」の例外（全角→半角のみの NFKC）として、追補で事前登録してから再実行する。
