# MOF 特別会計 歳出事項別内訳 — 行の文法の事前登録

状態: **確定（ユーザーが §3 の 3 点を案どおりと確定）**。この commit を事前登録とし、その後に実装する。実装・実行の前に、結果を見て文法を変えない。根拠は #474（行の種類の実例）と、項の開始行の差の確認（項は公式 CSV と 250 / 254 / 254 で一致）。

## 1. 範囲
- 対象: `歳出事項別内訳` のファイル（FY2024 32、FY2025 成立後・提出時 各 34。FY2025 のうち食糧管理勘定の `337a` は説明欄に入れ子の表がある）。帳票は `202412001`（FY2024）、`202512001`（FY2025 成立後・提出時）。
- 読み方は、一般会計の parser v0 と同じ作法（XML を木として読む。想定外は例外、silent skip なし）。**説明欄（`11.1`）は読まない**（出力に含めない。入れ子の表は無視する）。説明欄の「空でない」確認だけ行う（入れ子の表のセルは確認の対象外）。
- 所管・特別会計・勘定は、目次（menu）の祖先 chain から取る。chain は `[…, {所管名}所管, {特別会計}, 甲号歳入歳出予定計算書, ({勘定}), 歳出 事項別内訳]`。`甲号歳入歳出予定計算書` の位置を i として、所管＝chain[i-2]（末尾の `所管` を除く）、特別会計＝chain[i-1]、勘定＝chain[i+1]（それが末尾の `歳出 事項別内訳` ならば空欄）。末尾が `歳出 事項別内訳` でない、`甲号歳入歳出予定計算書` が無い・複数ある場合は STOP。

## 2. 受理する行の種類（列の開始番号 `n.m` の集合。`m` は列の位置の変種）
列の集合を、番号の組で完全一致させる。`3.1` と `3.2`、`1.1` と `1.4` は同じ意味の列の位置の変種として受け、受けた変種は source として残す（出力列 `source_row` で追える）。

| 行の種類 | 列の集合 | 意味（案） |
|---|---|---|
| 項の開始行 | `{1.1\|1.4, 2.1, 3.1\|3.2, 4.1, 5.1, 7.1, 9.1, 11.1}` | 項コード・項名・分類コード・事項名・予定額・前年度予算額・比較増△減額・説明 |
| 事項の続き行 | `{3.1\|3.2, 4.1, 5.1, 7.1, 9.1, 11.1}` | 直前の項の続き |
| 説明の続き行 | `{11.1}` | 数える（出力しない） |
| 所管の行 | `{1.1}`（値が府省名、復興庁のファイルだけ） | 以降の組織の所管 |
| 組織の行 | `{1.3}` または `{1.3, 5.1, 7.1, 9.1}` | 以降の項の組織。金額つきは組織計（数える。出力しない） |
| 入れ子の表の行 | 説明欄（`11.1`）の中にあり、データ行として数えない | 無視 |

- 上記以外の列の集合は、例外（`unknown_row`）で止める。
- 分類コードは 2 桁の数字（一般会計の `col4` と同じ検査）。項コードは 2 桁の数字。
- 金額は一般会計と同じ文法（千円のまま、`△` は比較増△減額のみ、空欄を 0 にしない）。

## 3. 確定した 3 点（ユーザー、案どおり）
1. **入れ子の表（食糧管理勘定の説明欄）:** 無視して他の列を読む。
2. **復興庁のファイル（所管・組織の行、列位置の変種）:** 受理して出力に `組織` を入れる（特別会計の他のファイルでは空欄）。
3. **前年度の列がない新勘定（FY2025 `170a`、`{1.1, 2.1, 3.1, 4.1, 5.1, 7.1}`、見出し `…令和7年度・説明`）:** 受理して前年度・比較増△減額を**空欄**にする（0 にしない。`7.1` は説明なので読まない）。

## 4. 出力（`jikou-special.csv`、列は固定）
`所管, 特別会計, 勘定, 組織, 項コード, 項名, 事項名, 分類コード, 令和N年度予定額(千円), 前年度予算額(千円), 比較増△減額(千円), source_file, source_row, source_page`。説明欄は含めない。
