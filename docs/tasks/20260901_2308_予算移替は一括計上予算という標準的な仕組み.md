# デジタル庁の予算移替は特殊ケースか（結論: いいえ、標準的な「一括計上予算」の一例）

[前回調査](20260829_1635_予備費等マイナスの正体は予算移替.md)で判明した「デジタル庁項003→14府省庁への予算移替」が、令和6年度予算・決算の中で特異な事象かどうかを、一般会計の当初予算(`DL202411001`)・補正予算(`DL202421001`)・決算(`DL202477001`)のCSVを機械的に突合して確認した。

## 結論

**特殊ケースではない。** 「一つの所管に予算を一括計上し、執行段階で実施省庁の所管へ予算移替する」という手法は、日本の予算制度で広く使われる標準的な仕組み（一括計上予算）であり、デジタル庁のIT関連予算はその典型例の一つに過ぎない。令和6年度一般会計だけで、同じパターンの項が**15所管・179件**、決算段階で新規に出現している。

## 検証方法

1. 当初予算(`DL202411001b.csv`)・補正予算(`DL202421001b.csv`)から「所管｜項コード｜項名」の組をすべて抽出し、和集合を取る（＝予算成立段階で存在した項の一覧）。
2. 決算(`DL202477001b.csv`、全所管・目レベル収録）から同様に抽出。
3. 決算にのみ存在する組（`comm -13`）を洗い出す＝「予算段階には無く決算で初めて計上された項」。これが移替による受け皿である可能性が高い。

## 補足: 決算CSVでの移替の見え方（今回追加で判明した点）

前回調査では「移替先ごとの内訳金額は非公開」としていたが、実は目レベル決算CSV（`DL202477001b.csv`）から機械的に復元できることが分かった。

- 移替は`予算決定後移替増△減額`という専用の差分列（col16）には計上されず、両側の`歳出予算額`列（col12）自体に直接反映される。
  - デジタル庁側: 補正後予算額 685,739,597,000円 − 移替減少額 509,690,849,950円 = 決算`歳出予算額` 176,048,747,050円（1円単位で一致）
  - 受入側14所管: 決算で新規計上された「情報通信技術調達等適正・効率化推進費」の`歳出予算額`列の合計 = 509,690,849,950円（デジタル庁の減少額と1円単位で一致）
- したがって移替先ごとの内訳（府省庁別・目別）は、決算CSVを「予算段階に無い項」で絞り込むことで復元可能。前回調査の「機械的に紐づけ不可能」という評価は訂正が必要。

## 未検証・今後の課題

- 179件全件について、送り手（一括計上元）と受け手の金額が1円単位で一致するかまでは検証していない（デジタル庁の1件のみ確認済み）。
- 他年度（令和6年度以外）でも同様の規模・パターンで一括計上予算が使われているかは未確認。
