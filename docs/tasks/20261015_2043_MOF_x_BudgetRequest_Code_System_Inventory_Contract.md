# MOF × 概算要求の突合 — コード体系と文法の記述（inventory）の契約

状態: 数える前に commit する。**記述のみ。規則・閾値・成功基準を置かない。** 設計は同日の Redesign Proposal（確定事項は §5）。ここで数えた結果を見てから、M0〜M3 の契約（規則）を書く。

## 数えるもの
入力: 概算要求の `data/work/budget-request-csv/{2024,2025}/{total-table,detail-table}/sources/*.csv` と、MOF の `tests/fixtures/mof-archive-csv/{2024,2025,2025_teishutsu}/`。概算要求 FY2024 は MOF 2024、FY2025 は MOF 2025_teishutsu と 2025 を**それぞれ**対にする。

1. **行の文法（概算要求側）:** 資料（総表／明細表）・年度ごとの `row_type` の件数、直前の `row_type` → その行の `row_type` の遷移の件数、`row_type` ごとの先頭のコードの桁の形（例 `NNN`、`NNNNN‑NNNN‑NN‑NNNN`）の件数。
2. **CONTEXT の形:** 明細表の `CONTEXT` の形（先頭の桁数、名称の末尾）の件数と実例。
3. **名称・コードの一致の件数（選択はしない）。** 比べ方は次のとおりで、名称は**空白を除いたうえでの完全一致**だけを使う（正規化・部分一致なし）。概算要求の `CONTEXT` から取った所管名（`NN 〇〇所管` の〇〇）・特別会計名（`NNNN 〇〇特別会計` の〇〇）が、MOF の所管・特別会計と完全一致する場合に限り、その範囲の MOF 行を相手にする。
   - 範囲（M0 相当）: `CONTEXT` の件数、MOF の所管／特別会計に完全一致した件数、しなかったものの一覧。
   - 項（M1 相当）: 明細表の `CODE3` の行（`NNN 名称`）のうち、名称が同じ範囲の MOF の項名に完全一致するもの。その中で、コードの前 2 桁＝MOF の項コード／コード＝項コード＋`0`／どちらでもない、の件数。
   - 事項（M2 相当）: 明細表の `DETAIL`（`NN‑NN 名称`）のうち、名称が同じ範囲の MOF の事項名に完全一致するもの。その中で、前半 `NN`＝MOF の項コード、後半 `NN`＝MOF の主要経費別分類コード、のそれぞれの一致の件数。
   - 目（M3 相当）: 明細表の `CODE_5_4_2_4`（`NNNNN‑X‑X‑X 名称`）のうち、名称が同じ範囲の MOF の目名に完全一致するもの。その中で、コードの読み方の候補ごとの一致の件数（候補は事前に次の 2 つに固定し、結果を見て増やさない）: **候補 S**（特別会計の形）＝(5桁の前2桁, 5桁の後3桁, 2番目, 3番目) が (主要経費, 目的別, 使途別, 目別) に一致。**候補 G**（一般会計の形）＝(5桁の前2桁, 5桁の後3桁, 2番目の前 N 桁と後 M 桁を経済性質別・使途別に分けた形, 3番目) の一致は、2番目が 4 桁のとき、前2桁＝経済性質別、後2桁＝使途別、3番目＝目別。どちらの候補にも当たらない件数も出す。
4. **MOF 側の裏づけ:** 目の CSV が項単位（事項の列がない）であること、同じ項で（主要経費, 目的別, 使途別, 目別）が同じで経済性質別だけ違う行の件数。

## 追補（第 2 ラウンド。第 1 ラウンドの結果と、MOF の目の 1 行（国会・衆議院の `職員基本給`）の列を見たあとに書く）
第 1 ラウンドの結果: 項コードの前 2 桁の仮説は 96／1,139 でしか当たらず、目の候補 G は 0 件、候補 S は約 2% だった。MOF の一般会計の項コードは 3 桁、目の列には財政法公債金対象非対象別分類コード（`財政法`）が 1 桁ある、と MOF の CSV の見出しから分かったため、**第 1 ラウンドの候補とは別に**、次の候補を追加して数える（第 1 ラウンドの出力は変えない。結果を見て、これ以上は増やさない）。
- 項: **K0**＝概算要求の `CODE3` の 3 桁が MOF の項コードと完全一致（一般会計・特別会計を分けて数える）。
- 目: 明細表の目のコード `NNNNN‑X‑YY‑ZZZZ` の 2 番目の塊（`X`）の桁数（1／3／4）ごとに、`X` を次のように読む候補の一致を数える（先頭 5 桁は常に 主要経費2桁＋目的別3桁、3 番目 `YY` は目別）。
  - **H1**（1 桁）: `X`＝使途別
  - **H3**（3 桁）: `X`＝経済性質別（2 桁）＋使途別（1 桁）
  - **H4**（4 桁）: `X`＝財政法（1 桁）＋経済性質別（2 桁）＋使途別（1 桁）
  - 3 つとも、どの桁数の行にも当てて数える（桁数と候補の対応も事実として出す）。特別会計の MOF の目には財政法の列がないため、H4 は一般会計の行だけに当てる。
- 出力: `cross-relations-round2.json`。`scripts/research/inventory-mof-budget-request-codes-round2.py` を実行前に commit する。
