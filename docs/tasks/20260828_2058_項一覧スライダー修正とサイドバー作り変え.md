# レンジスライダーのThumb位置ズレ修正 と 左サイドバーの/sankey-svg準拠化

## レンジスライダーの縦ズレ修正

`RangeSlider.tsx`のThumbがトラックのバーより上にズレて見える不具合。原因は`<input type="range">`自身の箱を`h-1.5`（6px）にしていたのに対し、Thumbの疑似要素は`h-3.5`（14px）で箱より大きく、ブラウザが中央揃えできず上端基準で描画していたため。inputの箱をコンテナと同じ高さ（`h-4`=16px、Thumb以上）まで広げ、`inset-0`でコンテナに一致させることで解消。合わせてトラックの塗り分け色を青（`bg-blue-500`）にして選択中の範囲を強調した。

## 左サイドバーを/sankey-svg準拠に作り変え

これまで独自実装（固定幅div＋独自のリサイズハンドル）だったフィルタパネルを、`/sankey-svg`・`/subcontracts`の左右詳細パネルが共通で使っている`SidePanelChrome`（`client/components/SidePanelChrome.tsx`）＋`useSidePanel`（`client/hooks/useSidePanel.ts`）に置き換えた。画面端の開閉タブ（矢印アイコン）・幅調整ハンドル（ダブルクリックで既定幅に戻る）・開閉時のtransitionが揃う。

`SidePanelChrome`は元々`position: fixed`固定（サンキー・subcontractsはヘッダーの無い全画面キャンバス型ページのため）。`/mof-kou`は通常のドキュメントフロー（ヘッダー・ツールバーを持つ）ページのため、`position?: 'fixed' | 'absolute'`propを追加し、`/mof-kou`側では`'absolute'`を指定して、ヘッダーの下のコンテンツ領域（`position: relative`にした行）だけに収まるようにした。この変更は他の利用箇所（サンキー・subcontracts）には影響しない（デフォルトは従来通り`'fixed'`）。

テーブル側は、パネルの開閉タブ幅（25px）とパネル自身の幅を考慮した`paddingLeft`で押し出す形にした（`filterPanel.collapsed ? 0 : filterPanel.effectiveWidth`＋タブ幅25px＋余白12px）。

## 検証

- `npx tsc --noEmit` / `npm run lint`: クリーン（既存警告のみ、SidePanelChromeの他の利用箇所にも影響なし）
- Playwrightでズームしたスクリーンショットにより、Thumbの縦中心がトラックの中心と一致することを確認
- サイドバーの開閉タブでの折りたたみ・再展開、その際のテーブルの再レイアウトを確認
