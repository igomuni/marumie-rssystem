# 年度をまたぐRSリンク引き継ぎ表示

RS事業データの公開はMOF予算書より遅れるため、`mof-rs-kou-moku-linkage-{年度}.json` は
予算年度2024（RS_2025）分しか存在しない。最新の予算年度（現状2026年度）を`/mof-kou-moku`で見ると
RSリンクが一件も表示されない状態だった。これを、識別子（会計区分・所管・組織/特会・勘定・
項コード・目分類コード・目名。予算種別を除く。決算目への予算種別間引き継ぎと同じ考え方）が
一致する直近の過去年度の紐づけを参考値として引き継いで表示するようにした。

## 実装

- `app/lib/api/mof-rs-kou-moku-linkage-loader.ts`: `resolveLinks(budgetYear)` を追加。
  要求年度に直接ファイルがあればそのまま返し、無ければ`mof-kou-moku`の`availableYears()`から
  紐づけファイルのある直近の過去年度を探し、`identityKey()`でその年度のkouMokuKeyへ変換して
  引き継ぐ。結果として `{ sourceBudgetYear, isCarriedOver, links }` を返す
- `app/api/mof-kou-moku/linkage/route.ts`: レスポンスに`isCarriedOver`・`sourceBudgetYear`を追加
- `app/mof-kou-moku/page.tsx` / `KouMokuTable.tsx`: 引き継ぎ時はRS↗バッジをアンバー色にし、
  詳細パネルに「この年度自体のRS紐づけデータはまだ無いため、◯◯年度時点の紐づけを識別子で
  参考表示しています」という注記を追加

## 確認

- 2024年度（直接データあり）: `isCarriedOver: false`、件数は従来通り24,223件
- 2026年度（データなし・最新）: `isCarriedOver: true`、`sourceBudgetYear: 2024`で13,809件を引き継ぎ表示
- 2017年度（過去年度のデータも無い）: `available: false`のまま（従来動作を維持）
- ブラウザで一覧・詳細パネルの表示を確認（スクリーンショット確認済み、コンソールエラーなし）
