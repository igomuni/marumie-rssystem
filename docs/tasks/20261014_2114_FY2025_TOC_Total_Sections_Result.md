## 読み方と限界
- 一致は、独立した2経路が同じ答えを出したということで、正解率ではない。2経路とも同じ誤りをする場合（例: 両方が同じ内訳行を項と取る）は検出できない。
- 項が確認できた範囲は、一般会計・特別会計・CONTEXT なしの 1,477 事項（全 1,869 の 79%）。一般会計で TOC＋総表が無い 317 事項は、ほとんどが総表が別の PDF にあるもので、別の PDF との対応付けは本 Task の範囲外。
- 不一致の多くは、X が事項の直前の3桁行（内訳や別の行）を項と取る型に見える。#460 の K2 の不一致や #461 の SECTION_MISMATCH との関係は調べていない。
