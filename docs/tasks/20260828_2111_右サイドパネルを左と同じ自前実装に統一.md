# 右サイドパネル（項詳細）を左フィルタパネルと同じ実装パターンに統一

前回`/sankey-svg`のSidePanelChromeに合わせたところ、実際に良かったのは左フィルタパネルの「マージン部分がハンドルとして反応する」実装であり、右パネルもそちらに揃えることになった。SidePanelChrome（画面端の開閉タブ・パネル自身の端にハンドルを重ねる方式）は使わず、左右とも同じ自前実装（固定幅div＋一覧との間のマージン全体がハンドルになる別要素）に統一した。

## 対応内容

- `client/components/mof-kou/KouSidePanel.tsx`: `width` propを復活（`onWidthChange`は不要になったため無し）。外側を`<aside style={{width}}>`＋角丸枠に戻したが、パネル自身の内部に幅調整ハンドルは持たない（左のFilterSidebarと同じ役割分担）
- `app/mof-kou/page.tsx`: `panelWidth`/`setPanelWidth`のstateと`startPanelResize`関数を復活（左の`sidebarWidth`/`startSidebarResize`と対になる実装）。一覧とKouSidePanelの間に、左と同じ見た目・挙動の幅調整ハンドル用div（`w-3`のマージン全体がドラッグ領域）を配置
- `client/components/SidePanelChrome.tsx`: 直前のコミットで追加した`position?: 'fixed' | 'absolute'` propは、この変更で利用箇所が無くなったため削除（他ページでの利用は元々`position: 'fixed'`固定だったため実質的な差分は無い）

## 検証

- `npx tsc --noEmit` / `npm run lint`: クリーン
- Playwrightで確認: 行クリックで右パネルが開き、左右とも同じ見た目（角丸枠＋マージン部分のハンドル）になっていることを確認。右パネルのハンドルをドラッグして幅が変わることを確認（横スクロールの再発なし）
