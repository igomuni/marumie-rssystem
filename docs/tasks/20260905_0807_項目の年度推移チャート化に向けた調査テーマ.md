# 項・目の年度推移チャート化に向けた調査テーマ

「目の使い回し」の調べ方を検討する過程で、[前回の調査](20260905_0730_MOF目の年度間変化調査.md)の前提そのものが誤っていたことが分かった。まず訂正を述べ、その上で年度推移をチャート化するために踏むべき調査テーマとデータ加工方針を整理する。

## 前提の訂正: 目コードは「目のID」ではなく「費目の分類コード」

`subItemCode`（CSVの`目別分類コード`）は、[mof-budget-data-guide.md](../mof-budget-data-guide.md) 4-7節のとおり **01=議員歳費・05=諸手当・08=旅費の類・09=庁費の類・16=補助金の類** といった**費目の種類**を表す2桁コードで、個々の目を一意に識別するものではない。実測（2024年度当初予算）:

- 同じ目コードが複数の目にぶら下がる項: **576/1,054項（54.6%）**
- 重複コードに属する目: **5,816/8,088目（71.9%）**
- 最大は「北海道開発事業費」のコード`00`（公共事業関係費等）で**82目**

一方、**目名は項の中でほぼ一意**（2024年度当初予算で目名が項内重複する項はわずか2/1,054。決算でも7/1,270）。したがって目の識別子は **(会計区分, 所管, 組織/勘定, 項コード, 目名)** であり、目コードを含めてはならない。

### 訂正1: 「目コードの使い回し」は誤り

前回「沖縄政策費(16) 沖縄子供の貧困緊急対策事業費補助金 → 沖縄観光景観形成支援事業費補助金」を目コードの使い回しと解釈したが、これは**目コードで突合したために生まれた偽のペア**だった。実際に沖縄政策費のコード16（補助金の類）の中身を全件見ると、2023年度13件・2024年度16件の補助金が並んでおり、両者は無関係な別の補助金である。

### 訂正2: 「表記揺れは0件」も誤り

同じ理由で表記揺れの検出も失敗していた。正しい識別子で突合し直すと、「沖縄政策費」の当該補助金は**消えたのではなく「沖縄子供の貧困緊急対策事業費補助金」→「沖縄こどもの貧困緊急対策事業費補助金」（子供→こども）と表記が変わって存続**していた。前回「表記揺れ0件」としたのは検出手法の誤りによるもので、実在する。

正しい識別子で全年度ペアを再突合した結果、完全一致率自体は前回とほぼ同じ（当初予算2023→2024で96.1%）だったが、その内訳の解釈は上記のとおり全面的に変わる。

## 調査テーマ

### テーマ1: 識別子の安定性検証（最優先）

年度推移を描くには「同じ項・同じ目」を年度をまたいで繋ぐ識別子が要る。既存コードは `mof-kou-loader.ts` の `sectionIdentity`（会計区分・組織/勘定・項コード。**所管と予算種別を除外**）を項の年度推移に使っている。この設計判断の妥当性と、目レベルへの拡張可否を検証する。

確認済みの事実:

- **所管名の変更は識別子を壊す**。2026年度は東日本大震災復興特別会計の所管表記に「防災庁」が加わり（`国会、裁判所、…、内閣府、デジタル庁、復興庁、…` → `…、デジタル庁、防災庁、復興庁、…`）、所管を識別子に含めると**280目が消滅・260目が新規**という偽の断絶になる。既存の `sectionIdentity` が所管を外しているのは正しい（[20260828_0642](20260828_0642_年度横断識別子から所管を除外.md) と同種の問題）
- **項名は項コードに固定されていない**。`sectionIdentity` 単位で全10年度を並べると、当初予算で **156/1,317識別子（11.8%）** で項名が変わる。中身は3種類:
  - 単なる改称・表記統一（`麻薬・覚せい剤等対策費`→`麻薬・覚醒剤等対策費`、`共生社会政策費`→`共生・共助政策費`）
  - 意味のある継承（`情報技術犯罪対策費`→`サイバー警察費`→`警察情報通信基盤費`、`熊本地震復旧等予備費`→`新型コロナ対策予備費`→`原油価格・物価高騰対策予備費`）
  - **項コードの振り直し**: 農林水産本省で2021年度に `003 食品の安全…`→`農林水産物・食品輸出促進対策費`、`007 農林水産物・食品輸出促進対策費`→`独法…施設整備費` のように、複数の項が玉突きでコードをずらしている。**これを識別子で繋ぐと無関係な項の推移が接続される**

調べること: 項名変化156件を「改称/継承/振り直し」に分類し、振り直しが疑われるケースで既存の年度推移表示が実際に壊れているかを確認する。

#### 検証結果（`scripts/analyze-mof-section-identity-stability.ts` で実施・恒久化）

sectionIdentity が同一で項名が変わった当初予算169件（前述の156件は決算込みの概数、当初予算のみでは169件）を、**同じ組織スコープ内で旧項名が別の項コードに新規出現しているか**（＝コードの交換の直接証拠）で機械判定した。

| 分類 | 件数 | 割合 |
|---|---|---|
| 振り直し疑い（コード交換の証拠あり） | 75 | 44.4% |
| 改称・継承（証拠なし） | 94 | 55.6% |

**項名変化の半数近くが、実は改称ではなくコードの玉突き交換だった。** 年度ペア別の内訳:

| 年度ペア | 件数 | 主因 |
|---|---|---|
| 2020→2021 | 46 | 農林水産本省・水産庁でコード帯全体が数コードずつスライド（例: コード036→038が旧038→040の項名を引き継ぎ、以下連鎖） |
| 2022→2023 | 36 | 経済産業本省・資源エネルギー庁・自動車安全特会でコードの一部入れ替え |
| 2025→2026 | 51 | 農林水産本省・林野庁で同種の帯スライドが再発。テーマ3で確認した2025→2026の断絶（消滅525・新規540）の相当数はこの振り直しが実体 |
| その他の年度ペア | 36 | 数件〜十数件（警察庁「サイバー警察費→警察情報通信基盤費」など単発の改称も含む） |

**影響**: `sectionIdentity()` は `/mof-kou` の項の年度推移（`sectionHistory()` → `/api/mof-kou/history`）で実際に使われている。上記の年度ペアをまたぐ項では、**この機能が無関係な2つの項を1本の系列としてつなげて表示している**（例: 2020→2021の農林水産本省コード003は「食品の安全・消費者の信頼確保対策費」から実際には無関係な「農林水産物・食品輸出促進対策費」に切り替わっているが、画面上は同一項の推移として表示される）。

CSV全件: `data/result/mof-section-identity-name-changes.csv`（Git管理外、`npx tsx scripts/analyze-mof-section-identity-stability.ts` で再生成可能）。

### テーマ2: 「消滅・新規」の塊を分解する

正しい識別子で突合しても、当初予算2023→2024で消滅316件・新規211件が残る。これは単一の現象ではなく、少なくとも以下が混在している。チャート化には、この塊を分解する処理が要る。

| 分類 | 判定に使える信号 |
|---|---|
| 表記揺れ | 正規化（子供/こども、覚せい剤/覚醒剤、障害/障がい、全角半角、中黒）後に一致 |
| 改称（同じ支出の名前だけ変更） | 目コード（費目の種類）が一致・金額が近い・分類コード群が一致 |
| 項をまたぐ移動 | 別の項に同名の目が出現。ただし後述のとおり単独では証拠にならない |
| 分割・統合 | 消滅側の合計と新規側の合計が保存されるか |
| 真の新設・廃止 | 上記いずれにも当たらない |

**注意点として確認済み**: 「別の項に同名の目がある」は移動の証拠にならない。消滅317件のうち183件（58%）が該当するが、中身は `庁費`・`職員旅費`・`児童手当` のような**どの項にも現れる汎用的な目名**がほとんどで、実際の移動ではない。移動の判定には金額の一致など追加の信号が要る。

### テーマ3: 年度ペアごとの断絶の集中箇所を特定する

当初予算の完全一致率は大半の年度ペアで94〜98%だが、**2020→2021（90.1%）と2025→2026（86.5%）** だけ明確に低い。2025→2026の内訳を所管別に見ると原因はほぼ特定できている:

- **農林水産省: 消滅525・新規540** — 突出。テーマ1の「項コードの振り直し」が2026年度にも大規模に起きている可能性が高い
- **東日本大震災復興特別会計: 消滅280・新規260** — 所管表記への防災庁追加による偽の断絶（テーマ1）
- 防災庁の新設: 新規16

2020→2021についても同じ切り分けを行えば、「実際の予算構造の変化」と「識別子の都合による見かけの変化」を分離できる。

### テーマ4: まとめ書き「◯◯外N目」の扱い

補正予算では `諸謝金外25目`・`職員旅費外6目` のように複数の目を1行に畳んだ書き方が多用され、年度でNの値が変わる（`諸謝金外25目`→`諸謝金外31目`）。これは目名の一部が件数になっているため、そのままでは年度をまたいで繋がらない。実数（何件がこの書き方か、金額規模はどれくらいか）を把握し、系列を作るときに「Nを除いた名前」で正規化するか、まとめ書き行は別扱いにするかを決める必要がある。

### テーマ5: 識別子に使えない行の把握

- **目名が空欄**の目（例: 補正予算・特別会計「07 国債整理基金特別会計へ繰入」。項自体が単一の目として計上され目名を持たない）
- 決算の**「目未定」**（予備費の枠など）

これらは目名を識別子に使う方針と正面から衝突する。件数と金額規模を把握し、項名で代替するなどの規則を決める。

## 目名の年度またぎ再利用状況（実施済み）

前節（テーマ1）は項コードが年度をまたいで安定するという前提に立って項の識別子を検証したが、**項コードは年度ごとに異なる別物という前提に立つべき**（項の再編・再配置は毎年度起こり得る）。したがって年度をまたいでキーになり得るのは実質「目名」しかなく、目名がどの範囲でどれだけ再利用・持続しているかを直接調べた（`scripts/analyze-mof-koumoku-name-reuse.ts`で恒久化、当初予算2017〜2026）。

### (A) 目名は組織内で一意ではない

(会計区分・所管・組織/特会/機関) スコープ内で目名の重複を見ると、**全目の約40%（毎年3,200〜3,300件）が同一年度内で複数の異なる項にまたがって同じ目名を持つ**。「庁費」「施設整備費」「職員旅費」のような共通の費目カテゴリ名が、同じ省庁内の多数の項に並行して存在するため。**目名は単独では特定の1つの目を指す識別子になり得ない**（そもそも同一年度内で一意でない）。

### (A2)〜(D) 組織内で一意な目名（残り約60%）に絞った場合

年内で単一の項にしか属さない目名（2024年度で60.1%、以後10年度とも59〜60%で安定）だけに絞って持続性を見ると:

| 指標 | 結果 |
|---|---|
| 全10年度に存在 | 3,301/7,136 (46.3%) |
| 1年度だけ存在 | 808/7,136 (11.3%) |
| 消滅後に復活（不連続） | 354/7,136 (5.0%) |
| 復活時に項名も変わり金額5倍以上乖離（＝使い回し疑い） | **4件のみ** |
| 連続年で項コードが変わっても目名で追跡できたペア | 507/40,926 (1.2%) |

**「同じ目名なのに中身が別物に置き換わっている」ケースは、金額0円を除外して厳密に見るとほぼ存在しない（7,136件中4件）。** 目名が組織内で一意でありさえすれば、消滅→復活は大半が「一時的に予算が付かなかった/計上を休止した」だけで、使い回しではなかった。

一方、**目名で項コードの変化を跨いで追跡できたのは1.2%とごく少数**。これは、項が再編・再配置されると（テーマ1で見た農林水産省・水産庁・林野庁のようなコード帯スライドを含む）、単一な目名を持つ項であっても目名ベースの追跡はほとんど機能しないことを示す。

### 結論: 何が年度をまたいでもキーになり得るか

- **(会計区分, 所管, 組織/特会/機関, 目名)** は、目名が組織内でその年度に一意である場合に限り、有効なキーになり得る（対象は全目の約60%）
- 残り約40%（庁費・施設整備費等の汎用名）は目名だけでは原理的に追跡不能。項名やより詳細な文脈（使途別分類・金額の連続性など）を追加の手がかりにするしかない
- 一意な目名についても、項の再編をまたぐと追跡が途切れる（1.2%しか繋がらない）。項再編が起きた年度ペア（テーマ3で特定した2020→2021・2022→2023・2025→2026等）では、目名ベースの系列もそこで一旦切れると見るべき

## 項名の年度またぎ再利用状況（実施済み）

目名と同じ手法を項名にも適用した（`scripts/analyze-mof-section-name-reuse.ts`、当初予算2017〜2026）。結果は目名よりもかなり良好で、**項名は目名よりも扱いやすい識別子**だとわかった。

### (A) 項名は組織内で完全に一意

(会計区分・所管・組織/特会/機関)スコープ内で項名の重複を見ると、**全10年度・全項で重複0件**。目名は約40%が組織内で複数項にまたがる汎用名だったが、項名にはその問題が無い。

### (B)〜(D) 持続性・使い回し

| 指標 | 項名 | （参考）目名（一意な目名のみ） |
|---|---|---|
| 全10年度に存在 | 760/1,502 (50.6%) | 3,301/7,136 (46.3%) |
| 1年度だけ存在 | 151/1,502 (10.1%) | 808/7,136 (11.3%) |
| 消滅後に復活（不連続） | 63/1,502 (4.2%) | 354/7,136 (5.0%) |
| 復活時に金額5倍以上乖離（使い回し疑い） | **2件のみ** | 4件 |
| 連続年で項コードが変わっても項名で追跡できたペア | 118/8,998 (1.3%) | 507/40,926 (1.2%) |

**使い回し（同じ名前で中身が別物に置き換わる）はほぼ存在しない**（1,502件中2件、いずれも数年おきの施設整備費で不自然ではない）。一方、項コードが変わると項名ベースの追跡も1.3%しか繋がらず、目名と同様に項再編を跨ぐ追跡は弱い。

### 結論

**項の年度をまたぐキーとしては、項コードより項名の方が実務上信頼できる**（対象範囲の集合自体が変わらない項コードと違い、項名は組織内で常に一意）。ただし項の再編（テーマ1・3で確認したコード帯スライド）が起きた年度ペアでは、項名を使っても系列は途切れる。既存の`sectionIdentity()`（項コードベース）をこのまま使い続けると、テーマ1で確認した「無関係な項を同一系列として繋げる」誤りを埋め込んだままになる。改善案としては、`sectionIdentity()`に項名の一致判定を組み合わせ、**項コードが変わった年度ペアでは項名の一致・不一致で継続/断絶を再判定する**方向が有力（実装はまだ行っていない）。

## チャート化に向けたデータ加工方針

上記テーマの結果を踏まえて、次の中間データを作るのが素直だと考えている。

1. **年度ペアのマッチング結果**: 隣接年度ごとに「完全一致 / 表記揺れ / 改称推定 / 分割・統合推定 / 新設 / 廃止」のいずれかでペアリングした対応表
2. **系列（lineage）**: 1のペアリングを年度方向に連鎖させ、複数年にわたる1本の系列にまとめたもの。系列IDを持たせ、各年度の金額・目名・所属項をぶら下げる
3. **系列の信頼度ラベル**: 完全一致だけで繋がった系列は高信頼、改称推定や分割・統合推定を挟む系列は要注意として区別する。**推定で繋いだ箇所を隠さずにチャート上でも示せるようにする**のが、このデータの性質上いちばん重要

チャートはこの系列データの上に乗せる（1系列＝1本の折れ線、断絶や推定接続は線種で区別する等）。生成物の置き場・スクリプトの構成は、テーマ1〜5の結果を見てから決める。

## 補足

- 本ドキュメントの数値は `public/data/mof-budget-{年度}.json` を直接読む使い捨てスクリプト（`/tmp`配下）で算出した。リポジトリには残していない
- 目コードの正体が判明したことで、前回の調査の「目名変更164〜396件」という数字自体が偽ペアを多く含む。テーマ2の分解を行うまでは、この数字を根拠に使わないこと
