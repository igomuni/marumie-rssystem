# 会計間の繰入構造の実測（令和8年度中心・15年度で裏取り）

「国の予算の合計はいくらか」を出すたびに二重計上が問題になるので、繰入の実態を測った。
結論は2つ。**一般会計は歳出の57%が他会計への繰入**で、**受け手側の捕捉方法にガイドの誤記があった**。

## 1. 送り手側は分類コードで取れる

歳出の `使途別分類コード = 6`（他会計へ繰入）で機械的に拾える。名前一致は要らない。

| 会計 | 歳出 | うち他会計へ繰入 | 比率 |
|---|---:|---:|---:|
| 一般会計 | 122.31兆 | **69.66兆** | **57.0%** |
| 特別会計 | 441.73兆 | 102.14兆 | 23.1% |

一般会計の使途別内訳:

```text
6 他会計へ繰入    69.66兆 (57.0%)
5 補助費・委託費   34.71兆 (28.4%)
3 物件費           6.66兆 ( 5.4%)
1 人件費           4.88兆 ( 4.0%)
4 施設費           4.00兆 ( 3.3%)
9 その他           2.29兆 ( 1.9%)
2 旅費             0.10兆 ( 0.1%)
```

**一般会計は「使う会計」ではなく「回す会計」。**人件費は4%しかない。

宛先は31種あるが上位3つで96%:

```text
30.79兆  普通国債等償還財源等国債整理基金特別会計へ繰入
20.88兆  交付税及び譲与税配付金特別会計へ繰入
13.13兆  基礎年金年金特別会計へ繰入
```

`目別分類コード = 22`（他会計への繰入）でも一般会計で69.61兆とほぼ同値。
使途別のほうが会計をまたいで一貫するのでそちらを使う。

## 2. 受け手側 — ガイドの記述が誤っていた

`docs/mof-budget-data-guide.md` 2-3節にこうあった。

> 款名が `他会計より受入` の行が**会計間の資金移動の受け手側**。一般会計からの繰入はここで捕捉する。

**これでは年金特別会計の13.38兆円を取りこぼす。**年金特会は「一般会計より受入」が
款 `保険収入` の下に置かれている（款 `他会計より受入` では0.12兆しか出ない）。

令和8年度:

```text
款名 = 他会計より受入            113.09兆
目名に「一般会計より受入」を含む    66.83兆
両方に該当                       53.45兆
款のみ（目名は別表記）             59.64兆
目のみ（款は別表記）★取りこぼし     13.38兆
和集合                          126.47兆
```

取りこぼす行の款名は `年金 / 保険収入` に集中している。

15年度ぶんで確認したところ**恒常的**で、毎年10〜13兆円が落ちる。

| 年度 | 款名のみ | 和集合 | 取りこぼし |
|---|---:|---:|---:|
| 平成23（2011） | 104.81兆 | 115.25兆 | 10.45兆 |
| 平成26（2014） | 111.38兆 | 122.11兆 | 10.73兆 |
| 平成30（2018） | 106.27兆 | 117.90兆 | 11.63兆 |
| 令和4（2022） | 112.23兆 | 124.39兆 | 12.16兆 |
| 令和8（2026） | 113.09兆 | 126.47兆 | 13.38兆 |

既存の `scripts/parse-mof-transfer-data.ts` は目名ベースで実装されているため**コードは正しい**。
誤っていたのはガイドの記述だけ。修正済み（§6-2）。

## 3. 送受は突き合う

宛先別に並べると整合する（兆円）。

| 特別会計 | 一般会計から | 受入計（他会計すべて） |
|---|---:|---:|
| 国債整理基金 | 31.27 | **87.99** |
| 交付税及び譲与税配付金 | 20.92 | 21.17 |
| 年金 | 13.50 | **13.50** |
| 子ども・子育て支援 | 2.72 | 2.61 |
| エネルギー対策 | 0.76 | 0.81 |
| 食料安定供給 | 0.31 | 0.24 |
| 合計 | 69.66 | 126.47 |

- **年金は1円単位で完全一致**
- 国債整理基金の差 56.7兆は特別会計からの繰入（56.65兆）とほぼ一致
- 特会名で宛先を判定できなかったのは `貨幣回収準備資金へ繰入` と `防衛力強化資金へ繰入` のみ（僅少）

特別会計から他会計への繰入の内訳:

```text
56.65兆  国債整理基金特別会計へ繰入
25.83兆  基礎年金勘定へ繰入
13.00兆  財政融資資金へ繰入
 2.19兆  雇用勘定へ繰入
```

## 4. 純計

```text
一般会計 歳出       122.31
特別会計 歳出       441.73
政府関係機関 支出      4.72
単純合計           568.75
− 他会計より受入    126.47
− 他勘定より受入      1.15
= 一次純計         441.13
```

**441兆でもまだ実態から遠い。**特別会計歳出の**50.9%（224.83兆）が国債整理基金**で、
その大半は借換債の償還。同じ債務を借り換えるための出入りなので、実質的な支出規模を
見るならここも落とす必要がある。

| 特別会計 | 歳出 | 構成比 |
|---|---:|---:|
| 国債整理基金 | 224.83兆 | 50.9% |
| 年金 | 102.93兆 | 23.3% |
| 交付税及び譲与税配付金 | 51.07兆 | 11.6% |
| 財政投融資 | 27.44兆 | 6.2% |
| エネルギー対策 | 16.92兆 | 3.8% |
| その他9会計 | 18.54兆 | 4.2% |

上位3会計で86%。特別会計の規模は**国債の借換と年金・交付税の通過**でできている。

## 5. 残課題

`scripts/parse-mof-transfer-data.ts` は次の点で古い。今回は触っていない。

- `mof_2023` 固定。年度引数を取らない
- 列を位置（`row[9]`, `row[11]` 等）で決め打ち。年度で列名が揺れる問題に対応していない
- 特会名の判定が if-else のハードコード。`(.+?)特別会計へ繰入` のフォールバックはあるが網羅していない
- 使途別分類コードを使わず目名の文字列一致で拾っている（コードを使えば頑健になる）

`/mof-budget-overview` はこのパーサの出力に依存しているので、改修するならそちらの確認も要る。

## 6. 追記: 逆方向（特会→一般会計）— 仮説が覆った

§1〜§4 は「繰入は一般会計から特会への一方通行」という前提で書いていた。**これは誤り。**

### 歳出側からは追えない

特会歳出に目名 `一般会計へ繰入` は実在するが、令和8年度で**18勘定あわせて7億円**しかない。

```text
0.0002兆（2億円）  労働保険 / 労災勘定 / 一般会計へ繰入
0.0001兆（1億円）  自動車安全 / 自動車検査登録勘定 / 一般会計へ繰入
0.0001兆（1億円）  年金 / 厚生年金勘定 / 一般会計へ繰入
  … 計18勘定 7億円
```

事務費相当の精算で、本体ではない。**§6-1 の `使途別分類コード=6` では逆流を捕捉できない。**

### 本体は一般会計の歳入側にある

| 一般会計 歳入 | 金額 |
|---|---:|
| 諸収入 / 特別会計受入金 / 外国為替資金特別会計受入金 | 2.378兆 |
| 諸収入 / 防衛力強化資金受入 | 1.381兆 |
| 諸収入 / 防衛力強化特別会計受入金 / 外国為替資金特別会計受入金 | 0.752兆 |
| 諸収入 / 東日本大震災復興エネルギー対策特別会計受入金 | 0.069兆 |
| 回収金等収入 / 社会資本整備事業特別会計整理収入 | 0.047兆 |

`◯◯特別会計受入金` 系の合計は年度により1.8〜4.3兆円。

| 年度 | 合計 | 最大 |
|---|---:|---|
| 平成23（2011） | 4.32兆 | 外国為替資金 2.93兆 |
| 平成26（2014） | 1.86兆 | 外国為替資金 1.59兆 |
| 平成30（2018） | 1.92兆 | 外国為替資金 1.75兆 |
| 令和4（2022） | 1.79兆 | 外国為替資金 1.42兆 |
| 令和8（2026） | 3.25兆 | 外国為替資金 3.13兆 |

### なぜ歳出に載らないのか

**原資が歳出予算ではなく剰余金だから。**外国為替資金特別会計の令和8年度は

```text
歳入 4.8247兆（うち利子収入 4.04兆）
歳出 1.9734兆
差   2.8513兆  ← これが繰入の原資
```

歳出予算に `一般会計へ繰入` の行が（融通証券事務取扱費の僅少分を除いて）無い。
外貨資産の運用益が原資なので、円安局面ほど額が膨らむ。平成23年度に4.32兆と大きいのも、
令和8年度に3.25兆へ戻っているのも、為替と金利の動きに連動している。

なお令和8年度は 2.378兆 ＋ 0.752兆 ＝ 3.13兆が外為特会由来で、単年度の剰余2.85兆を上回る。
積立金の取崩しを含むためで、**歳入歳出差額と繰入額は一致しない**。

`社会資本整備事業特別会計整理収入` は平成25年度に廃止された特別会計の残務処理。

### 含意

- 規模は単純合計568.75兆に対して0.6%程度で、§4 の一次純計441.13兆を大きくは動かさない
- ただし**方向によって捕捉方法がまったく違う**ため、双方向を扱うなら一般会計歳入側を読む処理が別に要る
- `scripts/parse-mof-transfer-data.ts` は一般会計→特会の一方向しか見ていない
