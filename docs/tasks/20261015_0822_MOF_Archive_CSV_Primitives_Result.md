## 特別会計と FY2025 の事項
- **parser が対応していない。** parser v0 は、FY2024 の一般会計（帳票 `202411001`）の凍結済みの source set に固定されている（DOCTYPE・見出しの「令和6年度」を含む）。特別会計と FY2025 の XML は、`unsupported` か入力の契約違反になる見込み。parser は変えていない。
- **XML の入手:** FY2024 の archive にある XML は、一般会計（`202411001`）だけ（328本）。ほかは、取得の予行（ダウンロードなし）で、リンクがあることを確認した:
  - FY2024 の特別会計 `202412001`
  - FY2025 の一般会計・特別会計、提出時（`2025_teishutsu`）と成立後（`2025`）のそれぞれ
- 取得は、parser の見通しが立つまでしていない（使えない XML を先に取っても使い道がないため）。

## 次（ユーザーの判断）
1. **parser の一般化:** 特別会計・FY2025 の事項を作るには、parser v0 を一般化する必要がある（組織の列が無い、列の位置の違い、DOCTYPE・見出しの年度）。規則の変更なので、事前登録し、FY2024 の一般会計の出力（`jikou-general.csv`、`2b92b50e…`）がバイト単位で変わらないことを回帰条件にする案。
2. 上が決まったら、特別会計と FY2025（提出時・成立後）の XML を取得し（`download-mof-archive.ts --xml=`）、同じ確認（項の一致、金額の整合）をする。
3. FY2025 では、成立後と提出時の XML の差（修正による14行＋3行の金額、事項の追加・削除の有無）も記述する。
