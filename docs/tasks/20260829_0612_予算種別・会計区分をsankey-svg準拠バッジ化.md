# 予算種別・会計区分を/sankey-svg準拠のバッジ表示に変更

`/mof-kou`の一覧・サイドパネルで平テキスト表示だった予算種別・会計区分を、`/sankey-svg`の会計区分バッジと同じ見た目（小さな色付きピル・白文字）に統一した。列幅節約とサイドパネルの視認性向上が狙い。

## 対応内容

- `app/lib/account-badge.ts`（`/sankey-svg`・`/subcontracts`と共用の会計区分バッジヘルパー）に`agency`（政府関係機関、紫 `#8b6fd6`）を追加。既存の`general`（赤 `#e45f6f`）・`special`（青 `#5f8ee8`）・`both`はそのまま
- `client/components/mof-kou/Badge.tsx`（新規）: 上記ヘルパーを使う`AccountBadge`と、MOF予算書ページ固有の予算種別バッジ`BudgetTypeBadge`（当初=グレー・暫定=琥珀・補正N号=橙・決算=紫、同じピルの見た目）を追加
- `client/components/mof-kou/KouTable.tsx`: 予算種別・会計区分の2列をバッジ表示に変更
- `client/components/mof-kou/columns.ts`: 上記2列の幅を124→76px、92→64pxに縮小
- `client/components/mof-kou/KouSidePanel.tsx`: サイドパネルヘッダーの「予算種別・会計区分・所管・組織…」という文字の羅列から、バッジ2つを見出しの上に独立表示するレイアウトに変更。年度推移タブの予算種別列もバッジ化（幅100→68px）

## 検証

- `npx tsc --noEmit` / `npm run lint`: クリーン
- Playwrightで一覧・サイドパネル双方の表示を確認。列幅短縮により増減率列まで画面内に収まるようになった
