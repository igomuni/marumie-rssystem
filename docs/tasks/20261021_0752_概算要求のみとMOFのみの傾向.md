# 概算要求のみ・MOF のみの項の傾向（年度・所管）

状態: 調査（FY2023〜2026 の項の突合。PR #535 の修正後の出力）。概算要求のみは約 5〜8%、MOF のみは約 5〜10% で、年度をまたいで続く項と、PDF の欠け、繰入・予備費・独立行政法人の施設整備費に寄る。

概算要求のみ = MOF の項に対応する名前が見つからない概算要求の項（候補なし、名前が近い、所属が引けない）。MOF のみ = 概算要求に対応する行がない MOF の項。突合は名前と所属で行い、金額は条件にしない。所属は、一般会計は所管、特別会計は特別会計名。

## 読み取れること

- **PDF の欠け**: MOF のみで割合が最も高い法務省（50%）は、FY2023・FY2024 の PDF の欠けによる。FY2025 以降は 0 件。交付税及び譲与税配付金特別会計の 8 件（FY2023）も同じ。
- **特別会計の繰入・予備費**: 概算要求のみでは、自動車安全特会（18.5%）、子ども・子育て支援特会（12.5%）、エネルギー対策特会（10.7%）、食料安定供給特会（10.0%）の割合が高い。繰入、予備費が多い（原因は未確認）。
- **内閣府・国土交通省**: 概算要求のみが毎年続く（内閣府は 8〜19 件、国土交通省は 13〜16 件）。
- **文部科学省・経済産業省・内閣府**: MOF のみに、独立行政法人の施設整備費・出資、エネルギー対策特会への繰入が毎年出る。
- **共管の特別会計**: MOF 側の所属が複数の府省名の特別会計は、MOF のみに出る（概算要求側の所属と一致しないため、割合は出さない）。
- 毎年続く項は、名前の食い違いというより、概算要求と当初予算の編成の違い（項の立て方、組み替え）と考えられる。原因は確認していない。

## 関連する直し（PR #535）

所属の補完、名称の変更、複数候補の絞り込み、NEAR_NAME（名前が近い組）で、FY2023 の概算要求のみ・複数候補の約 20 行が解消した。法務省の PDF の欠けは直せない。
