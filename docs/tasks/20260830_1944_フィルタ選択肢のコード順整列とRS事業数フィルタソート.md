# フィルタ選択肢のコード番号順整列（3ページ共通）と目一覧のRS事業数フィルタ・ソート

## フィルタ選択肢のコード番号順整列

`docs/mof-budget-data-guide.md` 4章の公式コード表（所管4-1・主要経費4-2・目的別4-3・財政法公債金対象非対象別4-4・経済性質別4-5・使途別4-6）に基づき、フィルタのプルダウン選択肢を五十音順ではなくコード番号順で表示するようにした。`/mof-kou`（項）・`/mof-jikou`（事項）・`/mof-kou-moku`（目）の3ページすべてに適用（従来は3ページとも`.sort()`＝文字コード順だった）。

新規`app/lib/mof-classification-order.ts`に各コード表の順序リストと`sortByCodeOrder()`を実装。特別会計は複数省庁の共管表記（例:「内閣府、総務省及び財務省」）になるため、文字列に含まれる名称のうち最も番号の若いものでランク付けする方式にした。コード表に無い値（政府系金融機関名等）は末尾に五十音順で並ぶ。

- `/mof-kou`: 所管
- `/mof-jikou`: 所管・主要経費
- `/mof-kou-moku`: 所管・主要経費・使途別・目的別・財政法公債金対象非対象別・経済性質別

## 目一覧（/mof-kou-moku）のRS事業数フィルタ・ソート

- **列ヘッダーをクリック可能に**: RS列の見出しがソートボタンになり、紐づくRS事業数（重複排除した事業ID数）でソートできる。ソートキー`'rs'`はitem自体のフィールドではなく`linkageByKey`から都度計算するため、`columns.ts`の汎用`sortItems`とは別に、ページ側で`sortKey === 'rs'`のときだけ専用の比較関数を使う分岐を追加。
- **RS事業数の範囲フィルタ**: サイドパネルに「RS事業数」スライダーを追加（本年度額等の他の数値スライダーと同じ位置づけ）。可動域は年度全体（他の絞り込みの影響を受けない）から算出。
