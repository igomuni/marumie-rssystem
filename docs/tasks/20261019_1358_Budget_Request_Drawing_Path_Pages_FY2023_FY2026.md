# 概算要求書 PDF の「描画パス型」頁の棚卸し（FY2023〜FY2026）

文字が画像として見えるのに文字層が空（pdftotext の結果が空）の頁が、FY2023〜FY2026 の corpus に 934 頁ある（法務省・金融庁・内閣官房・公取委・文科省・会計検査院）。残りの空頁 475 頁は白紙。所管への問い合わせ材料。

## 方法

- 対象: 各年度の `plain-text-manifest.json`（FY2023 134 PDF、FY2024 142、FY2025 135、FY2026 138）のうち、頁のテキスト SHA-256 が空文字列のもの（status `EMPTY` の PDF は全頁）。計 1,409 頁。
- 判定: 空頁を 30dpi のグレースケールで描画し、輝度 160 未満の画素の割合（インク量）を測った。0.05% 未満は白紙（475 頁）、0.3% 以上を描画あり（934 頁）とした。0.05〜0.3% の頁はなく、0.3〜1% は 2 頁だけ（描画あり側）。
- 目視: 描画あり頁のうち FY2023・FY2025・FY2026 と FY2024 の文科省は全頁、FY2024 の金融庁は 10 本すべて、法務省は 25 頁おき（約 22 頁）を、縮小画像の一覧で確認した。FY2024 法務省・金融庁の残り約 770 頁と、描画のない PDF の白紙頁 462 頁は画像を見ていない。描画のある PDF に含まれる白紙 13 頁は目視で白紙だった。
- 描画あり頁数は、描画の濃さによる近似。

## 所見

- 文字層が空で画像に中身がある頁は、金額表・事項名・表紙・定員表そのもの。図や罫線だけの頁ではない。
- 法務省は FY2023・FY2024 が全頁、FY2025・FY2026 は末尾付近の数頁だけ。金融庁は FY2024 だけ（FY2025・FY2026 は文字層あり）。内閣官房・文科省・公取委・会計検査院は、各年の数頁が描画パス。
- 内閣官房・文科省・法務省の頁には金額欄の黒塗りがある。文科省の学術研究助成基金の頁は、FY2023・FY2024 で黒塗りの位置まで同じ。画像でも黒塗り部分は読めないため、文字層の欠落と公開時の黒塗りは分けて考える。
- これらの頁は、plain text 由来の CSV・MOF 突合に入っていない（文字層から欠落したまま）。

## 問い合わせの論点（案）

- 法務省・金融庁・内閣官房・公取委・文科省・会計検査院の概算要求書 PDF で、文字が描画パスになっている頁がある。
- 年度や頁により混在しており、機械可読性の面で文字層のある PDF を出してほしい。
- 黒塗りの頁は、黒塗りと文字層の有無が重なっている（黒塗りの範囲の公開方針は別の話）。
