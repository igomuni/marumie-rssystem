# 概算要求PDFのCSV化・UI化・MOF突合の振り返り

状態: 振り返り（#522〜#535 まで。Claude と Codex の振り返りを 1 本に統合。末尾に次の作業の案と、要求額と当初予算額の予備調査を追加）。結論は、数字を取り出せただけでなく「数字が違う・項目が見つからない理由」を調べられるようになったこと。残る差は年度をまたいで同じ項に偏り、要求と編成の項の立て方の違いである可能性がある（個別の原因は未確認）。

作成日: 2026-10-21

概算要求PDFのCSV化から、MOF予算書との突合、年度推移UIの構築までを振り返る。以下はリポジトリ内の仕様・調査記録に基づく考察であり、新たな全件検証や制度資料の確認を行った結果ではない。数値は参照資料の集計時点・対象に依存する。

ここまでの大きな成果は、予算の数字を取り出せただけでなく、**「数字が違う・項目が見つからない理由」を調べられるようになったこと**である。

## 1. PDFの構造そのものが、予算を理解する情報だった

コードの桁数だけでは、組織・項・事項を区別できなかった。一方、目次の見出し、総表の並び、明細表の位置、分冊の対応を合わせると、所属と階層を復元できた。

予算書の意味は「名称と金額」だけでなく、**どこに、何の下に書かれているか**にも含まれている。CSV化で出所のページや行を残した判断が、後の突合とUIのPDFリンクまで効いている。

読めない頁も情報になる。文字層のない頁には、画像（黒塗り）・描画（文字が線画）・空白の3種類がある。FY2027 の黒塗りは法務省（公安調査庁）11頁、内閣官房11頁、内閣府2頁に集中し、いずれも情報・調査系の項である。総額は他の表から引けるが明細の頁は読めないので、抽出の失敗ではなく**意図的な非開示の可能性**がある（制度資料では未確認）。一方、PDF丸ごと文字層がない書（法務省 FY2024、金融庁 FY2024、厚生労働省 FY2027 の歳出）は年度ごとに出方が変わるため、コーパスは毎年検査が要る。

参照: [明細表CSVの仕様](../budget-request-detail-table-csv.md)

## 2. MOFとの不一致が、調査対象になった

10月21日の集計では、FY2026の「概算要求のみ」は63／1,181項、「MOFのみ」は58／1,084項だった。大部分が対応したことで、残りの特徴が見えるようになった。

未対応は一様ではなく、繰入・予備費・施設整備費などに偏り、4年度とも概算要求側だけに現れる項も23ある。毎年繰り返す差なら、単発の抽出ミスだけでは説明しにくく、要求と予算編成で項の立て方が違う可能性がある。ただし、個別の原因はまだ未確認である。

今後は一致率を上げるだけでなく、**残った差を分類することで、予算編成の特徴を調べられる**。

参照: [概算要求のみ・MOFのみの項の傾向](20261021_0752_概算要求のみとMOFのみの傾向.md)

## 3. 「新規・消滅」には、政策の変化と観測の変化が混ざっている

子ども・子育て支援特別会計への移管では、旧会計から項が消え、新会計に現れる。単純な年度比較では、継続している支出まで「廃止と新設」に見える。一方、FY2027の項数が少ないのは、厚生労働省の要求書が取り込まれていない影響がある。

したがって、新規・消滅はまず「データ上で初めて現れた／見えなくなった」という観測である。そこから制度上の新設・廃止を判断するには、移管・改称・収録範囲の確認が必要になる。

年度をつなぐキーの設計からも同じことが言える。項の同一性は**名前と場所**（会計・所管・特別会計・勘定・組織）で決まり、コードは属性にすぎない。項コードは同じ書の中で同名・別コードの項を区別するときだけ使い、所管コードは年度で変わる（例: 年金 9207 → 2507）のでキーから外した。年度間のつなぎには、改称・移管・会計新設・所管コード変更という出来事の記録が要る。確定は移管元が特定できる場合（同じ場所での改称、新設会計への移管）に限り、それ以外は候補に留めている。

UIまで作ったことで、この違いが利用者の解釈を左右することも明確になった。**データの収録状況自体が、金額と同じくらい重要な表示情報**である。

## 4. 二重計上には、別々に扱うべき二つの原因がある

一つは、同じ特別会計の項が複数府省の要求書に掲載される「掲載の重複」。特別会計の項も、PDFのドメインから判定した発行元の府省ごとに現れる。現れ方は2通りある。同じ額が複数の書にそのまま載る場合（例: エネルギー需給構造高度化対策費）と、復興特会のように各省が持ち分を載せ、その合計が合計書の額と一致する場合である。前者は掲載の重複、後者は内訳と合計の併存で、扱いを分ける必要がある。もう一つは、一般会計から特別会計への繰入と、その先の支出を両方足す「資金移動による重複」である。

前者は同じ項をまとめることで対処できるが、後者には会計間の資金の流れの把握が必要になる。さらに復興特会では、各省の取り分と合計書が併存する。単純な重複削除や同名集約だけでは足りない。

ここから得られる知見は、**「一覧として正しい」ことと「合計して正しい」ことは、別途確かめる必要がある**ということである。今後のサンキーとの接続でも中心となる論点である。

## 5. 次年度の要求書は、前年度を振り返るための資料にもなる

これは今回の成果から発展できる調査案である。要求書には当年度の要求額に加え、前年度予算額がある。そのため、同じ項について次の三つを並べられる。

| 観測する数字 | 分かること |
|---|---|
| 当年度の概算要求額 | 要求段階の金額 |
| 同年度のMOF予算額 | 提出時・成立後それぞれの金額 |
| 次年度要求書の前年度予算額 | 翌年の要求書が比較基準として扱う金額 |

この三点を比べれば、要求から予算への変更に加え、移管先で過年度の金額がどう引き継がれたかも調べられる可能性がある。ただし、補正後など比較基準の違いがあり得るため、三つ目を無条件に当初予算と同一視しないことが必要である。

参照: [年度推移CSVの金額列と移管・改称の扱い](../budget-request-trend-csv.md)

## 6. 今回確立した方法自体に、再利用できる価値がある

抽出では原文を残す、空欄を勝手にゼロにしない、判断不能を記録する。MOF突合では金額を一致条件にせず、対応した後に差を見る。この分離によって、「予想した答えに合うように読み取ってしまう」循環を避けられた。

金額差を調べたいときに、金額一致で対応先を選ぶと、肝心の差が消えてしまう。**差を発見できるのは、対応付けの根拠と、比較したい値を分けてきたから**である。

なお、年度推移UIの移管・改称候補の生成では金額の近さも使っており、MOF突合とは別の規則である。候補や推定を、制度資料によって確定した対応と混同しないことが重要となる。

## 7. 進め方で効いたこと

- **目視で挙がった具体的な項が最良のテストだった。** エネルギー需給構造高度化対策費（表紙の取り込み）、破壊的団体等調査費（黒塗り頁）、FY2023 の個人情報保護委員会（表紙のない書）が、それぞれ設計の欠陥を表に出した。
- **フラグの粒度は表示の粒度に揃える。** 項単位で持ったバッジが、発行元ごとのレコードで誤表示になった。
- **自動分類には目視の道具を添える。** サムネイルとホバー拡大で、画像・描画・空白の分類を人が素早く検証でき、「画像がない＝空白」という誤りも見つかった。

## 次に掘り下げたいこと

**毎年未対応のまま残る項を少数選び、要求書・MOF・次年度要求書の三点で理由を追う**ことを優先したい。

繰入、予備費、施設整備費から代表例を選び、残った不一致が次のどれに当たるかを確認する。

- 公開資料や収録範囲の欠落
- 抽出・階層復元の問題
- 名称や所属の違い
- 予算編成上の組み替え、移管、統合など

あわせて、対応が取れた約95%の項について**概算要求額と当初予算額を比べる（査定率）**。所管別・種別の査定の傾向は、このデータでしか出せない。

原因が具体化すると、UIも「差があることを見せる」段階から、**「その差をどう読むかを助ける」段階**に進められる。

## このあと何をするか（Claude の案）

### 予備調査: 要求額と当初予算額

`tests/fixtures/mof-budget-request-match/{year}/m1-kou.csv` の MATCHED の行を、MOF の行ごとに 1 件として数えた。名前で対応を取った結果をそのまま使った粗い集計で、個別の項は確認していない。

| 年度 | 項 | 同額 | 当初 < 要求 | 当初 > 要求 | 要求の合計 | 当初の合計 |
|---|---:|---:|---:|---:|---:|---:|
| FY2023 | 943 | 183 | 394 | 366 | 508.7兆 | 496.4兆 |
| FY2024 | 961 | 156 | 442 | 363 | 545.2兆 | 545.6兆 |
| FY2025 | 1,004 | 171 | 405 | 428 | 538.0兆 | 541.3兆 |
| FY2026 | 1,024 | 168 | 481 | 375 | 550.9兆 | 562.7兆 |

合計は一般会計と特別会計の総計なので、繰入の分が重複している。

- **査定で減るとは限らない。** 4割近くの項で、当初予算が要求額より大きい。
- **差の大きい項は、編成で機械的に決まるものが多い。** FY2026 では次のとおり。
  - 当初予算で増えた項:
    - 地方交付税交付金: 18.5兆 → 20.1兆
    - 財政融資資金へ繰入: 10.0兆 → 13.0兆
    - 予備費: 5,000億 → 1兆
  - 当初予算で減った項:
    - 国債費: 32.4兆 → 31.3兆
  - 要求の時点では仮置きで、編成の段階で地方財政対策・金利・財投計画に合わせて決まる、と読める。
- **要求額が 0 で、当初予算に額がある項がある。** FY2026 は 15 項、計 1.8兆。
  - 例: 先端半導体・人工知能関連技術対策費、同勘定への繰入、独立行政法人情報処理推進機構出資。
  - 事項要求（金額を示さない要求）の候補で、次の 5 項目の 1 つ目にそのまま当たる。

### 知りたいこと

1. **事項要求はどれだけあり、編成でいくらになったか。** 要求額 0 または「事項要求」の表記を全年度で拾い、当初予算の額と並べる。
2. **査定は何に効いているか。** 仮置きの項（交付税、国債費、予備費、繰入）と、裁量の項を分ける。そのうえで、裁量の項だけについて所管別の査定率を見る。分けずに見ると、仮置きの項の動きに埋もれる。
3. **翌年の「前年度予算額」は当初予算と一致するか。** 三点比較を全件で確かめる。ずれる項は、移管・改称・補正の扱いのどれかに当たるはず。
4. **年度をまたいで残る未対応の 23 項は、なぜ残るのか。**

### 欲しい機能

- **査定ビュー**（MOF 突合の UI を分ける方針に沿って、別ページ）
  - 項ごとの要求額と当初予算額の散布図（対数軸）
  - 仮置きの項と事項要求を色分けする
  - 所管で絞り込める
- **推移の 3 本線**: 項ごとに、要求額、当初予算額、翌年の前年度予算額を同じ軸に重ねる。
- **収録状況の注記**: PDF の欠けや丸ごと文字層のない書を、年度推移・突合の件数のそばに出す。

### 解きたい問題

- **繰入の純計。** 会計間の繰入をグラフにして、総計（約 550兆）から重複を除いた純計を出す。統合サンキーで「予算の総額」を正しく描く前提になる。
- **内閣府・内閣官房の分冊。** 約 40 分冊にまたがる項の PDF 頁が引けていない。
- **線画化された文字。** FY2027 の厚生労働省の歳出は文字が線画になっている。OCR か、グリフの形から文字を復元するかを判断する。

### 優先順位の案

1. 事項要求の検知。予備調査で要求額 0 の項が実際に見つかり、既存の議題とも一致する。
2. 仮置きの項と裁量の項を分けた査定率。
3. 繰入の純計。
