# 予算・決算のタイムラインと帳票の年度変遷（平成23年度〜令和8年度）

Web検索で制度上のタイムラインを確認し、財務省 予算書・決算書データベース（bb.mof.go.jp）の
アーカイブページを平成10年度〜令和8年度まで実地で走査して、CSV提供の有無と列構造の変遷を調べた。

## 1. 予算・決算のタイムライン

1つの会計年度は、編成開始から決算の国会提出まで**約2年半**かかる。

```text
前年 6月     骨太方針を閣議決定
前年 7月     財務省が概算要求基準を作成・提示
前年 8月末   各省庁が概算要求を提出
前年 9〜12月 財務省主計局の査定
前年12月末   政府予算案を閣議決定
当年 1月     通常国会に提出、衆参の予算委員会・本会議で審議
当年 3月末   当初予算 成立         ← 間に合わなければ 暫定予算
当年 4月     年度開始（執行）
当年度中     必要に応じて 補正予算（第1号、第2号…）
翌年 7月31日 各省庁が歳入歳出決算報告書を財務大臣へ
翌年11月30日 内閣が決算を会計検査院へ送付（財政法第40条）
翌年11月上旬 会計検査院が決算検査報告を内閣へ回付
翌年11月20日頃 決算＋検査報告を国会へ提出（平成15年度決算以降の運用）
```

- 決算の11月20日前後提出は、平成15年5月の参議院の要請に基づく前倒し運用
- 実例: 令和6年度決算検査報告は令和7年11月5日に内閣へ送付された
- **RS システムの行政事業レビューはこの流れの外側**で、執行後に各省庁が自主的に作る点検資料

## 2. 予算の種類は3つで網羅されている

財政法上、予算は**本予算（当初予算）／暫定予算（第30条）／補正予算**の3種類しかない。
MOF の帳票区分もこの3つ＋決算で閉じており、走査した全17年度で他の種別は現れなかった。

ただし**帳票としては CSV 化されていない参考書類がある**。

- `財政法第28条等による予算参考書類` — 全年度に PDF/XML であるが CSV は無い
- 事項別内訳・歳出決算報告書 — Web の XML のみ（`mof-budget-data-guide.md` §3）

## 3. 帳票区分コードの網羅（既存ガイドに未記載の `23` がある）

| 区分 | 内容 | 出現年度 |
|---|---|---|
| `11` / `12` / `13` | 当初予算 一般会計 / 特別会計 / 政府関係機関 | 全年度 |
| `21` / `22` | 補正予算 一般会計 / 特別会計 | ほぼ全年度 |
| **`23`** | **補正予算 政府関係機関** | **H23・R2 のみ** |
| `31` / `32` / `33` | 暫定予算 一般会計 / 特別会計 / 政府関係機関 | H24・H25・H27・R8 |
| `76` / `77` / `78` | 決算 政府関係機関 / 一般会計 / 特別会計 | H23〜R6 |

`docs/mof-budget-data-guide.md` §1 の表に **`23`（補正予算・政府関係機関）が抜けている**。

**連番3桁は補正予算の号数**（`21001`=第1号、`21002`=第2号 …）。最多は平成23年度の第4号まで。

## 4. CSV が取れるのは平成23年度から

| 形式 | 提供範囲 |
|---|---|
| PDF / XML | 少なくとも平成10年度から |
| **CSV（ZIP）/ Excel** | **平成23年度（2011）から** |

平成22年度以前のアーカイブページには CSV・Excel のリンクが1本も無い（PDF版・XML版のみ）。

## 6. 列構造の変遷 — 現行形式は平成24年度から

### 予算（当初）

一般会計は**平成23年度から令和8年度まで15年間まったく不変**（歳入12列・歳出14列）。
政府関係機関も不変。特別会計だけ1回変わった。

| 帳票 | 変更 |
|---|---|
| 一般会計 `11001a/b` | 変更なし |
| **特別会計 `12001b`** | **H23 のみ `共管所管名` `共管組織名` が無い**（H24 から追加、以降不変） |
| 政府関係機関 `13001` | 変更なし |

唯一の揺れは**令和6年度だけ金額列の `(千円)` が欠落**（`令和6年度要求額`）。
その前後（R5・R7・R8）は `(千円)` 付き。単発の表記ミスであり、列名の完全一致で拾うと R6 で落ちる。

### 政府関係機関の列は一般会計・特別会計と別物（ガイド未記載）

```text
13001a: 政府関係機関,業務,款コード,項コード,目コード,款名,項名,目名,{年度}予定額(千円),前年度予算額(千円),比較増△減額(千円)
13001b: 政府関係機関,業務,項コード,使途別分類コード,目コード,項名,目名,{年度}予定額(千円),前年度予算額(千円),比較増△減額(千円)
```

**分類コードが `使途別` の1本しかない**（主要経費別・目的別・経済性質別・公債金対象が無い）。
組織軸も `政府関係機関` + `業務`。一般会計用のパーサをそのまま当てられない。

### 暫定予算は金額列が1本だけ

```text
31001b: …,項名,目名,令和8年度暫定予算要求額(千円)
32001b: …,共管組織名,項名,目名,令和8年度暫定予算予定額(千円)
33001b: …,項名,目名,令和8年度暫定予算予定額(千円),,     ← 末尾に空列2つ
```

比較欄（前年度額・増減額）が無い。`33001b` には**末尾に空カラムが2つ付く**ので列数決め打ちは危険。

### 補正予算は金額列5本だが名前が会計ごとに違う

| 帳票 | 追加額の列名 |
|---|---|
| 一般会計 歳入 `21001a` | `予算補正追加額` |
| 一般会計 歳出 `21001b` | `補正要求追加額` |
| 特別会計 `22001` | `補正予定追加額` |
| 政府関係機関 `23001` | `補正予定追加額` |

共通は `{年度}成立予算額` → 3本の増減 → `改{年度}予算額`（特会・機関は `改{年度}予定額`）。
**`追加額` `修正減少額` `差引額` の前置語が3通りある**ので、完全一致で拾わず部分一致か列位置で解決する。

### 決算も現行形式は平成24年度から

| 帳票 | 変更 |
|---|---|
| 一般会計 `77001b` | H23〜R6 変更なし（9金額列） |
| **特別会計 `78001b`** | **H23 は `共管所管名` `共管組織名` `予算決定後移替増△減額` が無い**。H24 から現行 |
| **政府関係機関 `76001b`** | **H23 は `前年度繰越額` `翌年度繰越額` が無い**（7金額列）。H24 から9列 |

決算の金額列は会計区分ごとに違う。

```text
77001b（一般会計）: 歳出予算額,前年度繰越額,予備費使用額,流用等増△減額,予算決定後移替増△減額,
                    歳出予算現額,支出済歳出額,翌年度繰越額,不用額
78001b（特別会計）: 上記 + 予算総則の規定による経費増額（流用等の前）
76001b（政府関係機関）: 支出予算額,前年度繰越額,予備費使用額,予算総則の規定による経費増額,
                        流用等増△減額,支出予算現額,支出済額,翌年度繰越額,不用額
```

**`予算総則の規定による経費増額` は一般会計だけ無い。** 政府関係機関は
「歳出」ではなく「支出」で列名が揃う（`支出済額`、`支出予算現額`）。

H23 の `78001a` には末尾に空カラム2つが付く（暫定 `33001b` と同じ癖）。

## 7. パイプラインへの含意

現状（`mof_2021`〜`mof_2024`・`mof_2026`、事項は2023〜2026）を過去へ広げる場合:

- **平成24年度（2012）以降は列構造が完全に安定**しているので、既存パーサがほぼそのまま効く
- **平成23年度（2011）だけは特会予算・特会決算・政府関係機関決算で列が足りない**。
  取り込むなら列名解決を必須にし、欠落列は null にする分岐が要る
- 政府関係機関（`13`/`23`/`33`/`76`）は分類コード体系が別。未対応なら明示的に除外する
- 補正の号数（連番002以降）は現状のパイプラインが `001` 決め打ちのため、
  H23・H28・H30・R2・R4 の第2号以降を取りこぼす

## 8. 補正予算の号数と CSV 提供（追加調査）

補正予算の種類は**「第N号」の連番のみ**で、他のパターンは無い。最大は平成23年度の第4号。
アーカイブページの見出しは `補正予算第N号 [第NNN回(常会|臨時会|特別会)]` の形で、
成立した国会の回次が併記される。

## 9. 令和8年度が例外になった経緯（深堀り）

データ上の異常（当初が特別会で成立・暫定予算・当初と同じ回の補正が全部第221回に集中）の
原因を外部情報で確認した。**直接の原因は解散総選挙**で、経済ショックは補正の中身の側にある。

### 実際の日程

```text
2026-01-23  通常国会（第217回）冒頭で高市首相が衆議院を解散
2026-02-08  第51回衆議院議員総選挙
2026-02-18  第221回国会（特別会）召集。会期158日（当初150日→7/25まで延長）
            首班指名 → 政府四演説 → 代表質問 → 令和8年度予算の審議
2026-03-27  令和8年度暫定予算を閣議決定（一般会計 8兆5,641億円 / 4月1日〜11日の11日分）
2026-03-30  暫定予算 成立（2015年=平成27年度以来11年ぶり）
2026-04-07  令和8年度当初予算 成立（参院予算委は可否同数、委員長決裁で可決）
2026-06-05  令和8年度補正予算第1号 成立（一般会計 3兆1,135億円）
```

**予算審議入りが1か月ほど後ろにずれた**のが暫定予算の直接原因。
衆院の審議時間は約59時間で過去20年で最短。参院で可決されなくても憲法60条により
衆院可決から30日後の4月11日には自然成立するため、**暫定予算は4月11日までの11日分**として組まれた。

「11年ぶり」は §5 のマトリクスと整合する（暫定は H24・H25・H27・R8 の4回で、前回が H27=2015年）。

### 暫定予算は日割りではない（前提の訂正）

対象は11日分（365日中3.0%）だが、実際の計上額は当初比 **8.3%**（一般会計だけなら7.0%）で、
**日割りの約2.7倍**が積まれている。国債利子・年金・人件費など期日が暫定期間内に来る経費を
実額で積むためで、均等按分ではないことの裏付けになる。
（`20260822_0709_暫定予算は当初の内数であることのデータ検証.md` の当初の推測を訂正済み）

### 補正の中身は地政学と物価

補正第1号の事項は3件だけで、**増減額ベースで3兆1,135億円**（Wikipedia の記載額と一致）。

| 事項 | 主要経費 | 成立額 | 増減 |
|---|---|---:|---:|
| 物価高騰対応重点支援地方創生臨時交付金 | その他の事項経費 | 0（新設） | +1,000億 |
| **中東情勢等対応予備費** | **中東情勢等対応予備費（コード96・新設）** | 0（新設） | **+2兆5,000億** |
| 予備費 | 予備費（コード98） | 1兆 | +5,135億 |

- **主要経費コード `96 中東情勢等対応予備費` が新設**された。R5・R6 には存在しない分類で、
  事項ではなく**分類コードごと新設**されている
- **補正額の96.8%（3兆135億円）が予備費の積み増し**。使途を特定せず備える構成
- 既存の予備費コードは `97 復興加速化・福島再生予備費` `98 予備費` の2本で、そこに3本目が加わった

### 因果の切り分け

```text
解散・総選挙（1/23解散・2/8投票）
  → 特別会で当初予算を審議 → 年度内成立せず → 暫定予算11日分 → 3種別が第221回に集中
中東情勢・物価高騰
  → 補正の中身（臨時交付金・中東情勢等対応予備費）
```

**手続き上の例外性は解散総選挙、補正の内容は地政学・物価**で、原因が別。
両者に共通の上流があったかは予算書データからは検証できない。
