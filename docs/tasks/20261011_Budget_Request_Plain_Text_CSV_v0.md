# FY2024 Budget Request Plain Text to Cover / TOC CSV v0

Development only. The runner selects exactly MLIT PDF physical page 6 for a TOC and CAO PDF physical page 1 for the Cover. It reads only the preflighted UTF-8 TXT outputs, verifies terminal FF and manifest pageCount for both TXT inputs, then verifies the source PDF SHA-256 and selected page text SHA-256 against the frozen manifest, and writes deterministic outputs under `data/work/budget-request-csv/2024`.

The TOC schema is `要求番号,区分,ページ`. R1 rows retain the request number and complete `<code> <name>` text; `（項）` rows have a blank request number and preserve the exact full-width token and source spacing. R1 uses only the Pattern Catalog forms: a 1–3 digit request number and a code with U+2010, U+2011, or ASCII hyphen. I1 uses only `（項）\s*\d+`; ASCII parentheses and other dash lookalikes are rejected. Printed terminal page numbers are candidates copied from the selected text; request numbers are never inferred. Start-token positions classify the two sides against the observed column boundary 30; boundary ties and unresolved continuations are audited. Continuation text joins only the current unique same-side parent. The TSV audit includes each raw line’s zero-based LF-split index. Nonempty Cover lines outside the four represented CSV fields, headers/page markers, ambiguous starts, and unassigned text are explicitly excluded or unresolved in `audit.tsv`; prefix text before a later start token is attached as a same-side continuation when possible, otherwise audited.

Cover uses the selected page text to extract the year, authority header, and document name while retaining the text's internal spacing, printed authority code, and Unicode. The `会計` field is blank because it is absent from this page. If the selected Cover page cannot support all four columns, extraction fails instead of changing the schema.

Run `npx tsx scripts/pipeline-v2/build-budget-request-plain-text-csv.ts`. This intentionally does not enumerate the corpus or held-out data. The hand-authored continuous artificial one-page fixture, independent expected CSV, and provenance note are in `tests/fixtures/budget-request-plain-text-csv`; tests assert all 16 ordered R/I/C/E side-state pairs (including C parents) through a single page-level parse call, against an independent hand-authored expected CSV. Tests are in `scripts/pipeline-v2/lib/budget-request-plain-text-csv.test.ts`.
